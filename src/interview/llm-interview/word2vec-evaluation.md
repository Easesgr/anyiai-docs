## 30秒口述结论

Word2Vec 是一种基于分布式假设（Distributed Hypothesis）的浅层神经网络模型，通过滑动窗口学习词在固定维度空间中的稠密向量表示：

1. **获取词向量的两种架构**：
   - **CBOW**：用上下文词预测中心词。将上下文所有词的向量求和或取平均作为输入，计算效率高，适合海量语料快速训练。
   - **Skip-gram**：用中心词预测上下文词。每个上下文位置独立计算损失，低频词获得更新的机会更多，表征质量更好。
2. **训练加速与目标优化**：
   - 传统 Softmax 分母需要遍历整个词表 $V$，单步计算开销为 $O(|V|)$，计算不可行。
   - **层次 Softmax** 将多分类转为基于词频构建的霍夫曼树路径二分类，将复杂度降为 $O(\log_2 |V|)$。
   - **负采样** 将多分类转为正负样本的二分类对数似然最大化，结合 3/4 次方平滑采样，将复杂度降为常数级的正样本与 $K$ 个负样本计算。
3. **词向量的好坏评估**：
   - **内在评估**：脱离下游任务，通过词相似度数据集（如 WordSim-353，算模型与人工打分的 Spearman 等级相关系数）和词类比任务（如 $\text{king} - \text{man} + \text{woman} \approx \text{queen}$ 的检索准确率）评估几何空间的语义一致性。
   - **外在评估**：将词向量代入下游任务（如文本分类、命名实体识别），对比“随机初始化”、“预训练冻结”与“预训练微调”三种基线的最终任务指标（F1、准确率等）。

## 贯穿示例与模型架构：CBOW 与 Skip-gram

分布式假设的核心思想是：词的语义由其周围经常出现的词决定（"You shall know a word by the company it keeps"）。

我们以一个具体文本片段为例：
> **句子**：`["小明", "喜欢", "在", "操场", "踢", "足球"]`

设定滑动窗口半径 $c = 2$。当窗口滑动到中心词 **"操场"** 时：
- **中心词**：`"操场"`
- **上下文词**：`["喜欢", "在", "踢", "足球"]`（共 $2c = 4$ 个词）

Word2Vec 包含两个可训练参数矩阵：输入矩阵 $W \in \mathbb{R}^{|V| \times d}$ 和输出矩阵 $W' \in \mathbb{R}^{d \times |V|}$，其中 $|V|$ 为词表大小，$d$ 为词向量维度（通常取 100~300）。每个词在 $W$ 中对应一行作为输入向量 $v_w$，在 $W'$ 中对应一列作为输出向量 $v'_w$。在 [Embedding 机制](/interview/llm-interview/embedding.md) 中，从矩阵中提取某一行相当于 One-Hot 向量与权重的乘积。

![CBOW 与 Skip-gram 架构与数据流向对比](/images/content-rebuild/75cb514eaac9f17f/fig-1.png)

### 1. CBOW：上下文预测中心词

CBOW（Continuous Bag-of-Words）将上下文中的所有词作为输入，预测目标中心词：

1. **隐层聚合**：取出 4 个上下文词在 $W$ 中的向量求和或取平均：
   $$v_{\text{context}} = \frac{1}{2c} \sum_{-c \le j \le c, j \neq 0} v_{w_{t+j}}$$
   在示例中，即把 `v("喜欢")`、`v("在")`、`v("踢")`、`v("足球")` 的向量相加求均值。
2. **输出预测**：用聚合向量 $v_{\text{context}}$ 与输出矩阵 $W'$ 做内积，计算全词表各个词的得分，并最大化中心词 `"操场"` 的对数概率：
   $$\mathcal{L}_{\text{CBOW}} = \sum_{t=1}^{T} \log P(w_t \mid w_{t-c}, \dots, w_{t+c})$$
3. **计算特点**：CBOW 将窗口内词序消除（Bag-of-Words 特性），多个上下文词只触发一次前向与反向传播，在大规模语料上训练吞吐量高。

### 2. Skip-gram：中心词预测上下文词

Skip-gram 的计算流向与 CBOW 相反，以中心词作为输入，分别预测窗口内的每一个上下文词：

1. **前向输入**：输入中心词 `"操场"` 的单一向量 $v_{\text{操场}}$。
2. **独立预测**：假设给定中心词时上下文词之间相互独立，分别计算预测 `"喜欢"`、`"在"`、`"踢"`、`"足球"` 的损失并累加：
   $$\mathcal{L}_{\text{SG}} = \sum_{t=1}^{T} \sum_{-c \le j \le c, j \neq 0} \log P(w_{t+j} \mid w_t)$$
3. **计算特点**：中心词不经过均值平滑。对于低频词（例如专业生僻词），在 Skip-gram 中每次作为中心词或目标词出现时，其梯度都能直接独立回传；而在 CBOW 中，低频词会被均值操作稀释。因此 Skip-gram 对低频词和长尾词的表示通常更精细，但训练开销约为 CBOW 的 $2c$ 倍。

## 训练加速机制：解决全词表 Softmax 计算瓶颈

若直接使用全量 Softmax 计算预测目标词 $c$ 的条件概率：

$$P(c \mid w) = \frac{\exp({v'_c}^\top v_w)}{\sum_{i=1}^{|V|} \exp({v'_{w_i}}^\top v_w)}$$

其分母必须对词表中所有词进行指数求和。当词表大小 $|V|$ 达到几十万甚至数百万时，单步参数更新的分母求和开销无法承受。为此，Word2Vec 提出了两种近似加速机制。

### 1. 层次 Softmax（Hierarchical Softmax）

层次 Softmax 将全词表的单层多分类问题，转化为二叉树上的路径决策：

- **霍夫曼树构建**：以词表中所有词作为叶子节点，以词在语料中的出现频次作为权重构建霍夫曼树。高频词靠近根节点，低频词位于深层节点。
- **路径决策**：从根节点到任意叶子词 $w$ 存在唯一路径。树中的每个非叶子节点都维护一个向量参数 $\theta$。每经过一个分支，用 Sigmoid 函数 $\sigma(\theta^\top v_w)$ 计算向左走的概率，向右走的概率为 $1 - \sigma(\theta^\top v_w)$。
- **概率连乘**：从根到叶节点路径上所有分支概率的乘积，即为该词的生成概率。
- **计算复杂度**：从 $O(|V|)$ 降低到霍夫曼树的平均深度 $O(\log_2 |V|)$。

![层次 Softmax 霍夫曼树寻路机制](/images/content-rebuild/75cb514eaac9f17f/fig-2.png)

### 2. 负采样（Negative Sampling）

负采样基于噪声对比估计（NCE）简化而来，完全跳过了概率归一化，把多分类任务转为正负样本的二分类辨别任务。

对于给定的中心词 $w$ 和窗口内的真实上下文词 $c$（正样本）：
1. 正样本通过 Sigmoid 计算其被判为真实共现的概率：
   $$P(D=1 \mid w, c) = \sigma({v'_c}^\top v_w) = \frac{1}{1 + \exp(-{v'_c}^\top v_w)}$$
2. 随机抽取 $K$ 个在当前窗口未与 $w$ 共同出现的词 $\{w_{n_1}, \dots, w_{n_K}\}$ 作为负样本（例如中心词为“操场”，抽到“香蕉”、“量子”等）：
   $$P(D=0 \mid w, w_{n_i}) = 1 - \sigma({v'_{w_{n_i}}}^\top v_w) = \sigma(-{v'_{w_{n_i}}}^\top v_w)$$
3. 目标函数为最大化正样本对数似然与负样本对数似然之和：
   $$\mathcal{L}_{\text{NEG}} = \log \sigma({v'_c}^\top v_w) + \sum_{i=1}^{K} \log \sigma(-{v'_{w_{n_i}}}^\top v_w)$$

![负采样多分类向二分类转换与梯度回传图](/images/content-rebuild/75cb514eaac9f17f/fig-3.png)

#### 3/4 次方平滑噪声分布设计

负采样并非按原始词频采样，也不是均匀随机抽取，而是采用 3/4 次方指数做平滑：

$$P_n(w) = \frac{U(w)^{3/4}}{\sum_{w' \in V} U(w')^{3/4}}$$

其中 $U(w)$ 是词 $w$ 在语料中的单字词频。

**为什么是 3/4 次方？**
- 若按原始词频采样：像“的”、“在”这类高频虚词会占据几乎所有负样本配额，模型无法学习普通实词与长尾词的负向差异。
- 若按均匀分布 $1/|V|$ 采样：极罕见的罕见词被采到的概率与常见词完全相同，违背自然语言的分布事实。
- 取 3/4 次方的效果算例：
  假设高频词 A 出现 10,000 次，低频词 B 出现 16 次。原始词频比为：
  $$\frac{10000}{16} = 625 : 1$$
  开 3/4 次方后：
  $$10000^{3/4} = 1000, \quad 16^{3/4} = 8$$
  采样概率比调整为：
  $$\frac{1000}{8} = 125 : 1$$
  低频词被采样的相对几率提升了 5 倍，既压制了超高频词垄断负样本，又激活了低频词的负向判别更新。

## 词向量如何评估好坏？

评估词向量主要分为**内在评估（Intrinsic）**与**外在评估（Extrinsic）**两种方式。

![词类比任务空间平移与余弦夹角几何解释](/images/content-rebuild/75cb514eaac9f17f/fig-4.png)

### 1. 内在评估：基于空间几何结构的直接评测

内在评估不接任何下游网络，直接计算词向量之间的空间几何关系，并与人类先验知识对比。

#### A. 词相似度评测（Word Similarity）
- **基准测试集**：如 WordSim-353、SimLex-999。测试集包含大量由人类标注相似度分数的词对（例如 `(computer, keyboard) -> 7.8/10`）。
- **计算方法**：
  1. 计算模型词向量的余弦相似度：
     $$\cos(v_a, v_b) = \frac{v_a^\top v_b}{\|v_a\|_2 \|v_b\|_2}$$
  2. 将模型得出的余弦相似度排序与人类标注打分排序进行比对，计算 **Spearman 等级相关系数（$\rho$）**。
  3. $\rho$ 越接近 1，说明模型对词汇间语义接近度的度量越符合人类常识。

#### B. 词类比评测（Word Analogy）
- **任务形式**：检验向量空间是否自发形成了线性平移语义关系，形如“$A$ 之于 $B$，犹如 $C$ 之于 $D$”。
  - 语义类比：`king` - `man` + `woman` $\approx$ `queen`
  - 语法类比：`walking` - `walk` + `swim` $\approx$ `swimming`
- **计算方法**：在词表中寻找余弦相似度最大的词向量：
  $$w^* = \arg\max_{x \notin \{A, B, C\}} \cos(v_x, v_B - v_A + v_C)$$
  计算 Top-1 命中标准词 $D$ 的准确率（Accuracy）。
- **内在评估的局限**：测试集小，类比受词频和超参数（如窗口大小、负采样数）波动较大。内在评测高分**不保证**在实际业务下游任务中一定带来同等收益。

### 2. 外在评估：基于下游业务任务的端到端评测

外在评估将词向量作为下游模型（如文本分类器、序列标注器 NER）的输入层，用实际生产指标（Precision、Recall、F1-Score）评价其质量。评测原则可结合 [AI 评测指标系统](/fundamentals/evaluation-metrics/what-is-evaluation.md) 与 [分类评估](/fundamentals/evaluation-metrics/classification-metrics.md)。

![内在评估与外在评估的评测链路对比](/images/content-rebuild/75cb514eaac9f17f/fig-5.png)

#### A. 词向量接入下游任务的两种模式

| 模式 | 实现方式 | 优缺点 |
| :--- | :--- | :--- |
| **冻结模式（Frozen）** | 锁定预训练词向量矩阵，训练时仅反向传播更新下游分类层权重。 | 训练速度快、参数稳定；但无法根据垂直场景特有词汇进行动态语义适配。 |
| **微调模式（Fine-tuning）** | 将预训练词向量作为下游网络输入矩阵初值，全网络梯度回传更新。 | 领域适应能力更强，下游指标上限通常更高；但样本量少时容易产生过拟合或破坏原有通识空间。 |

#### B. 标准消融实验基线（Ablation Baselines）
评估词向量的外在有效性，必须保证下游网络结构与超参数完全相同，设置三组对照：
1. **Baseline 1（随机初始化）**：词向量随机初始化，下游端到端训练。
2. **Baseline 2（词向量预训练 + 冻结）**：加载 Word2Vec 权重并锁定。
3. **Baseline 3（词向量预训练 + 微调）**：加载 Word2Vec 权重并开启微调。

只有当预训练词向量在收敛速度和最终 F1 值上显著优于随机初始化 Baseline 时，才能证明该词向量提取到了有效语义特征。

## 面试追问与边界分析

![反义词高共现陷阱与静态向量多义词语义塌陷](/images/content-rebuild/75cb514eaac9f17f/fig-6.png)

### 追问 1：在滑动窗口中相似上下文多的词，词向量一定语义相似吗？

**核心解答**：不一定。这是基于局部共现的分布式假设的内在缺陷：
1. **反义词陷阱**：例如 `"hot"` 与 `"cold"`，`"increase"` 与 `"decrease"`。反义词彼此很少直接连用，但它们出现在极其相似的上下文句式中（例如 `"The water is very ___"`）。由于上下文分布高度重合，Word2Vec 训练出来的 `hot` 和 `cold` 向量余弦相似度往往非常高，模型无法仅通过上下文共现分辨出对立语义。
2. **高频功能词干扰**：未经过滤的高频介词、代词由于在大量词周围出现，也会与很多实词形成微弱但广泛的关联。通常需要通过下采样（Subsampling）丢弃极高频词来规避空间形变。

### 追问 2：训练完成后有 $W$ 和 $W'$ 两个矩阵，应该用哪一个作为最终词向量？

**核心解答**：
- **输入矩阵 $W$**：词作为模型输入端（Skip-gram 的中心词或 CBOW 的上下文输入）时的查找表征。
- **输出矩阵 $W'$**：词作为模型输出预测目标（Skip-gram 的上下文词或 CBOW 的中心词）时的表征参数。
- **实际使用**：
  - 开源工具（如 `gensim` 和原版 Word2Vec C 代码）默认只保留**输入矩阵 $W$**。
  - 实验表明，$W$ 和 $W'$ 包含互补的分布信息。部分研究尝试将二者相加 $W + W'$ 或拼接作为词向量，在某些内在评估数据集上指标有轻微提升；但考虑到下游显存和内存占用，工程中绝大多数只取输入矩阵 $W$。

### 追问 3：为什么 Word2Vec 无法解决一词多义（Polysemy）？

**核心解答**：
Word2Vec 属于**静态词嵌入（Static Embedding）**。词表中的每个词在参数矩阵中仅占据唯一固定的行向量。
- 例如单词 `"bank"`，在金融语境下表示“银行”，在地理语境下表示“河岸”。
- 在 Word2Vec 的训练过程中，无论句子是在讨论 `"bank interest"` 还是 `"river bank"`，更新的都是同一个参数向量 $v_{\text{bank}}$。
- 最终学到的向量实际上是这几种语义梯度的加权平均混合，导致静态向量在具体语境下产生歧义。
- 这一缺陷正是后续基于注意力机制的动态上下文表征模型（如 ELMo、BERT）诞生的直接动力，相关演进脉络可参考 [Token 机制](/interview/llm-interview/token-basics.md) 与 [Word2Vec 到 BERT 的演进](/interview/llm-interview/word2vec-to-bert.md)。
