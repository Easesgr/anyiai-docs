在大模型算法岗位的面试中，“涌现能力（Emergent Abilities）”是一个考察候选人理论深度与审慎思维的高频问题。面试官不仅看候选人能不能列举现象，更看重能否区分“工程观察到的现象”与“背后的真实数学/度量机制”。

本文先提供一段可直接口述的结构化答案，再深入分析三种典型表现、两大主流假说，以及思维链（CoT）的技术细节与局限。

---

## 30 秒口述答案

在面试中被问及“什么是大模型的涌现能力？如何解释其成因？”时，可以按以下三层逻辑作答：

> **定义**：涌现能力指模型在中小规模（如数十亿参数以下或低计算预算）时在某些复杂任务上表现接近随机猜测，而当参数规模、训练数据量或总计算量跨过特定临界点后，任务性能突然呈现出非线性的快速跃升。
>
> **三种典型表现**：
> 1. **上下文学习（In-Context Learning）**：无需调整权重，仅靠提示词中的几个示范样本，模型就能推断并完成新任务；
> 2. **思维链推理（Chain-of-Thought）**：面对多步数学或逻辑题目，通过生成分步中间推导，大幅提高复杂符号推理的最终准确率；
> 3. **多约束指令遵循**：同时处理包含格式要求、字数限制和负向排除（如“不要包含特定词”）的复杂指令。
>
> **成因与争议**：当前学术界主要有两种视角：
> - **多步协同假说（相变视角）**：复杂任务通常由提取实体、规则映射、步骤计算等多个子能力串联而成。即便每个子能力的准确率随着规模只是平缓提升，多步连续相乘的复合成功率也会表现为前段贴地、后段突然陡峭拉升的非线性曲线。
> - **度量指标假象假说（Schaeffer 等，NeurIPS 2023）**：涌现可能是由离散、不连续的评价指标（如 0-1 全对率 Exact Match）带来的测量假象；如果换用连续平滑的指标（如词元级交叉熵、编辑距离），模型能力的增长在多项任务中表现为随规模平稳递增。

## 一个贯穿例子：小模型与大模型的表现断层

为了直观理解这种断层，我们看一道典型的两步应用题：

> **输入题目**：“小明买了 3 盒彩色铅笔，每盒 12 支。他送给妹妹 5 支，又收到了朋友送的 2 盒（每盒 6 支）。小明现在一共有多少支铅笔？”

- **1B~3B 规模模型**：往往直接输出一个数字（如 `36 支` 或 `41 支`），或者生成的文本在第一步就出现计算错误、遗漏“朋友送的铅笔”这一条件，导致最终答案完全错误，在按“最终数值完全匹配”打分时得分常年为 0。
- **百亿参数以上模型（配合逐步推导）**：能够逐行写出：
  1. 原有数量：$3 \times 12 = 36$ 支；
  2. 送出后剩余：$36 - 5 = 31$ 支；
  3. 收到新增：$2 \times 6 = 12$ 支；
  4. 最终总计：$31 + 12 = 43$ 支。

在外部评测者看来，模型仿佛在某个规模突然“开窍”了。下面我们逐项拆解这一现象在具体任务上的三种典型表现。

## 三种典型的涌现表现

学术界早期将涌现定义为“不存在于小模型中，却存在于大模型中的能力”（Wei 等，2022）。在应用层，它主要集中在以下三类任务：

### 1. 上下文学习（In-Context Learning, ICL）
在小模型（如早期的 GPT-2 较小分支或早期 BERT）中，模型在冻结参数的情况下，很难仅凭 Prompt 里的两三个输入输出示例就自动对齐新任务的映射关系。小模型通常需要依赖带梯度反向传播的监督微调（SFT）才能学会特定任务。

而在具备足够参数规模的模型中，仅在提示词中展示少量样本，模型即可推断出期望的输入输出格式并稳定输出：

```text
示例示范：
输入: [苹果, 香蕉] -> 类别: 水果
输入: [椅子, 书桌] -> 类别: 家具
输入: [老鹰, 麻雀] -> 类别: 

模型补全：鸟类
```

在此过程中，模型权重保持冻结，依靠前向自注意力机制在上下文键值中完成对任务格式与语义映射的识别。在小模型阶段，该任务的 Exact Match 得分几乎接近零；达到数十亿甚至数百亿参数后，少样本准确率出现非线性提升。

### 2. 思维链推理（Chain-of-Thought, CoT）
对于 GSM8K 等多步数学应用题或符号推理任务，如果要求模型直接给出最终结果（Direct Prompting），中小模型通常表现极差。

思维链提示通过引导模型先输出中间推导步骤、再输出结论来解决这一问题。值得注意的是：**在参数量不足的模型上使用思维链提示，准确率往往不升反降**。

原因在于小模型生成中间步骤时容易产生错误推导（如单步算术错误或逻辑颠三倒四），而自回归解码会将这些错误作为后续生成的上下文条件，造成错误滚雪球；只有当模型参数规模足够大、单步推理足够稳定时，显式展开步骤带来的算力补充才能覆盖错误积累的风险，思维链才展现出相对于直接输出的明显收益。

### 3. 复杂多约束指令遵循（Instruction Following）
指令遵循并不是单纯生成通顺句子，而是要同时兼顾多项互相制约的限制条件。例如：

> “请写一段关于光合作用的介绍，字数在 80 到 100 字之间，必须包含‘叶绿体’和‘二氧化碳’，严禁使用‘阳光’两字，且必须以问句收尾。”

面对交织在一起的“正向实体包含”、“负向词汇排除”、“全局字数统计”和“结尾标点/句式”约束，小模型往往顾此失彼：能够写出包含叶绿体的段落，却很难在不触发违禁词的前提下精确收敛字数。随着模型参数量和训练算力增加，模型对长程条件与多重约束的联合满足率会显著跃升。

## 成因假说一：多步子能力协同（相变假说）

支持“涌现是模型能力客观质变”的研究者，通常从复杂任务的多步串联机制进行解释。

### 复合任务的串联乘积模型
复杂逻辑任务很少由单一动作完成，而是由 $k$ 个环环相扣的子步骤串联而成。以解答应用题为例，模型需要依次完成：
1. 题干实体与已知数值提取；
2. 数量关系与操作符识别；
3. 执行具体算术推导；
4. 按照要求格式拼接最终答案。

我们构建一个**教学简化算例**：假设完成任务需要 $k=5$ 个步骤，为直观展示放大效应，假定各步骤在理想条件下相互独立且成功率均为 $p$（注意：真实模型各步骤存在上下文依赖与误差传播，此处仅作原理示意），则端到端任务全对的概率为：
$$P_{\text{task}} = p^k = p^5$$

我们对比单步概率 $p$ 线性增长时，整任务通过率 $P_{\text{task}}$ 的变化：

| 模型规模（示意） | 单步成功率 $p$ | 5步串联成功率 $P = p^5$ | 连续表现感知 | 离散指标感知（0-1 匹配） |
| :--- | :--- | :--- | :--- | :--- |
| 1B 级 | 0.20 | 0.00032 (0.03%) | 较弱 | 几乎全错（表现为无能力） |
| 7B 级 | 0.50 | 0.03125 (3.1%) | 中等 | 偶有做对（仍接近无能力） |
| 13B 级 | 0.70 | 0.16807 (16.8%) | 良好 | 刚刚起步 |
| 70B 级 | 0.90 | 0.59049 (59.0%) | 优秀 | **突然爆发，视觉上陡峭拉升** |

在这个简化算例中，模型的底层单步能力 $p$ 随着规模扩大其实是平稳递增的（从 0.2 逐步提高到 0.9），并没有突然跳变。但因为复合任务要求每一步都必须正确，乘积效应使端到端全对率在 $p < 0.7$ 之前长期被压缩在接近 0 的区间，当 $p$ 跨入 0.8~0.9 时才迅速抬头。在只看最终结果对错的外部测试中，这种数学上的乘方效应便直观地表现为“涌现”。

## 成因假说二：评估指标非线性带来的测量表象（Schaeffer 等研究）

2023 年，斯坦福大学学者 Rylan Schaeffer、Brando Miranda 与 Sanmi Koyejo 在 NeurIPS 发表论文《Are Emergent Abilities of Large Language Models a Mirage?》，对涌现现象的本质提出了有力质疑。

### 核心论点：度量尺度的选择扭曲了能力的真实演变
Schaeffer 等人指出，文献中大部分被归类为“具有涌现能力”的任务，其所采用的评测指标均具备**非线性（Nonlinear）**甚至**离散阶跃（Discontinuous）**的特点：
- **精确匹配率（Exact Match, EM）**：答案必须每个字符完全一致才得 1 分，错一个标点或数字即为 0 分；
- **多选题准确率（Multiple-Choice Accuracy）**：仅当正确选项的预测概率高居首位（Argmax 命中）时才算正确。

设一个目标回答由 $L$ 个连续 Token 组成。在简化分析中假定模型对各 Token 的预测相互独立且单字命中率为 $r$（真实自回归生成中为逐步条件概率连乘）：
- **使用非线性离散指标（0-1 全对率）**：整段全部命中的概率正比于 $r^L$。随着模型参数增加，即使底层单 Token 准确率 $r$ 随规模平稳线性上升，只要输出长度 $L$ 稍大，$r^L$ 曲线就必然呈现“前段接近零、后段突然陡峭”的阶跃形态；
- **使用平滑连续指标**（如词元级编辑距离、目标 Token 的交叉熵损失、真实分布的 Brier 分数）：指标直接反映 $r$ 的变化，曲线平稳递增。

### 实验证据：更换度量，跃迁消失
研究团队对 BIG-bench 中此前被视为典型涌现任务（如模块求和、多步加法、符号操作）的模型原始输出进行了重新评估。在不改变模型任何预测结果的前提下，仅将评测函数由“非线性 0-1 准确率”替换为“词元编辑距离”或“正确答案的对数似然”：

结果显示，原先在准确率坐标轴上呈“L 型折线、在特定规模突然起飞”的涌现曲线，全部转变成了**随模型参数量和计算预算对数平滑增长的连续曲线**。

**结论启示**：这一研究证明，许多所谓的能力突变，并不是模型内部突然发生未知质变，而是评价标尺的非线性截断把连续的渐进积累放大了成视觉上的断崖跳跃。但这并不否定大模型在实际应用中的综合实用价值——无论是否为度量假象，大模型确实在端到端任务上达到了可用门槛。

## Scaling Law 的启示：平滑的损失与阶跃的下游任务

讨论涌现必须联系扩展定律（Scaling Law）。OpenAI（Kaplan 等，2020）与 DeepMind（Chinchilla，Hoffmann 等，2022）的研究表明：

语言模型在预训练验证集上的**交叉熵损失（Cross-Entropy Loss）**，与模型参数量 $N$、训练数据量 $D$ 和总计算量 $C$ 之间遵循平滑且可高度预测的幂律规律：
$$L(N, D) \approx \left(\frac{N_c}{N}\right)^{\alpha_N} + \left(\frac{D_c}{D}\right)^{\alpha_D} + L_0$$

在跨越几个数量级的计算开销范围内，损失值的下降轨迹极其规律。

然而，下游的具体工程任务（如写出完全无 Bug 的 Python 代码、解出几何题）却展现出难以预测的阶跃性：

```text
底层演进：
Compute / Data / Params (对数坐标) ──> 预训练 Cross-Entropy Loss (平滑幂律下降，高可预测)
                                       │
                                       ▼ 任务要求 100% 格式对齐与多步全对
表层呈现：
具体应用任务 (GSM8K/代码通过率/问答) ──> 0-1 离散任务成功率 (在特定临界点跳跃，难以外推)
```

这就造成了大模型研发中的核心难题：我们能通过几百兆小模型的训练平稳外推百亿大模型最终的验证集 Loss，却**无法直接根据 Loss 外推模型在某项具体下游任务上的性能跃升临界点**。

## 面试高频追问与机制解析

### 追问 1：思维链（CoT）为什么能提升多步推理准确率？

在回答该问题时，应从 Transformer 的前向传播机制给出原理解释，避免仅用“它让模型模仿人类一步一步思考”等拟人化表述。

**机制原理解析**：
1. **自回归架构下的有效计算步数扩展**：
   标准 Transformer 在预测单个 Token 时，其前向计算预算（网络深度、层数与浮点运算量）是完全固定的。如果不使用 CoT，直接要求模型根据题干输出最终答案，模型必须在固定深度的单次前向传递中完成从语义理解到符号推导的全部操作，计算深度严重受限。
   引入 CoT 后，模型生成了 $M$ 个推导 Token，相当于将该问题的推理过程扩展为了 $M$ 次自回归解码循环。模型利用显式文本将前序推导状态外显化存储在 [KV Cache](/interview/llm-interview/kv-cache.md) 中，大幅扩展了针对该问题的实际计算步骤。
2. **注意力机制的上下文约束收敛**：
   自回归解码预测第 $t$ 个 Token 时，其自注意力完全依赖于前序上下文。每生成一步正确的中间公式或分析，就为下一步的预测引入了更明确的局部条件依赖，减少了直接跨步推断时的注意力分散与自由胡编（幻觉）。

![CoT 机制与自回归计算预算展开](/images/content-rebuild/d2e54cd6349a5c91/fig-5.png)

### 追问 2：模型显式输出的推理过程是真实的决策逻辑吗？

这是考察大模型可解释性前沿认知的进阶问题。

**核心结论：外显推理文本存在“事后合理化（Post-hoc Rationalization）”与“不忠实性（Unfaithfulness）”。**
- **因果干预实验**：研究（如 Lanham 等，2023）发现，如果在 CoT 推理链中人为修改或破坏某些中间步骤，模型在很多时候仍然会输出原先预定的答案；这表明部分决策早在底层的隐层状态中就已形成，中间的推导文本只是模型在语言学概率上生成的一段“看似合理的解题说明”。
- **迎合偏见现象**：如果在 Prompt 中隐蔽加入引导性暗示（例如“我认为答案是选项 B”），模型在生成 CoT 时会编造看似严丝合缝但逻辑断层的推导链条来强行证明该选项正确。这说明 CoT 是自回归生成的文本表征，不能简单等同于模型内部严格因果绑定的推理执行图。

### 追问 3：只要无限增加模型参数，所有能力都会发生涌现吗？

必须明确给出否定答案，并列举技术边界：
1. **数据分布与环境反馈边界**：纯自回归模型只能拟合训练集所覆盖的分布规律。如果任务需要模型未曾见过的领域知识，或者需要外部环境的强动态交互（如物理世界的具身机器人操作），单纯堆叠参数无法凭空生成信息。
2. **理论计算复杂度瓶颈**：标准 Transformer 的自注意力机制在理论上存在计算复杂度限制（如在固定深度下对特定图连通性或动态规划问题的表达能力受限）。在不结合外部执行环境、动态工作记忆或代码解释器的情况下，无法仅靠堆参数解决图灵完备层面的无限递归推理。
3. **训练与调优稳定性制约**：随着参数规模指数级放大，训练过程中的损失尖刺（Loss Spike）、梯度爆炸与数据耗尽问题成为现实阻碍，无法支持无休止的规模扩张。

## 常见认知误区与避坑指南

| 常见错误说法 | 事实依据与纠偏说明 |
| :--- | :--- |
| “涌现意味着大模型拥有了像人一样的顿悟与意识。” | 涌现属于复杂统计系统在规模放大时的概率分布演进，本质是参数对语言规律更密集的建模，不能拟人化为主观意识。 |
| “Schaeffer 的论文证明了大模型涌现完全不存在，纯粹是骗局。” | 该研究的核心发现是**非线性离散度量放大了能力的阶跃感**，证明能力演变在底层更偏平滑，但并未否认大模型在复杂任务中达到实用可用水平的事实。 |
| “CoT 之所以有效，是因为模型内部学会了严密的逻辑推理规则。” | CoT 的本质是通过生成中间 Token 增加了前向自回归的计算迭代步数，并通过生成的文字提供了更强的局部注意力线索。推导过程存在不忠实性。 |
| “小模型绝对无法具备上下文学习或指令遵循能力。” | 并非绝对。经过针对性蒸馏、高质量任务合成数据微调后，数 B 参数级别的小模型在垂直任务中同样能展现出良好的少量样本适应能力。 |
