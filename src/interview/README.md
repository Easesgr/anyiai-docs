# AI经典面试题

![](/images/interview/interview_cover.png)

精选 AI 岗位高频面试问题，覆盖大模型、Prompt、RAG、Agent、系统设计等核心方向。

面试不是背八股文，而是理解底层原理。每篇文章围绕一个具体问题展开，讲清楚"是什么、为什么、怎么做"，让你面试时能自信地回答，而不是机械地复述。
