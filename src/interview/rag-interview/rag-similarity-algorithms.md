在检索增强生成（RAG）系统中，文本通过嵌入模型（Embedding Model）转换为稠密向量后，检索器需要计算用户查询（Query）向量与知识库文档切片（Chunk）向量之间的相似度。关于嵌入模型的基本机制，可参考 [/interview/rag-interview/embedding-in-rag.md](/interview/rag-interview/embedding-in-rag.md)。

面试中被问到这个题目时，考察重点主要有三层：能不能用白话讲清三种度量的几何含义；能不能推导出它们在归一化后的数学等价性；以及为什么工程上通常推荐“归一化后走点积”。

## 1. 核心口述答案

面试中遇到“余弦相似度、内积与欧氏距离有什么区别，该怎么选？”时，可以用以下三句话口述回答：

> **口述核心结论**：
> 1. **几何含义不同**：余弦相似度衡量两个向量的**夹角方向**，忽略向量长短；欧氏距离（L2）衡量空间中的**绝对直线距离**；点积（内积/IP）则是夹角余弦与两向量模长乘积的结合，同时受**方向和模长**影响。
> 2. **归一化后等价**：当向量经过 $L_2$ 归一化（模长全变为 1）后，三者在排序上**完全等价**。余弦值越大，点积就越大，欧氏距离就越小。
> 3. **工程选型建议**：常规文本检索首选**向量归一化 + 点积（IP）**。因为归一化保留了余弦的方向语义，而点积只需要乘加运算，可以充分利用 CPU/GPU 的向量化指令（如 FMA），避开在线开方和除法的高延迟。

## 2. 贯穿示例：短查询与长文档的模长差异

为了看清三种度量在实际检索中的区别，我们来看一个贯穿全文的具体例子。

用户输入一个短查询：
* **Query（短文本）**：“退货退款操作流程”

知识库中有两个候选文档切片：
* **切片 A（短文本）**：“退货退款流程说明”
* **切片 B（长文本）**：“退货退款流程说明：买家在订单详情页提交退款申请，商家需在48小时内审核；商家同意后顺丰上门取件，仓库签收质检无误后系统自动原路退款……”

假定嵌入模型对这两段文本编码。因为切片 A 和切片 B 的核心语义都与 Query 高度重合，它们在语义空间中的**方向几乎一致**（夹角接近 0 度）。但由于长文本包含更多词元，若模型采用未按长度做均值化的求和池化（Sum Pooling），或输出模长未作平抑约束，切片 B 的特征向量模长可能会显著大于切片 A 和 Query。

此时三种算法会给出截然不同的反应：
* **余弦相似度**：由于消除了长度影响，切片 A 和切片 B 与 Query 的相似度都接近 1.0，不会因为切片 B 句子长而被误判为不相关。
* **未归一化的欧氏距离**：切片 B 由于向量模长很长，在几何空间中离 Query 端点的直线距离被大幅拉远，可能导致欧氏距离偏大而被漏召回。
* **未归一化的点积**：切片 B 的长模长直接放大了点积得分，可能掩盖夹角带来的细微偏差，获得超高分数。

## 3. 三种度量算法的计算原理与适用边界

设查询向量为 $\mathbf{u} = [u_1, u_2, \dots, u_d]$，候选切片向量为 $\mathbf{v} = [v_1, v_2, \dots, v_d]$，维度为 $d$。

### 3.1 余弦相似度（Cosine Similarity）

余弦相似度衡量两个向量夹角 $\theta$ 的余弦值：

$$S_{\text{cos}}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \frac{\sum_{i=1}^d u_i v_i}{\sqrt{\sum_{i=1}^d u_i^2} \sqrt{\sum_{i=1}^d v_i^2}}$$

* **数值区间**：$[-1, 1]$。值为 1 表示完全同向，0 表示正交（无关联），-1 表示完全反向。
* **向量数据库余弦距离**：通常定义为 $D_{\text{cos}} = 1 - S_{\text{cos}}$，取值范围在 $[0, 2]$ 之间。
* **特点与适用场景**：通过分母的模长乘积抵消了绝对长度，专门关注语义特征的方向一致性。非常适合长短不一的自然语言检索场景。更多语义空间表征细节可参考 [/fundamentals/embedding/embedding-similarity.md](/fundamentals/embedding/embedding-similarity.md)。

![余弦相似度的尺度无关性](/images/content-rebuild/386433cb3082eefc/fig-2.png)

> **边界提醒：余弦距离不是严格的数学度量**
> 严格意义上的距离度量必须满足三角不等式（即 $D(A, C) \le D(A, B) + D(B, C)$）。但余弦距离 $D_{\text{cos}} = 1 - \cos\theta$ 不满足三角不等式。如果构建 VP-Tree、BK-Tree 这类强依赖三角不等式剪枝的索引，直接使用余弦距离可能导致剪枝错误；而 HNSW、IVF 等主流 ANN 索引不依赖三角不等式，可以正常使用。

### 3.2 点积 / 内积（Dot Product / Inner Product, IP）

点积计算两个向量对应维度的乘积和：

$$S_{\text{IP}}(\mathbf{u}, \mathbf{v}) = \mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^d u_i v_i = \|\mathbf{u}\|_2 \|\mathbf{v}\|_2 \cos\theta$$

* **数值区间**：$(-\infty, +\infty)$。
* **特点**：点积是投影长度与模长的乘积。如果两个向量夹角固定，任意一个向量的模长变大，点积都会按比例放大。
* **适用场景**：
  1. **已归一化向量**：若模长固定为 1，点积在数值上直接等于余弦相似度。
  2. **模长自带先验权重**：部分非对称问答模型或多向量模型（如 ColBERT 中的后期交互），模型训练时特意让高频核心词、权威文档拥有更大的模长。此时模长本身代表重要程度，不能随意消除。

![点积结合模长与方向的物理含义](/images/content-rebuild/386433cb3082eefc/fig-3.png)

### 3.3 欧氏距离（Euclidean Distance / L2 Distance）

欧氏距离是空间中两点之间的直线几何距离：

$$D_{\text{L2}}(\mathbf{u}, \mathbf{v}) = \|\mathbf{u} - \mathbf{v}\|_2 = \sqrt{\sum_{i=1}^d (u_i - v_i)^2}$$

* **数值区间**：$[0, +\infty)$。值越小说明两者越接近。
* **特点**：极度受坐标绝对尺度的影响。如果向量维度非常高且未做归一化，由于各维度差值的平方累加，距离值会迅速变大，不同切片之间的距离差异容易被模长差距主导。
* **适用场景**：多模态图像/音频底层特征比对，或者坐标具有明确物理单位的场景。

## 4. 向量归一化与数学等价性推导

在很多面试中，面试官常会要求推导：“在什么条件下，余弦相似度、点积和欧氏距离的检索排序结果完全一样？”

核心前置条件只有一个：**所有向量均完成 $L_2$ 归一化**。

### 4.1 数学推导过程

**前置假设**：向量 $\mathbf{u}$ 与 $\mathbf{v}$ 的 $L_2$ 范数均为 1：
$$\|\mathbf{u}\|_2 = 1, \quad \|\mathbf{v}\|_2 = 1$$

展开欧氏距离的平方：
$$
\begin{aligned}
D_{\text{L2}}^2(\mathbf{u}, \mathbf{v}) &= \|\mathbf{u} - \mathbf{v}\|_2^2 \\
&= (\mathbf{u} - \mathbf{v})^\top (\mathbf{u} - \mathbf{v}) \\
&= \mathbf{u}^\top \mathbf{u} - 2 \mathbf{u}^\top \mathbf{v} + \mathbf{v}^\top \mathbf{v} \\
&= \|\mathbf{u}\|_2^2 + \|\mathbf{v}\|_2^2 - 2 (\mathbf{u} \cdot \mathbf{v})
\end{aligned}
$$

代入条件 $\|\mathbf{u}\|_2^2 = 1$ 和 $\|\mathbf{v}\|_2^2 = 1$：
$$D_{\text{L2}}^2(\mathbf{u}, \mathbf{v}) = 1 + 1 - 2 (\mathbf{u} \cdot \mathbf{v}) = 2 - 2 (\mathbf{u} \cdot \mathbf{v})$$

又因为向量模长为 1，由内积和余弦定义可知：
$$\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|_2 \|\mathbf{v}\|_2 \cos\theta = 1 \times 1 \times \cos\theta = S_{\text{cos}}(\mathbf{u}, \mathbf{v})$$

两边开根号，得到精确的换算公式：
$$D_{\text{L2}}(\mathbf{u}, \mathbf{v}) = \sqrt{2 - 2 S_{\text{IP}}(\mathbf{u}, \mathbf{v})} = \sqrt{2(1 - S_{\text{cos}}(\mathbf{u}, \mathbf{v}))}$$

![单位超球面上的等价性数学推导](/images/content-rebuild/386433cb3082eefc/fig-4.png)

### 4.2 单调性与排序结论

观察函数 $D_{\text{L2}} = \sqrt{2(1 - S_{\text{cos}})}$：
* 当 $S_{\text{cos}}$ 从 -1 增大到 1 时，$1 - S_{\text{cos}}$ 从 2 减小到 0，平方根函数在其定义域内是严格单调递减的。
* 这意味着：**余弦相似度越大 $\Longleftrightarrow$ 点积越大 $\Longleftrightarrow$ 欧氏距离越小**。

$$\arg\max_{\mathbf{v}} S_{\text{cos}}(\mathbf{u}, \mathbf{v}) = \arg\max_{\mathbf{v}} S_{\text{IP}}(\mathbf{u}, \mathbf{v}) = \arg\min_{\mathbf{v}} D_{\text{L2}}(\mathbf{u}, \mathbf{v})$$

**结论**：在 $L_2$ 归一化前提下，针对同一个 Query 向量，按余弦最大、点积最大或欧氏距离最小挑出来的 Top-K 结果是**完全一致**的。

### 4.3 二维数据算例验证

以具体的二维向量为例进行数值计算：
* 查询向量 $\mathbf{u} = [1, \sqrt{3}]$，模长 $\|\mathbf{u}\|_2 = \sqrt{1^2 + (\sqrt{3})^2} = 2$
* 候选向量 $\mathbf{v} = [0, 2]$，模长 $\|\mathbf{v}\|_2 = \sqrt{0^2 + 2^2} = 2$

**第一步：未归一化时的计算**
1. 点积：$S_{\text{IP}} = 1 \times 0 + \sqrt{3} \times 2 = 2\sqrt{3} \approx 3.4641$
2. 余弦：$S_{\text{cos}} = \frac{2\sqrt{3}}{2 \times 2} = \frac{\sqrt{3}}{2} \approx 0.8660$
3. 欧氏距离：$D_{\text{L2}} = \sqrt{(1 - 0)^2 + (\sqrt{3} - 2)^2} = \sqrt{1 + (3 - 4\sqrt{3} + 4)} = \sqrt{8 - 4\sqrt{3}} \approx 1.0353$

**第二步：进行 $L_2$ 归一化**
* 归一化后 $\mathbf{\hat{u}} = [\frac{1}{2}, \frac{\sqrt{3}}{2}] = [0.5, 0.8660]$
* 归一化后 $\mathbf{\hat{v}} = [0, 1]$

**第三步：归一化后的重新计算**
1. 点积：$S_{\text{IP}} = 0.5 \times 0 + \frac{\sqrt{3}}{2} \times 1 = \frac{\sqrt{3}}{2} \approx 0.8660$
2. 余弦：分母模长乘积为 1，余弦值依然是 $\frac{\sqrt{3}}{2} \approx 0.8660$
3. 欧氏距离：
   $$D_{\text{L2}} = \sqrt{(0.5 - 0)^2 + (\frac{\sqrt{3}}{2} - 1)^2} = \sqrt{0.25 + (0.75 - \sqrt{3} + 1)} = \sqrt{2 - \sqrt{3}} \approx 0.5176$$

代入推导公式校验：
$$D_{\text{L2}} = \sqrt{2(1 - S_{\text{cos}})} = \sqrt{2(1 - \frac{\sqrt{3}}{2})} = \sqrt{2 - \sqrt{3}} \approx 0.5176$$
推导公式与直接计算完全一致。

## 5. 工程选型：为什么向量库推崇“归一化 + 点积”？

既然归一化后三种算法选出来的 Top-K 结果一模一样，为什么在工业级实践中，主流建议普遍是**在入库和查询前统一做归一化，底层检索度量直接选点积（IP）**？

这主要取决于底层算力与硬件指令集的工作模式。

![离线归一化在线检索计算加速流水线](/images/content-rebuild/386433cb3082eefc/fig-5.png)

### 5.1 算力开销差异

假设向量维度为 $d$：
* **未归一化的余弦计算**：
  * 计算分子：$d$ 次浮点乘累加；
  * 计算分母：各自计算模长平方（$2d$ 次乘累加），再执行 2 次开方（`FSQRT`），再执行 1 次乘法与 1 次除法（`FDIV`）。
* **预归一化后的点积计算**：
  * 仅需 $d$ 次浮点乘累加。

现代 CPU（x86 AVX2/AVX-512、ARM NEON）和 GPU 提供了高效的**融合乘加（FMA）**向量化指令，可以在单个时钟周期完成乘累加。相反，浮点开方和浮点除法属于耗时较长的长延迟指令。在高并发检索中，如果每次比较都要执行开方除法，吞吐量会明显下降。

### 5.2 向量库内部如何处理 Cosine？

在很多现代向量数据库（例如 Qdrant 或 Milvus）中，如果你将索引度量直接设置为 `Cosine`，向量库通常会在写入向量时**在底层隐式完成归一化**，然后在底层的图跳转和相似度比对时退化为内积计算。

即便如此，工程上依然建议显式完成归一化：
1. **入库阶段（离线）**：Chunk 向量生成后立即在客户端或写入服务内归一化，入库全部为单位向量。
2. **查询阶段（在线）**：用户 Query 生成向量后，仅对单个 Query 向量归一化一次（耗时不到 1 微秒）。
3. **检索匹配**：全链路均使用纯内积（IP）计算，跨平台（自研向量检索、嵌入式 SQLite-vss、外部向量库）的行为和打分完全一致。

向量数据库整体定位与选型考量，可进一步阅读 [/interview/rag-interview/vector-database.md](/interview/rag-interview/vector-database.md)。

## 6. 决策矩阵与面试高频追问

![向量度量函数工程选型决策矩阵与检查清单](/images/content-rebuild/386433cb3082eefc/fig-6.png)

### 选型速查表

| 模型与业务场景 | 建议向量库 Metric | 数据前置处理 | 选型原因 |
| :--- | :--- | :--- | :--- |
| **现代稠密嵌入模型**<br>(如 OpenAI text-embedding-3, BGE 系列) | **Dot Product (IP)** | 离线写入与在线 Query 均显式 $L_2$ 归一化 | 多数模型官方输出已归一化，或基于余弦损失训练。归一化+IP 既保持余弦方向语义，又最大化利用硬件 FMA 吞吐。 |
| **直接使用余弦的向量库**<br>(如 Qdrant `Cosine`, pgvector `<=>`) | **Cosine** | 保持原始向量即可 | 向量库底层通常会在写入或索引时隐式归一化；适合不想在业务代码维护归一化逻辑的小规模系统。 |
| **非对称检索 / 模长带权模型**<br>(训练目标直接为点积，未做归一化) | **Dot Product (IP)** | **禁止**手动归一化 | 模长承载了核心实体的先验重要度或置信度，强行归一化会抹除这部分有效特征。 |
| **物理特征空间度量**<br>(图像低层特征、音频频谱、绝对物理量) | **Euclidean (L2)** | 不要求归一化 | 坐标轴上的绝对数值差有明确物理意义，需要直接比对绝对几何距离。 |

### 面试高频追问与避坑回答

*   **追问 1：既然归一化后单调等价，我可以在建 HNSW 索引时配置 L2，在线查询时改用点积得分排序吗？**
    *   **避坑回答**：不能混用。虽然最终结果等价，但得分方向是相反的（L2 越小越相似，点积越大越相似）。HNSW 在构图和贪心搜索时，依赖度量函数判断“哪个邻居离目标更近”。如果混用度量标准，会导致图检索的贪心跳转方向彻底混乱，大幅降低召回率。
*   **追问 2：为什么两个语义非常接近的长短句子，余弦相似度很高，但未归一化的欧氏距离却很大？**
    *   **避坑回答**：因为两者的模长差异太大。设两向量完全共线（$\cos\theta = 1$），模长分别为 $r_1$ 和 $r_2$，此时欧氏距离退化为绝对差值 $|r_1 - r_2|$。短句向量和长句向量可能因为词数累积或特征尺度未受约束导致模长相差悬殊，未归一化前，欧氏距离被模长差值支配，掩盖了夹角方向的相似性。
*   **追问 3：归一化会不会损失向量的有效信息？**
    *   **避坑回答**：取决于模型如何训练。绝大多数文本嵌入模型（如 BGE、OpenAI 系列）在训练阶段都采用余弦对比损失（Cosine Contrastive Loss），特征信息完全编码在向量方向（高维超球面的相对角位置）中，模长通常只是副产物，归一化不会丢失语义信息。只有当模型显式利用模长表达先验权重（如特定召回双塔模型或多向量模型）时，归一化才会丢失信息。
