安逸Ai 是一套面向学习者的 AI 知识与工程实践文档站，内容涵盖理论基础、大模型应用、面试题解与前沿专题。技术文档在持续迭代中，难免出现笔误、链接失效或描述不够准确的情况。欢迎读者参与勘误与补充，共同维护文档的准确性。

## 接受的反馈类型

主要欢迎以下几类具体的改进建议：

1. **文字与排版勘误**：错别字、标点错误、公式格式错位、代码缩进异常或语法报错。
2. **链接与引用修复**：文内页面跳转断链、第三方官方文档迁移导致的失效外链（404）。
3. **事实与机制订正**：模型版本更新、库接口变动、参数默认值调整等带来的陈旧描述。
4. **表达清晰度优化**：部分原理解释存在歧义或跳步时，提供更易理解的文字表述。

## 反馈与提交方式

读者可通过以下两种方式提交反馈：

### 途径一：通过 GitHub 提交

文档站源码托管于 GitHub：[anyiai-docs](https://github.com/Easesgr/anyiai-docs)。

- **提交 Issue**：若发现错误但不便直接修改文件，可在仓库直接新建 Issue。请注明出错文章的标题或页面路径（例如 [AI 基础](/fundamentals/) 下的对应文章），附上原句、修改建议以及必要的官方文档依据。
- **提交 Pull Request**：
  1. Fork [anyiai-docs](https://github.com/Easesgr/anyiai-docs) 仓库。
  2. 定位到待修改的 Markdown 文档并完成修改。
  3. 提交 PR 并简要说明修改原因与上下文。

### 途径二：公众号留言

如果不使用 GitHub，可在微信公众号搜索 **安逸Ai** 发送留言。留言时请写清文章名、段落位置及订正建议，作者会定期查看并同步到站点。

## 编写与修改建议

为保持全站内容连贯统一，建议在修改时注意：

- **准确可查**：涉及工具与 API 行为时注明适用前提，不引用未经核实的虚构接口。
- **语言自然**：用具体对象与操作陈述事实，不堆砌营销术语与空泛概念。
- **贴合栏目定位**：内容增补请参考现有规划，如 [大模型 100 讲](/llm-100/) 或 [前沿专题](/frontier/) 的既有主题脉络。

感谢每一位协助改进文档的读者。
