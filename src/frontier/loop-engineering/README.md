# Loop Engineering

> 让 Agent 一轮一轮走向交付，而不是停在一次回答里。

Loop Engineering 是围绕 Agent 设计可持续运行的反馈循环。它解决的不是"单轮 Prompt 怎么写"，而是"多轮之间怎么推进"——有目标、有验证、有退出条件的闭环执行。
