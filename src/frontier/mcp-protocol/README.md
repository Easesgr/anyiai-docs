# MCP 协议

> MCP（Model Context Protocol）是 Anthropic 在 2024 年 11 月开源的开放协议，为 AI 模型与外部工具之间定义了统一的接口标准。本合集从协议本质、架构设计到实战集成，帮你系统掌握 MCP。
