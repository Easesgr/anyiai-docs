# Vibe Coding 是什么？为什么说它改变了普通人写软件的方式？

## 开篇

这道题考的是 **Vibe Coding** 的核心概念和它对编程门槛的影响。简单说：Vibe Coding 就是用大白话描述需求，让 AI 把代码全部写出来的编程方式。2025 年由 OpenAI 联合创始人 Andrej Karpathy 提出，它把编程从"写代码"变成了"表达需求"。这是 AI 时代的新编程范式，理解它对回答所有 AI + 编程相关的面试题都有帮助。

---

## 板块 1：Vibe Coding 是什么？

**Vibe Coding 的本质**：一种通过自然语言描述需求、由 AI 生成全部代码的编程方式。

传统编程是什么流程？你有个想法 → 花几个月学语法 → 写代码 → 调试 bug → 改bug → 再改 → 终于能跑了。Vibe Coding 呢？有想法 → 直接用中文/英文描述给 AI 听 → 代码直接出来 → 跑起来了。

你可以理解为：**请了一位能听懂人话的程序员**。你说"帮我做一个个人网页，要简约风格，有导航栏和作品展示区"，AI 帮你把 HTML、CSS、JS 全部写好。

这里要和另一个概念区分开：**Copilot**（代码补全工具）。Copilot 是"补一半"——你写一行，它帮你补下一行，本质还是你在主导代码。Vibe Coding 是"全部生成"——你只管提需求，代码全是 AI 写的，你甚至可以完全不懂代码在写什么。

## 板块 2：为什么说它改变了普通人写软件的方式？

编程门槛这件事，一直在降。

- 最早用机器语言（0和1），只有科学家会用
- 后来有汇编，稍微好一点点
- 再后来有 C、Python，写代码简单多了
- 但你还是得学语法、懂逻辑、会调试

**Vibe Coding 做了什么？它把门槛从"学会编程语法"降到了"会把自己的需求说清楚"。**

这句话怎么理解？

以前你要做一个网页，得学 HTML、学 CSS、学 JavaScript，少说几个月。现在呢？你只要能把需求描述清楚，AI 就能帮你实现。

用开车来类比：以前你想开车，得先学修车——发动机什么原理、变速箱怎么工作、油路电路怎么回事。Vibe Coding 时代呢？你直接踩油门就能开，发动机原理？不用懂。

**但注意：它消灭的是语法学习成本，不是编程思维。** 你还是得知道要做什么、怎么做，只是"怎么做"这部分 AI 帮你干了。

这个变化的意义是什么？以前软件是程序员的专属技能，现在任何有想法的人都能动手实现。文科生、设计师、产品经理——以前和代码八竿子打不着的人，现在都能做自己的网页、自动化脚本、数据管理工具。

## 板块 3：Prompt Engineering——Vibe Coding 的核心技能

既然核心变成了"描述需求"，那**提问质量直接决定输出质量**。

同样让 AI 写网页，两种描述方式效果天差地别：

- 模糊版："帮我做一个网站" → AI 随便生成，你大概率不满意，改来改去
- 精准版："做一个个人主页，简约现代风格，蓝白配色，顶部三个导航：首页、关于我、作品集，底部放联系方式" → 出来的效果八九不离十

**Prompt Engineering 就是"给 AI 写好菜谱"的能力。** 好厨师需要好菜谱，好 AI 需要好提示词。

怎么练？从小需求开始：

1. **先说清楚做什么**：功能目标要明确
2. **再说怎么做**：风格、布局、交互偏好
3. **最后检查**：让 AI 解释代码，确保逻辑是你要的

描述越具体，AI 理解越准确，结果越靠谱。这是 Vibe Coding 时代最值钱的能力——不是写代码，而是表达需求。

## 板块 4：真实案例与局限性

说个真实案例。中山大学有个文科生，完全零基础，用 Vibe Coding 三个小时完成了一个个人网页：

- 第 1 小时：描述需求，让 AI 生成页面框架
- 第 2 小时：迭代调整样式，说"导航栏太高了"、"背景色换成浅灰"
- 第 3 小时：部署上线，直接能访问

**三个小时，一个完全不懂代码的人，做出了能用的网页。**

这就是 Vibe Coding 的威力——让完全没有编程基础的人，快速把想法变成现实。

但它也有局限：

- **复杂项目**：需求一多、结构一复杂，你还是得懂架构、懂模块划分
- **安全意识**：AI 写的代码可能有漏洞，涉及到支付、用户数据的场景需要专业判断
- **性能优化**：高性能系统、游戏引擎这类场景，AI 目前还搞不定

类比一下：**会开车不代表能修车**。Vibe Coding 能让你快速出成品，但专业领域的代码安全和架构设计，还是需要专业能力。

## 面试怎么答

**基础版（能过的回答）：**

> Vibe Coding 是用自然语言描述需求、AI 生成全部代码的编程方式，由 OpenAI 联合创始人 Andrej Karpathy 于 2025 年提出。和 Copilot 的本质区别在于：Copilot 是补全代码，Vibe Coding 是全部生成。它把编程门槛从"学编程语法"降到了"会表达需求"，核心技能是 Prompt Engineering——需求描述越具体，AI 生成效果越好。适用场景包括网页、自动化脚本、原型验证，不适合高性能系统和安全关键场景。

**加分版（让面试官眼前一亮）：**

> Vibe Coding 实际上是编程范式的演进——从机器语言到汇编到高级语言，门槛一直在降，Vibe Coding 让这个趋势到了极致：用自然语言编程。更有意思的是，编程的门槛降低后，文字表达能力反而成了核心优势——能把需求描述清楚的人，比只会写代码的人更有竞争力。Karpathy 本人用 Vibe Coding 写了多个项目，效率成倍提升。我的理解是，Vibe Coding 不是让程序员失业，而是让专业程序员从"怎么写"转向"写什么"和"为什么写"。

## 一句话总结

**Vibe Coding 就是"说话就能写代码"——它消灭了语法学习成本，让任何人只要能清楚表达需求，就能做出软件。**
