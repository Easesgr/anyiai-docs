# Agent 记忆系统

> 没有记忆的 Agent 每次对话都从零开始——记不住用户偏好、忘掉之前的决策、无法积累经验。记忆系统让 Agent 拥有短期、长期和用户画像三层存储，真正具备"越用越懂你"的能力。本合集从架构到风险到设计实现，帮你系统掌握 Agent 记忆系统。
