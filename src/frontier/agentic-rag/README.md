# Agentic RAG

> 传统 RAG 只检索一次就交差，Agentic RAG 让 Agent 介入检索流程——自动改写问题、多轮检索、校验答案，显著提升复杂问题的回答质量。本合集从概念到架构到实战，帮你系统掌握 Agentic RAG。
