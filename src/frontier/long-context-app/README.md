# 长上下文应用

> 长上下文模型让 AI 能"一口气"处理超长文档，但上下文越长不代表效果越好——位置衰减、信息淹没、成本飙升都是真实痛点。本合集从模型能力到常见陷阱到文档问答设计，帮你系统掌握长上下文应用。
