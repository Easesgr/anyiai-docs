在之前的学习中，我们接触的回归和分类任务都有明确的目标标签 $y$。模型通过比较预测值和真实值的误差来调整参数。但在实际业务中，大量数据并没有现成的人工标签，或者我们正处于探索阶段，想先观察手头的数据究竟有怎样的分布。这类任务被称为**无监督学习**。

无监督学习的核心不是猜测某个特定的标签，而是通过数学准则从数据特征本身挖掘规律。最基础的两个任务是：
1. **聚类（Clustering）：** 把相似的样本归为同一组（簇），把不相似的样本分开。
2. **降维（Dimensionality Reduction）：** 在尽量保留数据主要差异的前提下，用更少的特征表示原始样本。

## 1. 聚类与降维的任务定位

为了直观理解这两种任务，我们可以设想一个具体的电商用户画像场景：我们手头有 10,000 名用户在平台上的两个行为指标——"每月登录天数"与"每月平均消费金额"。

- **聚类的动作是“划分子群”：** 空间中有 10,000 个二维坐标点。我们希望把这批用户分成若干组，例如活跃高消费组、偶尔来买日用品组、只逛不买组。这种划分不是靠预先标注，而是靠计算样本在坐标系中的几何距离。
- **降维的动作是“投影压缩”：** 如果除了这两个指标，我们还记录了用户的浏览时长、点击量、加购物车次数等 50 个维度的特征。这 50 个维度之间往往存在大量重复信息（例如浏览时长和点击量通常高度相关）。降维就是寻找一个低维方向（如一条直线或平面），把多维坐标点投影上去，用少数几个综合指标概括大部分变异。

![无监督学习任务定位：聚类分组与降维投影对比](/images/content-rebuild/41dd33753ea57ff9/fig-1.png)

两者的工作模式不同，但经常配合使用。当特征维度很高时，点与点之间的距离差异往往会被稀释，因此工程上常先用降维滤除冗余噪声，再执行聚类。

## 2. K-Means 聚类：分配与更新的交替迭代

K-Means（K均值聚类）是最常见的原型聚类算法。它的核心设定是：预先指定要把数据分为 $K$ 个簇，每个簇用一个“中心点”（均值向量，也称质心）来代表。

### 目标函数：簇内离差平方和

给定样本集合 $x_1, x_2, \dots, x_n$。假设当前分为 $K$ 个簇，第 $k$ 个簇记为 $C_k$，其中心点 $\mu_k$ 是该簇所有样本的平均值：

$$\mu_k = \frac{1}{|C_k|} \sum_{x_i \in C_k} x_i$$

K-Means 的目标是寻找一种样本划分方案，让所有样本到所属中心点的欧氏距离平方和最小。这个指标在 scikit-learn 中被称为惯性（Inertia），数学上叫簇内离差平方和（WCSS）：

$$J = \sum_{k=1}^K \sum_{x_i \in C_k} \|x_i - \mu_k\|^2$$

直接在所有可能的组合中遍历寻找全局最优解计算量极大。在实践中，标准算法（Lloyd 算法）采用坐标下降思想，通过交替执行两个步骤来逼近局部最优。

### 算法步骤

1. **初始化：** 选定 $K$ 个初始点作为中心点 $\mu_1, \dots, \mu_K$（可以随机挑选样本点，也可以用更分散的 K-Means++ 策略选取）。
2. **分配步（E步）：** 保持中心点位置不变。遍历每一个样本点，计算它与 $K$ 个中心点的欧氏距离，将样本分配给距离最近的中心点所属的簇。
3. **更新步（M步）：** 保持样本归属不变。计算每个簇内所有样本的几何算术平均值，将该平均值设为新的中心点位置。
4. **收敛检查：** 检查中心点是否还在移动。如果两次迭代间中心点的移动距离低于阈值，或者达到最大迭代次数，算法停止；否则重复步骤 2 和 3。

![K-Means迭代过程：分配步与更新步交替驱动](/images/content-rebuild/41dd33753ea57ff9/fig-2.png)

### 4 个样本的手算推演

设二维平面上有 4 个点：$x_1=(1, 1), x_2=(1, 3), x_3=(5, 5), x_4=(5, 7)$。我们设定 $K=2$。

1. **初始中心点：** 假设我们选定初始中心为 $\mu_1 = (1, 2)$，$\mu_2 = (3, 4)$。
2. **第一轮分配：**
   - 对 $x_1(1, 1)$：到 $\mu_1$ 的距离平方为 $(1-1)^2 + (1-2)^2 = 1$；到 $\mu_2$ 为 $(1-3)^2 + (1-4)^2 = 13$。距离 $\mu_1$ 更近，归入第 1 簇。
   - 对 $x_2(1, 3)$：到 $\mu_1$ 的距离平方为 $0^2 + 1^2 = 1$；到 $\mu_2$ 为 $(-2)^2 + (-1)^2 = 5$。归入第 1 簇。
   - 对 $x_3(5, 5)$：到 $\mu_1$ 的距离平方为 $4^2 + 3^2 = 25$；到 $\mu_2$ 为 $2^2 + 1^2 = 5$。归入第 2 簇。
   - 对 $x_4(5, 7)$：到 $\mu_1$ 的距离平方为 $4^2 + 5^2 = 41$；到 $\mu_2$ 为 $2^2 + 3^2 = 13$。归入第 2 簇。
3. **第一轮更新中心：**
   - 新的 $\mu_1 = \frac{(1,1) + (1,3)}{2} = (1, 2)$。
   - 新的 $\mu_2 = \frac{(5,5) + (5,7)}{2} = (5, 6)$。
4. **第二轮分配：**
   - 重新计算距离发现：$x_1, x_2$ 依然离 $(1, 2)$ 最近，$x_3, x_4$ 依然离 $(5, 6)$ 最近。样本归属没有发生任何变化，中心点不再变动，算法收敛结束。

由于每一步分配和更新都不会让目标函数 $J$ 增大，且样本的划分方式组合是有限的，算法必然会收敛。但必须注意：**它收敛到的是局部极小值，而非全局最优解**。初始点如果落在不良位置，可能导致次优结果，因此工业库通常会多次随机初始化运行并保留目标函数最小的那次。

## 3. K-Means 的几何假设与边界

K-Means 计算极其高效，但它的数学形式决定了它带有明显的几何假设：

1. **各向同性假设（偏好球形簇）：** 算法采用欧氏距离测量点到中心的距离。这相当于默认各方向的离散程度是一致的。若某类样本是细长椭圆形状，K-Means 会因追求离差平方和最小而把椭圆横向切成两段。
2. **空间划分必须是凸多边形：** 任意两个中心点之间的分界线是它们连线的垂直平分面。这导致 K-Means 划分出的区域必然是凸多面体。如果数据呈现同心圆环或月牙形等非凸形状，垂直平分线根本无法沿着弯曲边界切开它们。
3. **对量纲极度敏感：** 假设特征 A 取值在 $0 \sim 1$，特征 B 取值在 $0 \sim 10000$。计算欧氏距离时，特征 B 的数值差异会彻底掩盖特征 A。因此使用 K-Means 前，必须对数值型特征进行标准化（如标准差标准化）。

![K-Means几何假设失效对比：球形凸簇 vs 同心环流形](/images/content-rebuild/41dd33753ea57ff9/fig-3.png)

当数据呈现非凸连续形状时，通常需要考虑基于密度的算法（如 DBSCAN）或基于邻域图的方法。

## 4. PCA 主成分分析：两个等价的几何视角

主成分分析（Principal Component Analysis, PCA）是最经典的无监督线性降维算法。它的目标是：把 $d$ 维的原始特征映射到 $k$ 维（$k < d$），同时尽量少丢失信息。

对于“保留最多信息”，在统计学和几何学中有两个完全等价的表述：

### 视角一：最大化投影方差

信息论与统计学认为，如果一个特征在所有样本上的取值几乎一样（方差趋于 0），它就无法提供区分样本的信息；反之，样本在该维度上的分散程度越大（方差越大），包含的区分信息就越多。

假设中心化后的数据点为 $x_i$，我们寻找一个单位投影向量 $u$（满足 $u^T u = 1$）。样本在 $u$ 上的投影坐标为 $u^T x_i$。投影后的方差为：

$$\text{Var} = \frac{1}{n} \sum_{i=1}^n (u^T x_i)^2 = u^T \left( \frac{1}{n} \sum_{i=1}^n x_i x_i^T \right) u = u^T \Sigma u$$

其中 $\Sigma$ 是样本的协方差矩阵。最大化方差就是在约束 $\|u\|=1$ 下求 $u^T \Sigma u$ 的最大值。

### 视角二：最小化重构误差

我们把降维看成一种有损压缩：将高维点 $x_i$ 投影到低维直线后，再用直线上的投影点来近似原点。原样本点与投影点之间的欧几里得距离就是“重构误差”。

根据勾股定理，在直角三角形中：
$$(\text{原点到原样本的距离})^2 = (\text{原点到投影点的距离})^2 + (\text{投影点到原样本的距离})^2$$

因为样本点本身的模长平方和是固定的，所以：**最小化垂直残差平方和（最小化重构误差），在数学上完全等价于最大化在投影轴上的平方和（最大化投影方差）。**

![PCA降维原理：最大投影方差与最小重构误差的双重视角](/images/content-rebuild/41dd33753ea57ff9/fig-4.png)

## 5. PCA 的推导与极小手算例子

### 为什么特征向量就是最优投影方向？

利用拉格朗日乘子法求解带约束的极值问题：
$$\mathcal{L}(u, \lambda) = u^T \Sigma u - \lambda (u^T u - 1)$$

对向量 $u$ 求导并令导数为 0：
$$\frac{\partial \mathcal{L}}{\partial u} = 2 \Sigma u - 2 \lambda u = 0 \implies \Sigma u = \lambda u$$

这个式子正是线性代数中**特征值与特征向量**的标准定义：
- 投影轴向量 $u$ 必须是协方差矩阵 $\Sigma$ 的特征向量；
- 此时投影后的方差大小正是该特征向量对应的特征值 $\lambda$（因为 $u^T \Sigma u = u^T (\lambda u) = \lambda u^T u = \lambda$）。

因此，要找方差最大的第一主成分（PC1），只要取**最大特征值对应的特征向量**；要找与第一主成分正交且方差次大的第二主成分（PC2），只要取第二大特征值对应的特征向量。

### 标准计算流程

1. **零均值中心化：** 计算每个特征维度的平均值，样本矩阵减去均值 $\tilde{X} = X - \bar{X}$。若特征尺度相差过大，需先做标准化。
2. **计算协方差矩阵：** 计算 $\Sigma = \frac{1}{n-1} \tilde{X}^T \tilde{X}$。
3. **求解特征值与特征向量：** 求解 $\Sigma u = \lambda u$。
4. **排序与截断：** 将特征值从大到小排列，选取前 $k$ 个对应的单位特征向量组成变换矩阵 $W = [u_1, u_2, \dots, u_k]$。
5. **坐标投影：** 低维坐标 $Z = \tilde{X} W$。

![PCA数学推导与计算流程：中心化、协方差矩阵到特征分解](/images/content-rebuild/41dd33753ea57ff9/fig-5.png)

### 3 个样本的降维手算

我们用 3 个二维样本点验证整个流程：$x_1 = (1, 2), x_2 = (3, 3), x_3 = (5, 4)$。

1. **中心化：**
   - 均值 $\bar{x} = (\frac{1+3+5}{3}, \frac{2+3+4}{3}) = (3, 3)$。
   - 减去均值后的中心化矩阵：
     $$\tilde{X} = \begin{bmatrix} 1-3 & 2-3 \\ 3-3 & 3-3 \\ 5-3 & 4-3 \end{bmatrix} = \begin{bmatrix} -2 & -1 \\ 0 & 0 \\ 2 & 1 \end{bmatrix}$$
2. **计算样本协方差矩阵（分母采用 $n-1 = 2$）：**
   - $\Sigma_{11} = \frac{(-2)^2 + 0^2 + 2^2}{2} = 4$
   - $\Sigma_{22} = \frac{(-1)^2 + 0^2 + 1^2}{2} = 1$
   - $\Sigma_{12} = \Sigma_{21} = \frac{(-2)(-1) + 0 + 2 \times 1}{2} = 2$
   - 得协方差矩阵 $\Sigma = \begin{bmatrix} 4 & 2 \\ 2 & 1 \end{bmatrix}$。
3. **求特征值与特征向量：**
   - 解行列式 $\det(\Sigma - \lambda I) = (4-\lambda)(1-\lambda) - 4 = \lambda^2 - 5\lambda = 0$。
   - 特征值为 $\lambda_1 = 5, \lambda_2 = 0$。
   - 将 $\lambda_1 = 5$ 代入方程 $(\Sigma - 5I)u = 0$：
     $$\begin{bmatrix} -1 & 2 \\ 2 & -4 \end{bmatrix} \begin{bmatrix} u_{1} \\ u_{2} \end{bmatrix} = \begin{bmatrix} 0 \\ 0 \end{bmatrix} \implies -u_1 + 2u_2 = 0 \implies u_1 = 2u_2$$
   - 单位化后得到第一主成分方向：$u = \frac{1}{\sqrt{5}} \begin{bmatrix} 2 \\ 1 \end{bmatrix} \approx \begin{bmatrix} 0.894 \\ 0.447 \end{bmatrix}$。
4. **降至一维坐标：**
   - $z_1 = -2(0.894) + (-1)(0.447) = -2.236 = -\sqrt{5}$
   - $z_2 = 0(0.894) + 0(0.447) = 0$
   - $z_3 = 2(0.894) + 1(0.447) = 2.236 = \sqrt{5}$
   - 投影后的方差为 $\frac{(-\sqrt{5})^2 + 0^2 + (\sqrt{5})^2}{2} = 5 = \lambda_1$。
   - 因为 $\lambda_2 = 0$，说明第二特征方向上没有任何方差变异，原数据 3 个点严格落在一条斜率为 0.5 的直线上。投影到第一主成分后完整保留了全部样本变异。

## 6. 工程选型中的收益与代价

在机器学习实际流程中，降维带来便利的同时也有其代价：

```
原始高维特征
  │
  ├── [工程收益]
  │     ├─ 消除多重共线性：主成分特征向量彼此正交，消除线性相关性
  │     ├─ 缩减存储与算力：下游模型输入特征变少，减少矩阵运算时间
  │     └─ 2D/3D 可视化：便于画散点图观察样本是否存在天然聚集趋势
  │
  └── [伴随代价]
        ├─ 失去物理可解释性：新特征是原始特征的线性组合加权，难以归因
        ├─ 信号与标签脱节：方差最大的方向不一定是下游分类标签的最佳分界方向
        └─ 仅支持线性投影：无法把弯曲的流形结构在低维空间展开
```

### 核心优势
1. **正交解耦：** 实对称协方差矩阵的不同特征向量相互正交。降维后的各个主成分之间协方差为 0，这能消除输入特征间的线性多重共线性，改善[线性回归和逻辑回归](/fundamentals/ml-basics/linear-logistic-regression.md)因特征共线性带来的参数估计不稳定。
2. **计算压缩与可视化：** 将上百维的指标压缩为少数主成分，下游模型训练速度明显加快；压缩到 2 维或 3 维后，工程师可以直接通过散点图观察数据分布与异常离群点。

### 局限与陷阱
1. **特征可解释性下降：** 原始特征具有明确业务含义（如“订单数”、“页面停留秒数”），而主成分是各特征的加权和（如 $0.72 \times \text{订单数} + 0.35 \times \text{停留秒数}$）。在风控、信审等强监管可解释场景下，PCA 会给业务归因带来阻碍。
2. **最大方差不等于最佳分类特征：** PCA 属于无监督算法，它寻找的是方差最大的方向，而不是与监督任务标签 $y$ 相关性最强的方向。若区分两类用户的微弱特征恰好落在方差极小的维度上，PCA 的低方差截断会导致下游[分类评估指标](/fundamentals/ml-basics/evaluation-classification.md)下降。

## 本讲小结

无监督学习不依赖标签，核心在于依据特定的数学度量挖掘结构：
- **K-Means 聚类** 通过迭代最小化点到质心的欧氏距离平方和，适用于各向同性的球形凸簇分组；
- **PCA 降维** 通过对协方差矩阵进行特征分解，在正交方向上寻找投影方差最大的主成分，实现了线性空间中的特征压缩与解耦。

在熟悉了[数据、特征、标签](/fundamentals/ml-basics/data-features-labels.md)以及[决策树与集成学习模型](/fundamentals/ml-basics/tree-models.md)之后，理解这些无监督几何处理方法，能帮助我们在面对真实世界中杂乱无章的未标注数据时，拥有可靠的探索与预处理工具。
