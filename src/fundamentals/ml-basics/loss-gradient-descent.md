如果真实的单价是 $2.0$ 元/公里，而初始随机赋予的参数是 $w = 0.5$。当乘客坐了 $10$ 公里时，真实车费是 $20$ 元，模型却预测为 $5$ 元，预测偏低了 $15$ 元。

如何把“预测不准”整理成统一的数值指标？拿到这个指标后，又该怎样一步步把 $w$ 从 $0.5$ 调整到 $2.0$？这就是损失函数与梯度下降要解决的两个核心问题。

## 损失函数与目标函数：量化预测偏差

要调整参数，先要有一把度量误差的标尺。在机器学习中，通常区分单样本与全数据集两个统计层级：

1. **单样本损失函数（Loss Function）**：记作 $L(\hat{y}^{(i)}, y^{(i)})$，用来计算单个样本 $i$ 上的预测值 $\hat{y}^{(i)}$ 与真实标签 $y^{(i)}$ 之间的差距。当预测完全吻合时，损失达到最低。
2. **经验风险/目标函数（Cost/Objective Function）**：记作 $J(w)$，指模型在整个数据集（包含 $N$ 个样本）上的平均损失：

$$J(w) = \frac{1}{N} \sum_{i=1}^N L(f(x^{(i)}; w), y^{(i)})$$

优化的目标，就是寻找一组参数 $w^*$，让整个数据集上的平均损失最小：$w^* = \arg\min_w J(w)$。

![损失函数计算流向图：展示从单样本真实值与预测值的误差度量，到全数据集聚合为经验风险的闭环](/images/content-rebuild/e0c5e44ce0e1782f/fig-1.png)

### 为什么评估指标不能直接当作损失函数？

初学者容易把**评估指标（如准确率 Accuracy）**与**损失函数（Loss）**混为一谈。分类准确率的计算依赖阈值判定（如大于 0.5 判为正类）。在参数微调时，只要没有样本跨过 0.5 的阈值，分类对错的总数就不会改变，此时准确率对参数的导数处处为 0（阶梯状不连续函数）。导数为 0 意味着算法无法得知参数该往哪个方向修正。因此，用于梯度更新的损失函数必须是**连续且几乎处处可微**的函数。

## 常用损失函数：均方误差与交叉熵

不同任务的输出形式不同，对应的损失函数也来自不同的概率假设。

### 1. 回归任务：均方误差（Mean Squared Error, MSE）

对于连续数值预测（如房价、温度、车费），常用均方误差。单样本的二次损失为：

$$L_{MSE}(\hat{y}, y) = \frac{1}{2}(\hat{y} - y)^2$$

公式前面的系数 $\frac{1}{2}$ 是为了求导时消去平方项落下的常数 2。全数据集上的目标函数为：

$$J_{MSE}(w) = \frac{1}{2N} \sum_{i=1}^N (f(x^{(i)}; w) - y^{(i)})^2$$

**概率视角**：如果假设真实标签 $y$ 与模型预测值 $f(x; w)$ 之间存在符合独立同分布的高斯噪声 $\epsilon \sim \mathcal{N}(0, \sigma^2)$，即 $y = f(x; w) + \epsilon$，写出样本的似然函数并取负对数后，最大化似然概率在数学上就等价于最小化均方误差。由于误差被取了平方，MSE 会大幅放大较大误差的惩罚权重，因而对异常离群值较为敏感。在[回归模型评估](/fundamentals/ml-basics/evaluation-regression.md)中会进一步分析其与绝对误差（MAE）的鲁棒性差异。

### 2. 分类任务：交叉熵损失（Cross-Entropy Loss）

在二分类任务中，$y \in \{0, 1\}$，模型经过 Sigmoid 激活函数输出样本属于正类的预测概率 $\hat{y} = P(y=1|x) \in (0, 1)$。样本标签服从伯努利分布：

$$P(y|x) = \hat{y}^y (1 - \hat{y})^{1-y}$$

对其取负对数似然，得到二元交叉熵损失（Binary Cross-Entropy, BCE）：

$$L_{BCE}(\hat{y}, y) = - \left[ y \log(\hat{y}) + (1 - y) \log(1 - \hat{y}) \right]$$

当真实类别 $y = 1$ 时，损失简化为 $-\log(\hat{y})$：若预测值 $\hat{y}$ 接近 1，损失趋向 0；若预测值 $\hat{y}$ 接近 0（模型极度自信却判断完全错误），损失将趋向正无穷大。多分类任务则推广为多分类交叉熵，在[分类模型评估](/fundamentals/ml-basics/evaluation-classification.md)中有详细推导。

![均方误差与交叉熵损失在误差增大时的惩罚斜率对比](/images/content-rebuild/e0c5e44ce0e1782f/fig-2.png)

### 为什么分类问题不建议直接用 MSE？

如果将 MSE 直接套用在输出经 Sigmoid 映射的分类模型中：$L = \frac{1}{2}(\sigma(z) - y)^2$。由于 Sigmoid 函数的导数为 $\sigma'(z) = \sigma(z)(1 - \sigma(z)) = \hat{y}(1 - \hat{y})$，利用链式法则对线性输入权重 $w$ 求偏导：

$$\frac{\partial L}{\partial w} = (\hat{y} - y) \cdot \hat{y}(1 - \hat{y}) \cdot x$$

当模型预测错得很离谱时（例如真实标签 $y = 1$，模型预测 $\hat{y} = 0.001$），$\hat{y}(1 - \hat{y})$ 会接近 0。这导致求出的梯度几乎为 0（即梯度饱和/梯度消失），参数即使出现巨大偏差也难以自我修正。

而改用交叉熵损失后，对权重 $w$ 求导的结果为：

$$\frac{\partial L_{BCE}}{\partial w} = (\hat{y} - y)x$$

分母项直接抵消了 Sigmoid 的饱和导数，更新幅度直接正比于预测误差 $(\hat{y} - y)$：预测偏差越大，推动更新的梯度就越大。有关 Sigmoid 与线性的详细结合，请参阅[线性回归和逻辑回归](/fundamentals/ml-basics/linear-logistic-regression.md)。

## 梯度的几何意义：为什么沿负梯度方向更新？

求出损失函数后，参数更新的方向应该选在哪里？

多元函数 $J(w)$ 在当前点 $w$ 处的**梯度（Gradient）**是一个由各个参数偏导数组成的向量：

$$\nabla_w J(w) = \left[ \frac{\partial J}{\partial w_1}, \frac{\partial J}{\partial w_2}, \dots, \frac{\partial J}{\partial w_d} \right]^T$$

假设我们从当前点 $w$ 沿着某个单位方向向量 $u$（满足 $\|u\| = 1$）跨出微小的步长 $\alpha$。利用一阶多变量泰勒展开：

$$J(w + \alpha u) \approx J(w) + \alpha \nabla_w J(w)^T u$$

函数值的变化量为：

$$J(w + \alpha u) - J(w) \approx \alpha \nabla_w J(w)^T u = \alpha \|\nabla_w J(w)\| \|u\| \cos \phi$$

其中 $\phi$ 为梯度向量与步进方向 $u$ 之间的夹角。因为 $\|u\| = 1$：

1. 当 $\cos \phi = 1$（$\phi = 0^\circ$，$u$ 与梯度同向）时，函数值增长最快。**梯度是函数值上升最快的局部方向**。
2. 当 $\cos \phi = -1$（$\phi = 180^\circ$，$u$ 与梯度完全反向）时，函数值下降最快。**负梯度方向 $-\nabla_w J(w)$ 是局部下降最快的方向**。

在几何等高线图中，梯度向量始终与等高线保持正交（垂直），指向数值更高的一侧；负梯度向量则指向数值更低的一侧。

![二元参数空间等高线与负梯度向量几何指向图](/images/content-rebuild/e0c5e44ce0e1782f/fig-3.png)

## 梯度下降迭代与学习率：一维算例

沿着负梯度方向更新参数的迭代规则就是**梯度下降（Gradient Descent）**：

$$w_{t+1} = w_t - \eta \nabla_w J(w_t)$$

其中 $\eta > 0$ 称为**学习率（Learning Rate）**或步长，用来控制单步参数调整的幅度。

![不同学习率下的参数更新步长示意：对比学习率过小、合适、过大振荡与发散四种形态](/images/content-rebuild/e0c5e44ce0e1782f/fig-4.png)

### 一维二次函数逐步追踪

为了直观展示学习率如何改变收敛行为，我们以简单的一维二次函数为例：

$$J(w) = w^2$$

其导数为 $\nabla J(w) = 2w$，极小值在 $w^* = 0$ 处。代入梯度更新公式：

$$w_{t+1} = w_t - \eta (2w_t) = (1 - 2\eta)w_t$$

从初始点 $w_0$ 出发，经过 $t$ 次更新后的参数解析表达式为：

$$w_t = (1 - 2\eta)^t w_0$$

序列能否收敛到 0，取决于因数 $|1 - 2\eta|$ 的取值：

| 学习率 $\eta$ | 递推因子 $(1 - 2\eta)$ | 从 $w_0 = 10.0$ 开始的轨迹（$t=1, 2, 3$） | 运行形态说明 |
| :--- | :--- | :--- | :--- |
| **$\eta = 0.1$（偏小）** | $0.8$ | $8.0 \to 6.4 \to 5.12$ | 沿同一侧平稳单调下降，但收敛步数较多 |
| **$\eta = 0.5$（临界步长）** | $0.0$ | $0.0 \to 0.0 \to 0.0$ | 仅需一步直接精准命中极小值点 |
| **$\eta = 0.9$（偏大振荡）** | $-0.8$ | $-8.0 \to 6.4 \to -5.12$ | 在谷底两侧来回横跳，但幅度收窄，最终能收敛 |
| **$\eta = 1.0$（极限等幅振荡）** | $-1.0$ | $-10.0 \to 10.0 \to -10.0$ | 形成固定循环，在谷底两侧来回跳跃，无法靠近 0 |
| **$\eta = 1.1$（过大发散）** | $-1.2$ | $-12.0 \to 14.4 \to -17.28$ | 跳跃幅度逐级放大，数值迅速溢出（发散） |

对于局部二次曲率（二阶导数/Hessian 特征值）为 $L$ 的平滑函数，保证迭代稳定的理论条件是步长 $\eta < \frac{2}{L}$（本例中 $L=2$，因而要求 $\eta < 1$）。如果学习率过大，一阶泰勒展开的局部线性假设就会失效，导致步子迈得太大跨过了低谷，甚至在两壁越弹越高。针对大模型训练中突发的极端梯度，通常会辅以[梯度裁剪（Gradient Clipping）](/interview/llm-interview/gradient-clipping.md)来防止单步更新失控。

## 三种梯度下降变体：样本量、方差与计算效率

在实际工程中，损失函数 $J(w)$ 是 $N$ 个样本损失的均值。如何取用样本计算梯度，衍生出了三种主要的更新模式。

![批量、随机与小批量梯度下降在损失曲面上的收敛轨迹对比](/images/content-rebuild/e0c5e44ce0e1782f/fig-5.png)

### 1. 批量梯度下降（Batch Gradient Descent, BGD）

每次更新参数时，都计算全部 $N$ 个训练样本的平均梯度：

$$g_{BGD} = \frac{1}{N} \sum_{i=1}^N \nabla_w L(f(x^{(i)}; w), y^{(i)})$$

- **特点**：每次前进都严格沿着整个训练集的最优方向，轨迹平滑稳定，没有采样噪声。
- **代价**：单步计算量为 $O(N \cdot d)$。当训练样本达到数百万甚至数亿时，每迈出一步都要遍历全部数据，内存与显存通常无法承受，训练速度极其缓慢。

### 2. 随机梯度下降（Stochastic Gradient Descent, SGD）

每次只随机抽取**单个样本** $(x^{(i)}, y^{(i)})$ 计算梯度并立即更新参数：

$$g_{SGD} = \nabla_w L(f(x^{(i)}; w), y^{(i)})$$

- **特点**：单步计算代价仅为 $O(d)$，计算开销小，适合在线流式数据。
- **代价**：单个样本的梯度是全量梯度的无偏估计，但在独立样本假设下，单样本的噪声方差很高。这导致参数更新轨迹呈现剧烈锯齿状，在极值点附近容易持续跳动，难以平稳驻留。

### 3. 小批量梯度下降（Mini-batch Gradient Descent）

这是现代深度学习与工程实践的标准方案：每次抽取固定数量（Batch Size 记为 $B$，常见取值为 32、64、128 或 256）的样本计算均值梯度：

$$g_{MBGD} = \frac{1}{B} \sum_{k=1}^B \nabla_w L(f(x^{(k)}; w), y^{(k)})$$

在批次内样本相互独立的假设下，均值梯度的方差按样本量缩减：

$$\mathrm{Var}(g_{MBGD}) \approx \frac{\sigma^2}{B}$$

小批量方案兼顾了两方面需求：

1. **方差适中**：通过适度增大批次大小 $B$，有效压低了单样本噪声，使收敛路径相对平稳。
2. **硬件吞吐高效**：GPU 与专用 AI 加速芯片在执行批量的矩阵-矩阵乘法（GEMM）时，能充分利用张量单元（Tensor Cores）和数据并行流水线。如果只计算单个样本的向量运算，往往无法填满芯片算力。

| 对比维度 | 批量梯度下降 (BGD) | 随机梯度下降 (SGD) | 小批量梯度下降 (Mini-batch GD) |
| :--- | :--- | :--- | :--- |
| **单步样本量** | 全部样本 $N$ | 单个样本 $1$ | 小批次 $B$（如 32~256） |
| **单步计算量** | 很高（与 $N$ 成正比） | 极低（仅算 1 个样本） | 适中（与 $B$ 成正比） |
| **梯度方差** | 0（全量真实梯度） | 很高（单样本噪声大） | 较低（随 $\frac{1}{B}$ 衰减） |
| **硬件并行性** | 高（但受限于显存上限） | 极低（无法充分发挥 GPU 吞吐） | 很高（充分契合硬件矩阵乘法设计） |
| **更新稳定性** | 轨迹平滑，但计算较慢 | 锯齿剧烈，容易跳出浅层平坦区 | 兼顾收敛平稳度与吞吐速度 |

## 峡谷曲面与动量法：平息振荡

普通梯度下降在遇到**病态条件峡谷（Ill-conditioned Ravine）**曲面时容易遇到阻碍：曲面在横向（谷底方向）坡度极平缓，而在纵向（两侧山壁）坡度极陡峭。

![病态曲面上普通梯度下降剧烈振荡与动量法平滑穿越的动力学对比](/images/content-rebuild/e0c5e44ce0e1782f/fig-6.png)

在这种地形下：
- 陡峭方向计算出的梯度数值很大，导致参数在两侧山壁之间剧烈来回反弹；
- 平缓方向计算出的梯度数值很小，沿着谷底向前推进极其迟缓；
- 若调小学习率，山壁反弹虽被抑制，但沿谷底前进的步伐也几乎停滞。

为了改善这种现象，优化算法引入了**动量机制（Momentum）**。动量法参考物理惯性，保留历史梯度的指数加权平均值作为推进速度：

$$v_{t+1} = \beta v_t + (1 - \beta) g_t$$
$$w_{t+1} = w_t - \eta v_{t+1}$$

其中衰减系数 $\beta \in [0, 1)$ 通常设定为 0.9 左右。由于在峡谷两侧来回反弹的梯度在相邻几步中正负符号交替，加权求和后会彼此抵消；而沿峡谷底部持续向前的梯度方向稳定一致，累加后速度逐渐增大。动量法有效平抑了无意义的高频横向振荡，加速了沿平缓方向向目标靠近的过程。

在此基础上，进一步结合各参数梯度平方自适应调节步长的 Adam 等现代优化器，构成了当下大模型训练的主流基准。关于深度网络中梯度如何逐层计算并在大模型中运行，请参考[梯度下降、反向传播在大模型里如何工作？](/llm-100/training/gradient-descent-backprop.md)。

## 总结与延伸阅读

1. **损失函数定义误差大小**：连续可微的目标函数是梯度优化的前提，回归任务常用 MSE，分类任务常用交叉熵；
2. **负梯度指明下降方向**：根据一阶泰勒展开，负梯度方向是函数值局部下降最快的几何方向；
3. **学习率决定步长边界**：步长必须适应曲面的二阶曲率，过小训练迟缓，过大会导致振荡甚至发散；
4. **小批量兼顾吞吐与稳定**：Mini-batch GD 凭借适中的方差和对硬件矩阵运算的充分利用，成为深度学习的事实标准。
