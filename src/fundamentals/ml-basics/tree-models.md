在[线性回归与逻辑回归](/fundamentals/ml-basics/linear-logistic-regression.md)中，模型试图在特征空间中绘制一条直线或超平面来切分数据。但现实中的很多决策并不符合连续线性假设，而是像查阅规则手册一样的分段判定：如果申请人月收入大于 1 万元且无不良信用记录，则发放贷款，否则拒绝。

决策树通过坐标轴对齐的切分，将输入空间划分成一个个互不重叠的矩形区域。单棵树简单直观，但极易出现[过拟合与欠拟合](/fundamentals/ml-basics/overfitting-underfitting.md)中讨论的高方差问题。为了获得更稳定的预测表现，集成学习衍生出了两条核心路线：以随机森林为代表的 **Bagging**（并行构建多棵树以降低方差），以及以 GBDT 为代表的 **Boosting**（串行训练多棵树以降低偏差）。

### 一个贯穿全文的信贷审批例子

为了直观理解这三种模型的差异，我们来看一个简化版的个人信贷数据集（包含 6 位申请人）：

| 申请人 | 年龄（岁） | 月收入（万元） | 是否违约（标签 $y$） | 授信额度（万元） |
| :--- | :--- | :--- | :--- | :--- |
| A | 23 | 0.8 | 是（1） | 1.0 |
| B | 25 | 1.2 | 是（1） | 1.5 |
| C | 28 | 1.5 | 否（0） | 3.0 |
| D | 35 | 1.0 | 否（0） | 2.5 |
| E | 40 | 2.5 | 否（0） | 6.0 |
| F | 45 | 3.0 | 否（0） | 8.0 |

在这个数据集中，我们可以用分类任务预测用户是否会违约，也可以用回归任务预测用户的授信额度。

### 单棵决策树的生长：轴对齐切分与纯度准则

决策树从根节点开始，每次挑选一个特征和一个阈值，把当前节点的数据分成两个子集。到达叶节点后，分类任务输出子集中出现最多的类别，回归任务输出子集的样本均值。

因为每次只比较一个特征的大小，决策树在特征空间中画出的所有切分线都与坐标轴垂直（即轴对齐切分）。这种切分带来两个重要特点：
1. **不需要对特征做归一化或标准化**：无论是按年龄（20 到 50 岁）还是月收入（0.8 到 3.0 万元）切分，算法只关心数值的大小次序，单调递增变换不会改变切分结果。
2. **边界呈阶梯状**：面对真正斜向分布的决策边界时，单棵树必须用大量阶梯状的水平线和垂直线去逼近，需要很多层切分才能覆盖。

![决策树的轴对齐空间切分与二叉树节点映射](/images/content-rebuild/220b2808a3bc918f/fig-1.png)

#### 怎么选出最佳切分点？

决策树采用贪心策略：遍历所有特征及其可能的切分阈值，计算切分前后样本集纯度的提升幅度，选择纯度提升最大的切分点。

衡量样本不纯度（Impurity）的常见准则有三种：

#### 1. 信息增益（Information Gain，ID3 算法）
信息熵度量了样本标签的不确定性。假设集合 $D$ 中有 $K$ 个类别，第 $k$ 类样本占比为 $p_k$，则熵定义为：
$$H(D) = -\sum_{k=1}^K p_k \log_2 p_k$$
如果选择某个特征 $A$ 将数据划分为 $V$ 个子集，划分后的信息增益为父节点的熵减去各子节点的加权熵：
$$\text{Gain}(D, A) = H(D) - \sum_{v=1}^V \frac{|D^v|}{|D|} H(D^v)$$
**局限**：如果把“申请人 ID”作为特征切分，每个子集只有 1 个样本，子节点的熵全为 0，信息增益会非常大。但这种切分无法用于新样本，缺乏泛化能力。

#### 2. 信息增益率（Gain Ratio，C4.5 算法）
为了惩罚取值过多的特征，C4.5 引入了特征自身的内在信息量 $\text{IV}(A)$ 作为分母：
$$\text{IV}(A) = -\sum_{v=1}^V \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|}$$
$$\text{Gain\_ratio}(D, A) = \frac{\text{Gain}(D, A)}{\text{IV}(A)}$$
当某个特征分类特别碎时，$\text{IV}(A)$ 会很大，从而抑制该特征被选中的倾向。

#### 3. 基尼不纯度（Gini Impurity，CART 算法）
CART（分类与回归树）在分类任务中使用基尼不纯度。它表示从集合中随机抽取两个样本，其类别标签不一致的概率：
$$\text{Gini}(D) = 1 - \sum_{k=1}^K p_k^2$$
若某个切分将集合 $D$ 分成左右两个子集 $D_1$ 与 $D_2$，加权基尼指数为：
$$\text{Gini\_index}(D, A) = \frac{|D_1|}{|D|} \text{Gini}(D_1) + \frac{|D_2|}{|D|} \text{Gini}(D_2)$$
相比于对数计算，基尼指数只需进行加减乘法，计算开销更低。

#### 算例验证：在信贷数据上寻找第一次切分
在上述信贷数据集中，共 6 个样本，违约样本 2 个（A、B），未违约样本 4 个（C、D、E、F）。
父节点的基尼不纯度为：
$$\text{Gini}(D) = 1 - \left[\left(\frac{2}{6}\right)^2 + \left(\frac{4}{6}\right)^2\right] = 1 - \left(\frac{4}{36} + \frac{16}{36}\right) = 1 - \frac{20}{36} \approx 0.444$$

我们测试一个候选切分点：**“月收入 $\le 1.35$ 万元”**：
- **左子集 $D_1$（月收入 $\le 1.35$ 万元）**：包含 A、B、D 共 3 个样本，其中违约 2 个，未违约 1 个。
  $$\text{Gini}(D_1) = 1 - \left[\left(\frac{2}{3}\right)^2 + \left(\frac{1}{3}\right)^2\right] = 1 - \left(\frac{4}{9} + \frac{1}{9}\right) = \frac{4}{9} \approx 0.444$$
- **右子集 $D_2$（月收入 $> 1.35$ 万元）**：包含 C、E、F 共 3 个样本，全部未违约（违约 0 个，未违约 3 个）。
  $$\text{Gini}(D_2) = 1 - \left[\left(\frac{0}{3}\right)^2 + \left(\frac{3}{3}\right)^2\right] = 0$$

切分后的加权基尼指数为：
$$\text{Gini\_index} = \frac{3}{6} \times 0.444 + \frac{3}{6} \times 0 = 0.222$$
不纯度下降量为 $0.444 - 0.222 = 0.222$。算法会把这个收益与“按年龄切分”的所有候选点进行比较，挑选出纯度提升最大的特征与阈值作为当前分裂规则。

### 单树的过拟合与剪枝

如果不对决策树的生长施加限制，算法会持续切分，直到每个叶节点只包含 1 个样本或所有样本属于同一类别。由于每一步都是局部贪心切分，深层节点基于极少量的样本做出判断，训练集中只要混入一个标签打错的噪点，树结构就会分出一个孤立的叶子去专门拟合它，产生高方差和严重的过拟合。

为了控制模型复杂度，需要引入剪枝策略：

![决策树的预剪枝截断与后剪枝代价复杂度合并对比](/images/content-rebuild/220b2808a3bc918f/fig-2.png)

#### 1. 预剪枝（Pre-pruning）
在建树过程中实时评估停止条件，一旦满足就提前终止节点分裂：
- **最大树深（`max_depth`）**：达到指定深度后强制停止；
- **节点分裂所需最小样本数（`min_samples_split`）**：当前节点样本数少于阈值时不切分；
- **叶节点最小样本数（`min_samples_leaf`）**：切分后若任意子节点样本数过少，则放弃本次切分；
- **最小不纯度下降阈值（`min_impurity_decrease`）**：收益低于阈值时不切分。

*代价与边界*：预剪枝计算快、使用方便，但容易过早停滞。某些特征单独切分时纯度下降极小，但与后续特征组合后能带来明显收益，预剪枝可能会直接错过这类深层规则。

#### 2. 后剪枝（Post-pruning）
先让决策树充分生长，随后自底向上评估每个非叶节点：如果把该子树折叠回一个叶节点不会明显损害验证集表现，则执行合并。

CART 采用代价复杂度剪枝（Cost-Complexity Pruning, CCP）。其目标是最小化带有叶节点数量惩罚的损失函数：
$$C_\alpha(T) = R(T) + \alpha |T|$$
其中 $R(T)$ 为树在训练集上的误差（如分类误判率或均方误差），$|T|$ 为树拥有的叶节点数量，$\alpha \ge 0$ 为复杂度惩罚系数。当 $\alpha$ 从 0 开始增大时，每一步剪去边际损失增加最小的子树，生成一组候选树序列，最后用独立的验证集挑出表现最优的一棵。

后剪枝通常能保留更优质的判定路径，但必须付出完整建树与反向遍历的计算成本。

### 随机森林：通过样本抽样与特征采样降低方差

剪枝能降低单树的复杂度，但单棵树对训练集微小变动极其敏感的性质依然存在。集成学习的第一种思路是 **Bagging（Bootstrap Aggregating，自举汇聚法）**。

#### 为什么集成平均能降低方差？
假设我们训练了 $B$ 个基学习器 $\hat{f}_1(x), \hat{f}_2(x), \dots, \hat{f}_B(x)$。假设每个基学习器的预测方差均为 $\sigma^2$，且任意两个基学习器之间的预测相关系数均为 $\rho$。
我们将这 $B$ 个学习器的预测结果取算术平均：$\bar{f}(x) = \frac{1}{B} \sum_{b=1}^B \hat{f}_b(x)$。根据方差的性质，集成模型的总方差为：
$$\text{Var}(\bar{f}(x)) = \frac{1}{B^2} \left[ \sum_{b=1}^B \text{Var}(\hat{f}_b(x)) + \sum_{i \neq j} \text{Cov}(\hat{f}_i(x), \hat{f}_j(x)) \right]$$
代入 $\text{Cov}(\hat{f}_i, \hat{f}_j) = \rho \sigma^2$，展开后可得：
$$\text{Var}(\bar{f}(x)) = \frac{1}{B^2} \left[ B\sigma^2 + B(B-1)\rho\sigma^2 \right] = \rho \sigma^2 + \frac{1 - \rho}{B} \sigma^2$$

从这个公式可以看出：
- 随着树的数量 $B$ 增大，第二项 $\frac{1 - \rho}{B} \sigma^2$ 会迅速趋近于 0；
- 最终能够保留的方差下界由第一项 $\rho \sigma^2$ 决定。**基学习器之间的相关系数 $\rho$ 越小，整体方差就降得越低**。

![随机森林的双重随机性机制：行重采样与列特征子集采样](/images/content-rebuild/220b2808a3bc918f/fig-3.png)

#### 随机森林如何打破树之间的相关性？
如果直接在同一批数据上并行训练多棵充分生长的决策树，因为训练集相同，每棵树挑选的前几个最强特征往往是一样的，导致生成的树结构高度相似，$\rho$ 接近 1，求平均后方差几乎没有下降。

随机森林通过两项随机化手段压低相关系数 $\rho$：
1. **样本行抽样（Bootstrap 重采样）**：对于包含 $N$ 个样本的数据集，每次通过有放回抽样抽取 $N$ 次构成一棵树的专属训练集。每个样本在 $N$ 次抽取中未被选中的概率为 $(1 - 1/N)^N \approx 1/e \approx 36.8\%$。这部分未被抽中的样本被称为袋外数据（Out-of-Bag, OOB），可以直接充当内置验证集。
2. **特征列抽样（节点级特征子集）**：在单棵树生长的**每一个节点分裂时**，算法不遍历全部 $D$ 个特征，而是随机抽取 $k$ 个候选特征（分类任务通常取 $k = \lfloor\sqrt{D}\rfloor$），仅在这 $k$ 个候选特征中寻找最佳切分点。

特征随机化迫使各个树无法在每一层都依赖最强特征，而是探索不同的特征组合。这显著降低了基学习器之间的相关性 $\rho$，使得集成后的总方差大幅下降。

### 提升树（Boosting Tree）：串行拟合残差

与 Bagging 并行训练强模型来降方差不同，集成学习的第二种思路是 **Boosting（提升法）**。Boosting 使用串行训练机制：初始模型通常是一个非常简单的弱学习器（高偏差、低方差），每一轮训练的新模型都专注于修复前面所有模型组合在一起后遗留下的预测误差。

加法模型可以表示为：
$$F_M(x) = \sum_{m=0}^M h_m(x)$$

![提升树通过串行拟合当前模型残差逐步逼近真实目标](/images/content-rebuild/220b2808a3bc918f/fig-4.png)

以连续值回归任务为例，假设我们使用均方误差作为损失函数：
$$L(y, F(x)) = \frac{1}{2} (y - F(x))^2$$
假设第 $m-1$ 轮更新后的组合模型为 $F_{m-1}(x)$，我们希望下一棵树 $h_m(x)$ 能够让更新后的损失进一步缩小：
$$L(y, F_{m-1}(x) + h_m(x)) = \frac{1}{2} \left[ (y - F_{m-1}(x)) - h_m(x) \right]^2$$
定义残差（Residual）为当前预测与真实标签的差值：
$$r = y - F_{m-1}(x)$$
目标函数就变成了：
$$\min_{h_m} \frac{1}{2} \sum_{i=1}^N \left[ r_i - h_m(x_i) \right]^2$$
这意味着：**在均方误差损失下，每一轮训练的新树，其拟合的目标值就是上一轮模型留下的残差**。

#### 授信额度预测数值演示
以信贷数据集中申请人 A 为例（真实授信额度 $y = 1.0$ 万元）：
- **初始化**：初始模型预测全局均值 $F_0 = 3.67$ 万元；
- **第 1 轮**：申请人 A 处的残差为 $r_1 = 1.0 - 3.67 = -2.67$。新树 $h_1$ 拟合这个负残差，输出 $-2.0$。更新模型为 $F_1 = 3.67 + (-2.0) = 1.67$；
- **第 2 轮**：新残差缩小为 $r_2 = 1.0 - 1.67 = -0.67$。下一棵树以 $-0.67$ 为目标继续拟合。

随着多轮串行纠偏，预测值与真实目标之间的系统偏差逐步降低。

### 梯度提升决策树（GBDT）：用负梯度推广残差

提升树拟合残差直观有效，但它严格受限于“均方误差损失”。如果任务变成二分类逻辑损失（Binary Cross-Entropy）或对异常值更鲁棒的绝对误差损失（MAE），损失函数对预测值的导数不再是简单的标签差值。如何在任意可导损失函数下推广这一机制？

Jerome Friedman 提出的 **梯度提升决策树（GBDT）** 解决了这一问题：**将损失函数的负梯度作为通用残差的逼近（通常称为伪残差，Pseudo-residual）**。

![GBDT 在函数空间中沿着负梯度方向更新模型参数](/images/content-rebuild/220b2808a3bc918f/fig-5.png)

#### 函数空间的梯度下降
在普通参数优化中，我们在参数空间更新权重：$\theta \leftarrow \theta - \eta \nabla_\theta L$。
在 GBDT 中，我们直接在函数空间优化预测值：把当前模型在训练样本 $x_i$ 上的输出 $F(x_i)$ 本身视为自变量，计算损失函数关于预测输出的负梯度：
$$r_{im} = -\left[ \frac{\partial L(y_i, F(x_i))}{\partial F(x_i)} \right]_{F(x) = F_{m-1}(x)}$$

让我们验证不同损失函数下的负梯度形式：
1. **均方误差损失** $L(y, F) = \frac{1}{2}(y - F)^2$：
   $$-\frac{\partial L}{\partial F} = y - F$$
   负梯度与真实残差完全相等。
2. **二分类对数损失**（标签 $y \in \{0, 1\}$，模型输出为对数几率 $F(x) = \ln\frac{p}{1-p}$，即 $p = \frac{1}{1 + e^{-F}}$）：
   损失函数为 $L(y, F) = -y \ln p - (1 - y) \ln(1 - p) = -y F + \ln(1 + e^F)$。
   对预测输出 $F$ 求偏导并取负：
   $$-\frac{\partial L}{\partial F} = y - \frac{e^F}{1 + e^F} = y - p$$
   此处的伪残差是**真实类别与当前模型预测概率的差值**。

#### 算法执行流程与步长缩减（Shrinkage）
1. **初始化常数模型**：找到使总损失最小的常数值 $c$：
   $$F_0(x) = \arg\min_c \sum_{i=1}^N L(y_i, c)$$
2. **串行迭代 $m = 1$ 到 $M$ 轮**：
   - 对每个样本计算负梯度 $r_{im}$；
   - 将 $(x_i, r_{im})$ 作为训练数据，拟合一棵回归树，得到其划分的叶节点区域 $R_{jm}$（$j = 1, \dots, J$）；
   - 对每个叶节点区域 $R_{jm}$，求解其最优输出值 $\gamma_{jm}$：
     $$\gamma_{jm} = \arg\min_\gamma \sum_{x_i \in R_{jm}} L(y_i, F_{m-1}(x_i) + \gamma)$$
   - **步长缩减更新**：引入学习率 $\eta \in (0, 1]$，更新模型：
     $$F_m(x) = F_{m-1}(x) + \eta \sum_{j=1}^J \gamma_{jm} \mathbb{I}(x \in R_{jm})$$

这里的 $\eta$ 控制了每棵新树对整体预测的修正强度。较小的学习率（例如 0.05 到 0.1）配合更多的迭代树数量，可以防止模型过度拟合局部的负梯度噪点，显著增强泛化表现。

### 代码实现：从单树到集成学习的 API 对比

在 `scikit-learn` 中，这三种模型有着统一的调用接口。下面的示例展示了如何在信贷违约预测任务上配置并运行它们：

```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

# 贯穿示例数据：年龄、月收入（万元）
X = np.array([
    [23, 0.8],
    [25, 1.2],
    [28, 1.5],
    [35, 1.0],
    [40, 2.5],
    [45, 3.0]
])
y = np.array([1, 1, 0, 0, 0, 0])  # 1 为违约，0 为正常

# 1. 单棵决策树：使用预剪枝限制深度，防止叶节点样本过少
tree = DecisionTreeClassifier(
    criterion="gini",
    max_depth=3,
    min_samples_split=2,
    random_state=42
)
tree.fit(X, y)

# 2. 随机森林：并行构建 100 棵充分生长的深树，节点分裂随机挑选 sqrt(D) 个特征
rf = RandomForestClassifier(
    n_estimators=100,
    max_depth=None,
    max_features="sqrt",
    bootstrap=True,
    random_state=42
)
rf.fit(X, y)

# 3. GBDT：串行迭代 100 棵浅树（弱学习器），配合较小的学习率缩减步长
gbdt = GradientBoostingClassifier(
    n_estimators=100,
    learning_rate=0.1,
    max_depth=3,
    loss="log_loss",
    random_state=42
)
gbdt.fit(X, y)

# 预测新申请人：30 岁，月收入 1.1 万元
X_new = np.array([[30, 1.1]])
print("单树预测概率:", tree.predict_proba(X_new)[0])
print("随机森林预测概率:", rf.predict_proba(X_new)[0])
print("GBDT 预测概率:", gbdt.predict_proba(X_new)[0])
```

### 决策树、Bagging 与 Boosting 的综合对比

理解随机森林与 GBDT 的关键，在于理清它们在偏差与方差权衡上的不同路径。

![Bagging 与 Boosting 在偏差-方差路径上的因果权衡对比](/images/content-rebuild/220b2808a3bc918f/fig-6.png)

| 对比维度 | 单棵决策树 | 随机森林（Bagging） | GBDT（Boosting） |
| :--- | :--- | :--- | :--- |
| **主要优化目标** | 寻找局部最优划分 | **降低方差（Variance）** | **降低偏差（Bias）** |
| **基学习器形态** | 单一树模型 | **深树**：充分生长，低偏差、高方差 | **浅树**：受限深度（通常 3~6 层），高偏差、低方差 |
| **学习器构建方式** | 一次性递归贪心切分 | 相互独立，并行构建 | 相互依赖，串行拟合负梯度 |
| **采样策略** | 使用全部数据与特征 | 样本 Bootstrap 抽样 + 节点特征随机抽样 | 通常使用全部样本（或子采样），关注难分样本的梯度 |
| **异常噪点敏感度** | **高**：容易因个别噪点深层分支 | **低**：异常点影响被大量互不相关的树平均冲淡 | **高**：异常噪点会产生巨大梯度，后续树会集中拟合这些偏差 |
| **计算并行能力** | 仅单树内部特征评估可并行 | 天然支持多核/多机跨树并行构建 | 树与树之间必须串行，并行主要发生在节点特征切分统计 |

在下一篇[聚类和降维](/fundamentals/ml-basics/clustering-dimensionality.md)中，我们将打破“训练必须依赖已知标签”的前提，探索在无标签场景下如何度量样本相似性并发现数据的内在几何结构。
