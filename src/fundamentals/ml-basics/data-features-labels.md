## 从现实对象到数值矩阵：样本、特征与坐标空间

以二手房交易为例，假设我们要预测房屋的成交价格。每套挂牌出售的房子是一个独立的观测对象，在数据集中称为**样本**（Sample 或 Instance）。而描述房子属性的各项指标（例如建筑面积、距最近地铁站距离、建造年份、所在城市）被称为**特征**（Feature）。

如果收集了 $N$ 套房子的数据，每套房子记录了 $D$ 个数值特征，我们可以把这些数据整齐地排列成一个二维表格，数学上称为**设计矩阵**（Design Matrix），记作 $\mathbf{X} \in \mathbb{R}^{N \times D}$：

$$\mathbf{X} = \begin{bmatrix} x_{11} & x_{12} & \cdots & x_{1D} \\ x_{21} & x_{22} & \cdots & x_{2D} \\ \vdots & \vdots & \ddots & \vdots \\ x_{N1} & x_{N2} & \cdots & x_{ND} \end{bmatrix}$$

- **行向量（样本）**：第 $i$ 行记为 $\mathbf{x}_i^T = [x_{i1}, x_{i2}, \dots, x_{iD}]$，表示第 $i$ 套房子的各项属性。在几何视角下，这组数字就是该样本在 $D$ 维空间中的一组坐标。
- **列向量（特征）**：第 $j$ 列包含了所有 $N$ 套房子在第 $j$ 个属性上的测量值，反映了该属性在样本群体中的数值分布。

由这 $D$ 个坐标轴组成的空间称为**特征空间**（Feature Space）。每一套真实的房子，都被映射为这个空间里的一个几何点。后续的模型训练，无论是在空间中画一条分界线，还是拟合一个曲面，都是在这个几何空间中展开的。

![业务实体到特征矩阵与向量空间的映射流程](/images/content-rebuild/afe78ab6708f7337/fig-1.png)

上图展示了从客观实体到特征空间的转化路径。左侧为实体属性度量，中间为结构化设计矩阵 $\mathbf{X}$，右侧则展现了样本映射至特征空间后的几何分布。请注意，矩阵的行决定了空间中散点的数量，而矩阵的列则决定了该空间的坐标轴维度。

## 特征类型与编码：别给模型强加错误的数学假设

收集到的业务数据往往格式各异，不能直接往矩阵里填。根据属性的数学性质，特征通常分为三类：

1. **连续数值型**：具有明确物理单位，支持大小比较与加减乘除。例如面积 $89.5\,\text{m}^2$、地铁距离 $0.8\,\text{km}$。
2. **离散有序型**：取值为离散项，项与项之间有先后、强弱或优劣顺序，但没有固定的量化间隔。例如房屋楼层划分为 $[\text{低楼层}, \text{中楼层}, \text{高楼层}]$，或者户型评级 $[\text{普通}, \text{良好}, \text{优秀}]$。通常可以依序映射为整数（如 $0, 1, 2$）。但在使用线性模型时要注意：这种赋值隐含了“中楼层到高楼层的差距，正好等于低楼层到中楼层差距”的假设。
3. **离散无序型**：取值为离散名称或符号，彼此平级，不存在大小或顺序关系。例如城市名称 $[\text{北京}, \text{上海}, \text{广州}]$、外墙颜色 $[\text{红}, \text{黄}, \text{蓝}]$。

### 整数编码无序变量会引入虚假先验

有些初学者为了图省事，直接用连续整数为无序变量编码，比如将城市编码为：北京 $= 1$、上海 $= 2$、广州 $= 3$。

这种做法在线性回归、逻辑回归或 KNN 等依赖算术计算的模型中，会强行引入两个错误的数学先验：

- **距离不对称假设**：模型计算出的距离为 $|3 - 1| = 2$，而 $|2 - 1| = 1$。这等于在告诉模型：“广州和北京的差异，是上海和北京差异的两倍”。但城市之间并没有这种倍数关系。
- **中介过渡假设**：在线性方程 $\hat{y} = w x + b$ 中，当特征取 $x=2$（上海）时，其预测结果必定严格等于 $x=1$（北京）和 $x=3$（广州）预测值的算术平均：
  $$\hat{y}_{\text{上海}} = \frac{\hat{y}_{\text{北京}} + \hat{y}_{\text{广州}}}{2}$$
  在现实业务中，上海的房价效应完全可能同时高于或低于另外两个城市，直接给无序类别赋整数会死死卡住模型的表达能力。

### 独热编码的正交基底机制

对于离散无序变量，标准处理方式是**独热编码**（One-Hot Encoding）。如果一个类别变量有 $K$ 种互斥取值，就新建 $K$ 个二进制特征列。每个样本仅在自己对应的类别位置记为 $1$，其余全为 $0$：

$$\text{北京} = [1, 0, 0]^T, \quad \text{上海} = [0, 1, 0]^T, \quad \text{广州} = [0, 0, 1]^T$$

在几何上，独热编码将离散类别放置在相互垂直（正交）的坐标轴上。这样处理具有清晰的数学性质：

- 任意两个不同类别向量 $\mathbf{e}_i$ 与 $\mathbf{e}_j$ 之间的欧几里得距离恒定为：
  $$\|\mathbf{e}_i - \mathbf{e}_j\|_2 = \sqrt{1^2 + (-1)^2} = \sqrt{2}$$
- 曼哈顿距离恒定为 $2$。
- 余弦相似度恒定为 $\frac{\mathbf{e}_i \cdot \mathbf{e}_j}{\|\mathbf{e}_i\| \|\mathbf{e}_j\|} = 0$。

不同类别之间的几何距离全部相等，模型不会预先带入偏袒任何一方的大小次序，每个类别都能学到独立的参数权重。

![无序标签编码错误先验对比独热编码正交空间](/images/content-rebuild/afe78ab6708f7337/fig-2.png)

上图对比了两种编码的几何差异。左图的一维整数轴强行将离散类别串联，产生了不合理的线性约束与中介点；右图的三维空间中，独热向量分别占据三个互相正交的坐标轴，各点之间欧氏距离均为 $\sqrt{2}$，保持了对称与等距。

## 标签的作用：监督模型学习的目标信号

在有监督学习中，除了输入特征矩阵 $\mathbf{X}$ 之外，每个样本还需要一个参考答案——**标签**（Label），通常记为向量 $\mathbf{y} \in \mathbb{R}^N$。

标签的取值形式直接决定了任务的类别和损失函数的选择：

| 任务类型 | 标签取值范围 | 学习目标 | 示例 |
| :--- | :--- | :--- | :--- |
| **回归任务（Regression）** | 连续实数 $y \in \mathbb{R}$ | 拟合连续曲面，降低预测数值与真实数值的偏差 | 预测房屋成交价（如 685.5 万元） |
| **二分类任务（Binary Classification）** | 离散二值 $y \in \{0, 1\}$ | 寻找判定边界，估计属于某一类的概率 $P(Y=1 \mid \mathbf{x})$ | 判断该房屋在挂牌30天内能否售出（能/否） |
| **多分类任务（Multi-class）** | 离散多值 $y \in \{1, 2, \dots, C\}$ | 划分多个决策区域，输出属于各类的概率分布 | 预测该房产被买家评定的装修风格类别 |

特征是模型的输入（自变量），标签是计算损失函数时的标准依据（因变量）。如果收集到的标签存在大量标注错误（标签噪声），或者正负样本数量极其悬殊（如 99% 的房屋都未在30天内售出，即类别不平衡），优化过程就容易被常见类别或错误数据牵着走，导致模型在少见但重要的样本上表现不佳。

![回归连续曲面拟合与分类决策超平面划分机制对比](/images/content-rebuild/afe78ab6708f7337/fig-3.png)

上图对比了连续标签与离散标签在空间几何上的不同学习目标。回归问题（左侧）寻找贯穿点云的平滑连续曲面，预测值可连续变化；分类问题（右侧）寻找将不同颜色的离散类别样本隔开的决策边界（Decision Boundary）。

## 特征缩放：消除量纲差异，稳定数值求解

当不同特征的数值范围悬殊时，许多依赖梯度更新或距离计算的算法会遇到收敛缓慢的问题。

假设我们用两个特征来预测房价：$x_1$ 为卧室数量（取值在 $1 \sim 5$ 之间），$x_2$ 为房屋面积（取值在 $50 \sim 200\,\text{m}^2$ 之间）。两个维度的数值相差几十到上百倍。

### 为什么尺度悬殊会影响梯度下降？

采用线性模型时，预测方程为 $\hat{y} = w_1 x_1 + w_2 x_2 + b$。均方误差损失函数对权重 $w_j$ 的导数为：

$$\frac{\partial L}{\partial w_j} = -\frac{2}{N} \sum_{i=1}^N (y_i - \hat{y}_i) x_{ij}$$

可以看到，梯度大小与输入特征值 $x_{ij}$ 直接相关。由于面积 $x_2$ 的数值远大于卧室数 $x_1$，对 $w_2$ 的梯度就会比对 $w_1$ 的梯度大得多。这导致损失函数等高线在参数空间中被拉成一个非常狭长的椭圆：

- 在 $w_2$ 对应的轴向上，坡度非常陡，参数稍微移动就引起损失剧烈波动；
- 在 $w_1$ 对应的轴向上，坡度非常缓，参数更新步幅极小。

如果用同一个学习率更新参数，步子迈大了会在陡坡上来回震荡，步子迈小了在缓坡上又走不动，导致梯度下降轨迹呈现剧烈的“Z字形”震荡，显著增加训练耗时甚至难以收敛。

### 两种常用的数值缩放方法

为了平衡不同特征的影响，需要对各特征列进行缩放处理：

1. **Z-score 标准化（Standardization）**：
   $$x' = \frac{x - \mu}{\sigma}$$
   其中 $\mu$ 为该特征的均值，$\sigma$ 为样本标准差。变换后，特征的均值为 $0$，方差为 $1$。标准化不会改变原本分布的偏态与形态，保留了异常点在均值周围的相对距离。
2. **Min-Max 归一化（Min-Max Normalization）**：
   $$x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$$
   把数据统一线性映射到 $[0, 1]$ 之间。该方法对**异常极大值和极小值非常敏感**。如果数据中混入了一处录入错误的特大数值（例如面积误填成了 $10000\,\text{m}^2$），正常范围内的面积数值就会被全部压缩在极窄的微小区间内（如 $0.005 \sim 0.02$），丢失区分度。

**适用条件说明**：
特征缩放对于基于距离度量的模型（如 KNN、K-Means、带核函数的 SVM）和基于梯度下降优化的模型（如线性回归、逻辑回归、神经网络，详见[/fundamentals/ml-basics/linear-logistic-regression.md](/fundamentals/ml-basics/linear-logistic-regression.md)）非常关键。但对于**决策树以及基于树集成的模型**（如随机森林、GBDT，详见[/fundamentals/ml-basics/tree-models.md](/fundamentals/ml-basics/tree-models.md)），特征缩放**没有实质影响**。因为树模型在寻找最优切分点时，只关注特征在样本内部的相对数值大小与先后排序，把面积整体乘以 1000 或做标准化，样本之间的相对次序不变，切分位置对应的分位数也不会改变。

![未缩放狭长椭圆与标准化后同心圆梯度下降轨迹对比](/images/content-rebuild/afe78ab6708f7337/fig-4.png)

上图展示了特征缩放对损失函数几何形状的影响。左侧未缩放时，不同维度的量纲差异导致损失等高线极度狭长，梯度更新沿陡峭方向激烈震荡；右侧标准化后，等高线趋于正圆，梯度方向几乎直指全局最优点，收敛迅速且稳定。

## 高维特征与“维度灾难”的直觉理解

在特征工程中，人们常常把“高维稀疏特征”与“维度灾难”混为一谈。

### 维度灾难是怎么发生的？

狭义上的“维度灾难”（Curse of Dimensionality），是指在连续欧几里得空间中，**空间的体积随着维度 $D$ 的增加呈指数级爆炸**，使得有限数量的样本点在广袤的空间中变得极其稀疏，原本基于局域密度的距离度量逐渐失效。

我们看一个具体的几何比例：
在一个边长为 $2$ 的 $D$ 维超立方体中，放入一个半径为 $R=1$ 的内切超球。超立方体的体积是 $V_{\text{cube}} = 2^D$。半径为 $1$ 的 $D$ 维超球体积为：

$$V_{\text{sphere}} = \frac{\pi^{D/2}}{\Gamma(D/2 + 1)}$$

计算超球体积占超立方体体积的比例：
- 当 $D = 2$ 时，两者的体积比为 $\frac{\pi}{4} \approx 0.785$
- 当 $D = 10$ 时，比值降为约 $0.0025$
- 当 $D = 20$ 时，比值进一步跌落至约 $2.46 \times 10^{-8}$

这说明，随着连续空间维度升高，几乎所有的空间体积都分布在超立方体的“边角”位置，中间区域空空如也。在没有特殊结构且各维度独立同分布的假设下，任意两点间的最大距离与最小距离差异会相对缩小，依赖全局欧氏距离找邻居的算法（如无降维的全局高维 KNN）容易遇到近邻与远邻区分度降低的瓶颈。

### 稀疏高维为什么并不等同于灾难？

在推荐系统、点击率预估或文本分类场景中，经过大量 One-Hot 编码后，特征维度经常达到数万甚至数百万维。但这类场景很少直接发生前述的全局欧氏距离失效，原因在于：

1. **内在有效自由度低**：现实业务产生的数据并不是在数百万维空间中均匀乱撒，有效样本往往集中在少数几个低维关联结构中。
2. **物理稀疏性**：每个样本虽然名义上有上百万个特征槽位，但其中绝大多数分量全为 $0$，非零特征只有几十到数百个。样本之间的距离和相似度只在极少数共同出现的非零位置上计算，不需要在全空间进行各向同性的连续搜索。
3. **模型算子匹配**：处理稀疏高维特征时，工程上通常搭配带正则化（如 $L_1$ 惩罚）的线性模型或因子分解模型，通过点积打分而非全空间的欧几里得距离聚类。

因此，不能单纯根据维度数字的大小判断是否发生了“维度灾难”，而要看数据的实际几何分布以及模型所采用的计算方式。

![几何空间超球体积随维度坍缩与稀疏流形低维投影对比](/images/content-rebuild/afe78ab6708f7337/fig-5.png)

上图解析了高维特征的几何现实。左侧展示了随着空间维度提升，超立方体内切球的相对体积趋近于 0，质量全部堆积在超空间角落；右侧展现了真实业务中的高维稀疏数据：散点虽然置身于多维外置空间，但实际只附着在低维流形曲面上，可以通过有效降维进行紧凑表达。

## 工程实践：用流水线防止数据泄露

在对连续特征做标准化、对离散特征做独热编码时，必须严格遵守一个工程准则：**严防数据泄露（Data Leakage）**。

很多初学者常犯的错误，是在把数据切分为训练集和测试集之前，就对整个数据集调用预处理工具拟合均值和方差。这样一来，测试集的均值、极值分布就被悄悄带进了预处理参数中，使离线评估测出的指标偏高，上线面对真正的未知数据时效果大打折扣。

正确的顺序是：
1. 先把数据集划分为训练集和测试集；
2. 仅在训练集上计算特征的统计参数（`fit`）；
3. 将算好的统计参数直接套用到训练集和测试集上进行数值转换（`transform`）。

在 `scikit-learn` 中，推荐使用 `ColumnTransformer` 与 `Pipeline` 将预处理逻辑与模型串联封装：

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import StandardScaler, OneHotEncoder
from sklearn.pipeline import Pipeline
from sklearn.linear_model import Ridge

# 1. 构造演示用的房产数据（行数较少仅用于展示语法流程）
data = pd.DataFrame({
    'area': [85.0, 120.5, 65.0, 150.0, 92.0, 110.0],
    'distance_subway': [0.5, 1.2, 0.2, 2.5, 0.8, 1.5],
    'city': ['Beijing', 'Shanghai', 'Shanghai', 'Beijing', 'Guangzhou', 'Beijing'],
    'price': [720.0, 950.0, 580.0, 1100.0, 680.0, 890.0]  # 目标标签：房屋价格（万元）
})

X = data[['area', 'distance_subway', 'city']]
y = data['price']

# 2. 严格优先划分训练集与测试集
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.33, random_state=42
)

# 3. 按不同特征类型定义针对性的转换规则
numeric_features = ['area', 'distance_subway']
categorical_features = ['city']

preprocessor = ColumnTransformer(
    transformers=[
        ('num', StandardScaler(), numeric_features),  # 连续特征：Z-score 标准化
        ('cat', OneHotEncoder(sparse_output=False, handle_unknown='ignore'), categorical_features)  # 无序类别：独热编码
    ]
)

# 4. 将预处理模块与预测模型装配为一体化流水线
model_pipeline = Pipeline(steps=[
    ('preprocessor', preprocessor),
    ('regressor', Ridge(alpha=1.0))
])

# 5. fit 只在训练集上执行：统计参数（均值、方差、类别字典）均来自 X_train
model_pipeline.fit(X_train, y_train)

# 6. 对测试集做预测时，内部自动复用训练集学到的均值与方差做转换
predictions = model_pipeline.predict(X_test)
```
