在[训练集、验证集、测试集](/fundamentals/ml-basics/train-val-test.md)中，我们通过数据切分来检验模型的泛化能力。在实际训练中，开发者最常遇到两类极端情况：
1. 模型在训练集和验证集上的误差都居高不下，根本没学到规律；
2. 模型在训练集上误差几乎为零，但在验证集上误差很大，换一批新数据就频繁出错。

这两种情况分别对应机器学习中的两个核心问题：**欠拟合（Underfitting）**与**过拟合（Overfitting）**。

我们可以用一个具体的贯穿实验来建立直觉：假设真实的数据生成规律是一个正弦波加随机噪声 $y = \sin(2\pi x) + \epsilon$。我们从中只采集 15 个点作为训练数据：
* **欠拟合**：如果强行用一条直线（一阶线性模型）去拟合，无论如何调整斜率，直线都无法表达波峰与波谷，在训练点和新数据上误差都很大；
* **过拟合**：如果用一个九阶多项式去拟合，模型为了精确穿过每一个带着噪声的样本点，曲线在点与点之间剧烈上下震荡。虽然训练点的误差接近于零，但稍微偏离训练点的新位置，预测值就会彻底失真；
* **良好拟合**：如果用合适阶数（如三阶或施加约束的模型）去拟合，曲线平滑地贴合正弦走势，既抓住了核心波动，又没有被个别噪声点带偏。

## 欠拟合与过拟合的显式特征：通过学习曲线诊断

评估模型状态最直接的工具是**学习曲线（Learning Curves）**，即损失函数（Loss）或评估指标随着训练轮数（Epochs）或样本规模增加时的变化轨迹。

```
欠拟合 (高偏差)             良好平衡状态                过拟合 (高方差)
损失                        损失                        损失
 |                          |                          |       验证损失反弹上升
 | ─── 验证损失 (高位)       |                          |   /── 验证损失
 | ─── 训练损失 (高位)       | ─── 验证损失 (平稳收敛)    |  / 
 |                          | ─── 训练损失             | /──── 训练损失持续趋近0
 └───────────> 训练轮数      └───────────> 训练轮数      └───────────> 训练轮数
```

### 1. 欠拟合的诊断特征
* **表现**：训练集损失大，验证集损失也大，两者数值接近，但都达不到预期的可用标准。
* **产生原因**：模型结构过于简单，特征表达能力不足，或者假设空间受到过强限制，无法表达输入特征 $X$ 与目标变量 $y$ 之间的映射关系。
* **常见场景**：用没有交互项的简单线性模型拟合复杂的周期性业务数据，或者在非线性图像任务中仅输入全局平均统计量。

### 2. 过拟合的诊断特征
* **表现**：训练集损失极低，但验证集损失在经过一段下降后停滞甚至大幅反弹。训练损失与验证损失之间拉开明显的差距（Generalization Gap）。
* **产生原因**：模型参数量和自由度过高，超出了数据所包含的真实规律需求。模型不仅记住了输入输出之间的共有规律（信号），还把当前这批训练样本特有的测量误差、随机扰动（噪声）当作普遍规律编码进了权重里。
* **常见场景**：样本量仅有几百条，却使用高阶多项式或层数极深的神经网络，且未配置任何参数惩罚与正则化。

![学习曲线诊断对比图](/images/content-rebuild/a88290f186ada975/fig-1.png)

在训练过程中，一旦观察到验证误差曲线不再下降并开始向上拐折，通常意味着模型已经学完了主要规律，正在逐步转向过度拟合训练集噪声。

## 泛化误差的数学分解：偏差、方差与不可约噪声

为什么模型在训练集上表现好，到了测试集却会失效？我们可以通过**偏差-方差分解（Bias-Variance Decomposition）**将均方误差（MSE）拆解为三个数学组成部分。

### 1. 形式化推导
假设数据的客观生成过程为：
$$y = f(x) + \epsilon$$
其中 $f(x)$ 为真实映射函数，$\epsilon$ 为独立于 $x$ 的随机噪声，满足均值为零、方差恒定：
$$\mathbb{E}[\epsilon] = 0, \quad \text{Var}(\epsilon) = \sigma^2$$

我们从数据分布中随机抽样出一个训练集 $\mathcal{D}$，训练得到模型 $\hat{f}(x; \mathcal{D})$。对于一个独立的测试点 $x_0$，其真实标签为 $y_0 = f(x_0) + \epsilon$。我们考察该测试点处的期望均方误差，该期望是对所有可能的训练集抽样 $\mathcal{D}$ 和测量噪声 $\epsilon$ 取平均：

定义模型在所有可能训练集上的平均预测值为：
$$\bar{f}(x_0) = \mathbb{E}_{\mathcal{D}}[\hat{f}(x_0; \mathcal{D})]$$

将均方误差项展开并重组：
$$\begin{aligned}
\mathbb{E}_{\mathcal{D}, \epsilon}\left[(y_0 - \hat{f}(x_0))^2\right] &= \mathbb{E}_{\mathcal{D}, \epsilon}\left[\left((f(x_0) + \epsilon) - \hat{f}(x_0)\right)^2\right] \\
&= \mathbb{E}_{\mathcal{D}, \epsilon}\left[\left((f(x_0) - \bar{f}(x_0)) + (\bar{f}(x_0) - \hat{f}(x_0)) + \epsilon\right)^2\right]
\end{aligned}$$

展开平方项后包含三项平方与三项交叉积。由于噪声 $\epsilon$ 与模型估计 $\hat{f}(x_0)$ 相互独立，且 $\mathbb{E}[\epsilon] = 0$、$\mathbb{E}_{\mathcal{D}}[\bar{f}(x_0) - \hat{f}(x_0)] = 0$，所有交叉项的期望均为零：
$$\begin{aligned}
\mathbb{E}\left[2(f(x_0) - \bar{f}(x_0))(\bar{f}(x_0) - \hat{f}(x_0))\right] &= 2(f(x_0) - \bar{f}(x_0)) \cdot \mathbb{E}[\bar{f}(x_0) - \hat{f}(x_0)] = 0 \\
\mathbb{E}\left[2(f(x_0) - \bar{f}(x_0))\epsilon\right] &= 2(f(x_0) - \bar{f}(x_0)) \cdot \mathbb{E}[\epsilon] = 0 \\
\mathbb{E}\left[2(\bar{f}(x_0) - \hat{f}(x_0))\epsilon\right] &= 2 \cdot \mathbb{E}[\bar{f}(x_0) - \hat{f}(x_0)] \cdot \mathbb{E}[\epsilon] = 0
\end{aligned}$$

最终得到泛化均方误差的三个组成部分：
$$\mathbb{E}\left[(y_0 - \hat{f}(x_0))^2\right] = \underbrace{(f(x_0) - \bar{f}(x_0))^2}_{\text{偏差平方 (}\text{Bias}^2\text{)}} + \underbrace{\mathbb{E}_{\mathcal{D}}\left[(\hat{f}(x_0) - \bar{f}(x_0))^2\right]}_{\text{方差 (}\text{Variance}\text{)}} + \underbrace{\sigma^2}_{\text{不可约噪声 (Noise)}}$$

![偏差-方差分解机制图](/images/content-rebuild/a88290f186ada975/fig-2.png)

### 2. 各项物理含义与权衡关系

| 分解项 | 定义公式 | 实际含义 | 与拟合状态的对应 |
| :--- | :--- | :--- | :--- |
| **偏差（Bias）** | $f(x_0) - \mathbb{E}[\hat{f}(x_0)]$ | 模型多次训练的平均预测值与客观真实值之间的距离。 | 偏差大意味着模型自身表达能力受限，无法拟合数据规律，对应**欠拟合**。 |
| **方差（Variance）** | $\mathbb{E}[(\hat{f}(x_0) - \bar{f}(x_0))^2]$ | 训练集样本的微小改变，引起模型预测结果波动的剧烈程度。 | 方差大意味着模型对训练样本极度敏感，缺乏稳定性，对应**过拟合**。 |
| **不可约噪声（Noise）** | $\sigma^2$ | 数据本身包含的测量误差或未观测到的随机扰动。 | 无法由模型优化消除，构成泛化误差的理论下界。 |

在训练样本量固定的条件下，**偏差与方差通常存在此消彼长的权衡关系**：
* 增加模型自由度（如提高多项式阶数、加深网络层数）通常会降低偏差，但模型对具体样本的敏感度升高，导致方差变大；
* 限制模型自由度（如平滑约束、减少参数）可以降低方差，但模型拟合复杂规律的能力变弱，导致偏差上升。

模型调优的核心目标，就是在当前数据量下找到使“$\text{Bias}^2 + \text{Variance}$”总和最小的平衡点。后文在讨论[决策树与集成学习](/fundamentals/ml-basics/tree-models.md)时会看到：Bagging（如随机森林）主要通过多模型平均来**降方差**，而 Boosting（如 GBDT）主要通过残差迭代来逐步**降偏差**。

## 实验验证：多项式拟合中的模型复杂度与权重膨胀

为了直观展示复杂度对拟合状态的影响，我们实现开头的正弦拟合实验：
真实生成过程设为 $y = \sin(2\pi x) + \epsilon$（$x \in [0, 1]$），采样 $N=15$ 个带高斯噪声的训练点，分别用 1 阶、3 阶与 9 阶多项式模型进行最小二乘拟合：
$$\hat{y} = w_0 + w_1 x + w_2 x^2 + \dots + w_M x^M$$

```python
import numpy as np

# 固定随机种子以便复现
np.random.seed(42)

def true_func(x):
    return np.sin(2 * np.pi * x)

# 生成15个带噪声的训练样本
x_train = np.sort(np.random.uniform(0, 1, 15))
y_train = true_func(x_train) + np.random.normal(0, 0.2, 15)

# 生成100个测试评估点
x_val = np.linspace(0, 1, 100)
y_val_true = true_func(x_val)

# 拟合并评估不同阶数
degrees = [1, 3, 9]
for deg in degrees:
    poly_weights = np.polyfit(x_train, y_train, deg)
    
    # 训练集均方误差
    train_pred = np.polyval(poly_weights, x_train)
    train_mse = np.mean((y_train - train_pred) ** 2)
    
    # 验证集均方误差（相对真实函数评估泛化性）
    val_pred = np.polyval(poly_weights, x_val)
    val_mse = np.mean((y_val_true - val_pred) ** 2)
    
    # 观察权重向量的二范数模长
    w_norm = np.linalg.norm(poly_weights)
    print(f"阶数: {deg:2d} | 训练集MSE: {train_mse:.4f} | 验证集MSE: {val_mse:.4f} | 权重模长: {w_norm:.1f}")
```

运行上述代码，输出结果示意如下：
```text
阶数:  1 | 训练集MSE: 0.1832 | 验证集MSE: 0.2105 | 权重模长: 1.8
阶数:  3 | 训练集MSE: 0.0385 | 验证集MSE: 0.0412 | 权重模长: 14.2
阶数:  9 | 训练集MSE: 0.0071 | 验证集MSE: 1.4820 | 权重模长: 125890.4
```

![多项式拟合阶数对比实验图](/images/content-rebuild/a88290f186ada975/fig-3.png)

从实验数据可以清晰观察到三个阶段：
1. **阶数 $M=1$（欠拟合）**：模型为一条直线，训练误差（0.1832）和验证误差（0.2105）都偏大，属于高偏差；
2. **阶数 $M=3$（良好拟合）**：平滑还原了正弦波动，训练误差（0.0385）与验证误差（0.0412）都很低且接近，属于低偏差、低方差；
3. **阶数 $M=9$（过拟合）**：训练误差被压缩到 0.0071，但验证误差暴增至 1.4820，同时权重模长激增到 $10^5$ 量级。

权重模长的急剧膨胀是多项式过拟合的典型数学特征：**为了精确穿过间隔狭窄且带有上下扰动的噪声点，高阶项必须依赖幅度极其巨大的正负权重相互抵消，从而在样本点之间产生剧烈弯折震荡**。这种数值特征启发了后续的正则化策略：只要在损失函数中惩罚过大的参数模长，就能有效抑制这种震荡。更多指标细节可参考[回归模型评估](/fundamentals/ml-basics/evaluation-regression.md)。

## 参数约束机制：L1（Lasso）与 L2（Ridge）正则化及稀疏性成因

为了限制过大的参数权重，最常用的数学手段是**正则化（Regularization）**。其做法是在原有的训练损失函数中增加一个针对权重模长的惩罚项。

在[损失函数和梯度下降](/fundamentals/ml-basics/loss-gradient-descent.md)与[线性回归和逻辑回归](/fundamentals/ml-basics/linear-logistic-regression.md)中，原本的优化目标是最小化经验损失 $\mathcal{L}_0(w)$。引入正则化后，目标函数变为：
$$\min_w \mathcal{L}_{\text{reg}}(w) = \mathcal{L}_0(w) + \lambda \Omega(w)$$
其中 $\lambda \ge 0$ 为控制惩罚力度的超参数，$\Omega(w)$ 为正则化惩罚项。

### 1. L2 正则化（Ridge / 岭回归）
惩罚项定义为权重向量的 $L_2$ 范数平方的一半：
$$\Omega(w) = \frac{1}{2}\|w\|_2^2 = \frac{1}{2} \sum_{j=1}^d w_j^2$$
使用梯度下降时的更新公式为：
$$w^{(t+1)} = w^{(t)} - \eta \left( \nabla \mathcal{L}_0(w^{(t)}) + \lambda w^{(t)} \right) = (1 - \eta \lambda) w^{(t)} - \eta \nabla \mathcal{L}_0(w^{(t)})$$
在每次更新前，原有权重都会先乘以一个略小于 1 的因子 $(1 - \eta \lambda)$，因此在深度学习中常称 L2 正则化为**权重衰减（Weight Decay）**。它会使所有权重平滑地向零收缩，抑制极端大数值，平滑模型输出。

### 2. L1 正则化（Lasso 回归）
惩罚项定义为权重向量的 $L_1$ 范数：
$$\Omega(w) = \|w\|_1 = \sum_{j=1}^d |w_j|$$
在 $w_j \ne 0$ 处的次梯度更新步为：
$$w_j^{(t+1)} = w_j^{(t)} - \eta \nabla_j \mathcal{L}_0(w^{(t)}) - \eta \lambda \cdot \text{sign}(w_j^{(t)})$$
与 L2 的衰减幅度随权重绝对值变小而减弱不同，L1 只要权重不为 0，每一步都会受到一个大小恒为 $\eta \lambda$ 的恒定推力将其拉向 0。这使得 L1 倾向于将不重要的特征权重直接压缩到 0，产生**稀疏解（Sparsity）**。

### 3. 几何等高线：为什么 L1 能把部分权重精确压为 0？
根据拉格朗日对偶性，上述加权形式与带约束的最优化问题等价：
$$\min_w \mathcal{L}_0(w) \quad \text{s.t.} \quad \Omega(w) \le C$$

![L1与L2正则化几何等高线对比图](/images/content-rebuild/a88290f186ada975/fig-4.png)

在二维参数平面 $(w_1, w_2)$ 上观察：
1. **损失函数的等高线**：未受约束的损失函数 $\mathcal{L}_0(w)$ 在无约束最优点周围形成一圈圈椭圆形等高线，椭圆越往外，损失值越大。
2. **可行域形状**：
   * **L2 约束区**：$w_1^2 + w_2^2 \le C$，在几何上是一个平滑的**圆盘**；
   * **L1 约束区**：$|w_1| + |w_2| \le C$，在几何上是一个带有尖锐顶点的**菱形**，其尖角恰好落在坐标轴上（即 $w_1 = 0$ 或 $w_2 = 0$ 处）。
3. **切点几何特性**：
   带约束优化的最优解，对应从椭圆中心向外扩散的损失等高线与约束区域相碰的**第一个切点**。
   * 对于 L2 的平滑圆周，其边界处处光滑连续且曲率均匀，没有尖锐突出的角点，切点几乎总是落在象限内部的光滑圆弧上，因此通常使所有参数都向零收缩但依然保持非零；
   * 对于 L1 的菱形区域，尖角处向外突出。当椭圆等高线从外部扩散过来相遇时，有极大几率先碰触到这些位于坐标轴上的尖角。而坐标轴上的点意味着某个参数严格为 0。

因此，L1 正则化具备内嵌的特征筛选特性，常用于高维特征的稀疏建模；L2 正则化则更适合缓解多重共线性并提升数值稳定性。

## 工程治理过拟合的常用手段：早停法、数据增强与降维

除了向目标函数添加参数正则项，工程中还会配合多层次的防御手段来治理高方差：

### 1. 早停法（Early Stopping）
模型在迭代优化过程中，通常优先学会主要低频规律，随着步数推移才逐步拟合高频噪声。
* **操作流程**：在每个训练轮次结束时，计算当前模型在独立验证集上的损失。如果验证集损失连续若干轮（容忍轮数 Patience）不再下降反而上升，则中断训练，并回滚到验证集损失最低时的那一套参数权重。
* **机制直觉**：通过限制参数优化走过的距离，在模型深入过拟合区域之前强行刹车。

![早停法机制图](/images/content-rebuild/a88290f186ada975/fig-5.png)

### 2. 数据增强（Data Augmentation）
如果模型结构必须保持较大容量，降低方差最直接的方式是扩大样本在输入空间的覆盖面。
* **操作方式**：利用任务先验合成新样本。例如图像分类中的随机裁剪、水平翻转、轻微色彩扰动，或自然语言处理中的同义词替换与回译。
* **实际作用**：迫使模型关注变换下的不变性特征，增加过拟合单个局部噪声点的难度。

### 3. 特征降维与去噪
根据维度灾难理论，特征维度过高时样本在空间中极为稀疏，模型更容易找到偶然分隔训练集的复杂超平面。
* 使用主成分分析（PCA）或[聚类和降维](/fundamentals/ml-basics/clustering-dimensionality.md)方法去除线性共线和冗余列；
* 通过特征重要性评估或统计检验，剔除与预测目标无明确关联的纯噪声特征。

## 诊断与治理全景对比

遇到模型表现不佳时，应先区分当前所处的状态，再采取针对性动作：

| 状态分类 | 核心成因 | 典型表现 | 常见改善手段 | 应避免的操作 |
| :--- | :--- | :--- | :--- | :--- |
| **欠拟合**<br>(高偏差状态) | 模型容量或特征表达力不足以拟合数据规律。 | • 训练损失远高于预期标准<br>• 验证损失与训练损失都偏高且接近 | 1. 构造非线性特征或交互项<br>2. 增加模型复杂度（如加深网络、放宽树深）<br>3. 减小正则化系数 $\lambda$ | 盲目增加训练样本量（模型本身学不会时，堆再多数据也无法拟合）。 |
| **过拟合**<br>(高方差状态) | 模型自由度过高，记住了训练集特有的样本噪声。 | • 训练损失极低<br>• 验证损失显著反弹，泛化差距（Generalization Gap）大 | 1. 补充训练数据或做数据增强<br>2. 引入 L1/L2 正则化或增大惩罚系数 $\lambda$<br>3. 使用早停法在验证损失拐点处截断<br>4. 降低特征维度，过滤噪声特征 | 盲目加深网络或进一步提高多项式阶数。 |

理解偏差与方差的动态平衡，是排查训练异常的基础思维。在后续深入探讨[分类模型评估](/fundamentals/ml-basics/evaluation-classification.md)和集成学习[决策树、随机森林和GBDT](/fundamentals/ml-basics/tree-models.md)时，我们将看到剪枝和集成策略如何直接应用这些机制；而在大语言模型场景下，[大模型微调为什么会过拟合？](/llm-100/finetuning/finetuning-overfitting.md)同样遵循参数容量与有效数据量失配的基本规律。
