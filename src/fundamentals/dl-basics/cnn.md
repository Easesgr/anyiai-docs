我们在手机上查看一张数字照片时，图像是由紧密排列的像素网格构成的。比如要识别一只猫，它的耳朵、胡须或轮廓，都由物理空间上相互挨着的局部像素共同组成。

在[神经网络基础](/fundamentals/dl-basics/neural-network-basics.md)中，多层感知机（MLP）习惯通过矩阵乘法把输入连到每一个隐藏神经元。若直接用全连接网络处理二维图像，就必须先将整张图像“拉直”成一条长向量。这种处理方式不仅破坏了像素原本的上下邻近关系，还会立刻带来极其夸张的参数量。

卷积神经网络（Convolutional Neural Network，简称 CNN）针对图像的二维网格结构，采用了两个直观的设计假设：**局部连接**与**权重共享**。它不再让单个神经元去连接整张图的所有像素，而是使用小型的滑动窗口在图像上逐步做点积。这使得参数量从几十亿骤降到几百个，同时自然保留了图像的几何信息。

## 1. 为什么全连接层处理图像会“参数爆炸”？

数字图像以二维矩阵（或包含颜色通道的三维张量）的形式保存在内存中。这种数据天然具备**空间局部性**：距离接近的像素通常属于同一个物体或纹理，彼此高度相关；而距离很远的像素，关联性往往较弱。

如果沿用普通全连接网络来处理图像，必须先执行展平（Flatten）操作，把二维矩阵拉伸成一维向量。这一步会立刻引发两个问题：

1. **打乱了垂直方向的相邻关系**：展平之后，水平相邻的像素还能排在一起，但原本垂直相邻的像素会被硬生生隔开。例如在一张 $1000 \times 1000$ 像素的图片中，第 1 行第 1 列的像素与第 2 行第 1 列的像素本来贴在一起，展平后在向量中的索引相差了整整 1000。网络不得不耗费大量训练样本去重新“领悟”这种本就明确的二维邻近关系。
2. **参数量灾难性暴增**：假设输入一张分辨率为 $1000 \times 1000$、具备 RGB 3 个通道的彩色图像，输入数值总量为：
   $$1000 \times 1000 \times 3 = 3\text{M (300 万个数值)}$$
   若第一层隐藏层只设置 1000 个神经元，仅此一层的权重矩阵尺寸为：
   $$\text{权重参数量} = (3 \times 10^6) \times 1000 = 3 \times 10^9 \text{ 个浮点数}$$
   按标准的 32 位浮点数（FP32，每个浮点数占 4 字节）计算，仅保存这单层权重就需要占用显存：
   $$\frac{3 \times 10^9 \times 4 \text{ 字节}}{1024^3 \text{ 字节/GB}} \approx 11.18\text{ GB}$$
   这还没计算前向传播和反向传播时的中间激活值与梯度开销。参数量远远超过了训练样本所能提供的有效约束，极易引起严重的过拟合（参见 [Dropout 与正则化](/fundamentals/dl-basics/dropout-regularization.md)）。

![全连接层展平瓶颈与卷积层网格拓扑对比](/images/content-rebuild/26a2ea12047172b5/fig-1.png)

CNN 不把图像拉平，而是直接在保留二维形态的网格上进行滑动计算，从结构上避开了参数爆炸。

## 2. 滑动窗口点积：卷积（互相关）运算是怎么算的？

在数学和信号处理中，标准的连续卷积操作包含两步：“翻转（Flip，旋转 180 度）”与“平移滑动相乘求和”。而在深度学习框架（如 PyTorch、TensorFlow）的底层实现中，卷积层执行的实际上是**互相关运算（Cross-correlation）**——也就是省略了翻转步骤，直接将核权重盖在输入窗口上做对应元素相乘再求和。

因为卷积核里的权重并不是人工指定的固定模板，而是由网络在反向传播中（参考 [PyTorch 自动微分引擎机制](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)）根据损失函数自动学出来的。翻转与否只相当于权重的空间对称映射，完全不影响模型的特征提取能力。因此在深度学习中，大家习惯统称这种滑动窗口点积操作为“卷积”。

### 离散互相关公式
假设单通道输入特征图为 $X \in \mathbb{R}^{H \times W}$，二维卷积核为 $K \in \mathbb{R}^{K_h \times K_w}$，偏置为一个常数标量 $b$。输出特征图 $Y$ 在坐标 $(i, j)$ 处的计算公式为：

$$Y(i, j) = (X \star K)(i, j) + b = \sum_{m=0}^{K_h - 1} \sum_{n=0}^{K_w - 1} X(i + m, j + n) K(m, n) + b$$

其中 $\star$ 代表二维离散互相关运算，$m, n$ 是卷积核内部的相对坐标位置。

### 逐步计算数值示例
我们用一个具体的算例来看它是如何一步步计算的。给定一个 $3 \times 3$ 的单通道输入矩阵 $X$ 和一个 $2 \times 2$ 的卷积核 $K$（设偏置 $b = 0$，步长为 1，无填充）：

$$X = \begin{bmatrix} 1 & 2 & 3 \\ 0 & 1 & 2 \\ 3 & 0 & 1 \end{bmatrix}, \quad K = \begin{bmatrix} 1 & 0 \\ 0 & 2 \end{bmatrix}$$

输出特征图 $Y$ 的尺寸为 $(3 - 2 + 1) \times (3 - 2 + 1) = 2 \times 2$。计算四个输出坐标的过程如下：

1. **输出位置 $(0, 0)$**：输入滑动窗口截取左上角的 $2 \times 2$ 区域 $\begin{bmatrix} 1 & 2 \\ 0 & 1 \end{bmatrix}$：
   $$Y(0, 0) = 1 \times 1 + 2 \times 0 + 0 \times 0 + 1 \times 2 = 1 + 0 + 0 + 2 = 3$$
2. **输出位置 $(0, 1)$**：窗口向右移动 1 格，截取右上角的区域 $\begin{bmatrix} 2 & 3 \\ 1 & 2 \end{bmatrix}$：
   $$Y(0, 1) = 2 \times 1 + 3 \times 0 + 1 \times 0 + 2 \times 2 = 2 + 0 + 0 + 4 = 6$$
3. **输出位置 $(1, 0)$**：窗口回到左侧并向下移动 1 格，截取左下角区域 $\begin{bmatrix} 0 & 1 \\ 3 & 0 \end{bmatrix}$：
   $$Y(1, 0) = 0 \times 1 + 1 \times 0 + 3 \times 0 + 0 \times 2 = 0 + 0 + 0 + 0 = 0$$
4. **输出位置 $(1, 1)$**：窗口向右移动 1 格，截取右下角区域 $\begin{bmatrix} 1 & 2 \\ 0 & 1 \end{bmatrix}$：
   $$Y(1, 1) = 1 \times 1 + 2 \times 0 + 0 \times 0 + 1 \times 2 = 1 + 0 + 0 + 2 = 3$$

最终得到的输出特征图为：
$$Y = \begin{bmatrix} 3 & 6 \\ 0 & 3 \end{bmatrix}$$

## 3. 为什么能大幅精简参数？局部连接与权重共享

全连接层假设输入里的每个像素和隐藏层的每个节点都有可能产生直接联系；而卷积层通过引入两项直观的结构假设，极大地缩减了需要学习的参数量：

### 假设一：局部连接（Local Connectivity）
提取图像的局部特征（如水平边缘、色块边界）时，神经元并不需要同时看整张图。每个输出神经元只和输入特征图上一个 $K_h \times K_w$ 大小的局部窗口相连，这个小窗口就叫作该神经元的**感受野（Receptive Field）**。
* **原因**：图像里的底层视觉特征（如边缘明暗变化）是由紧挨着的几个像素差分体现出来的。去和几百像素之外的点强行建立直接权重连接，不仅在统计上属于冗余噪声，还会成千上万倍地增加参数开销。

### 假设二：权重共享（Weight Sharing）
同一个卷积核在整张图像上从左往右、从上往下扫描滑动的过程中，**卷积核内部的权重参数始终保持不变**。
* **原因**：如果一个 $3 \times 3$ 的卷积核学会了检测“垂直边缘”，那么无论这条边缘出现在图像的左上角、正中央还是右下角，检测垂直边缘的数学规律是相同的。在不同位置重复使用这同一组权重，赋予了网络一个良好的数学特性——**平移等变性（Translation Equivariance）**。

用数学符号表示：设平移操作为 $g$，卷积特征提取为 $f$。平移等变性意味着把输入图像先平移再做卷积，得到的结果与先做卷积再把输出特征图做同样位移完全一致：
$$f(g(X)) = g(f(X))$$

### 参数量对比验证
重新计算前文 $1000 \times 1000$ 的单通道输入图像：
* **全连接层**（假设隐层为 1000 个节点）：需要 $1000 \times 1000 \times 1000 = 10^9$（10 亿）个权重参数。
* **卷积层**（假设配置 16 个 $3 \times 3$ 的卷积核）：无论输入图片是 $1000 \times 1000$ 还是更高分辨率，这一层的可学习权重总数仅为：
  $$16 \times (3 \times 3) = 144 \text{ 个权重}$$
  加上 16 个通道的偏置项，总共只有 160 个参数。权重共享机制彻底将模型的参数规模与输入图像的分辨率大小解耦开来。

## 4. 特征图尺寸计算：Kernel Size、Padding 与 Stride

卷积核在网格上滑动时，由于窗口自身具备大小，如果不做任何边界处理，输出图像的边缘就会缩小一圈。为了在多层网络中精确控制特征图的尺寸变化，我们需要引入**填充（Padding）**与**步长（Stride）**。

### 核心几何参数
1. **输入尺寸（$H_{in}, W_{in}$）**：输入图像或特征图的高与宽。
2. **卷积核大小（$K_h, K_w$）**：滑动窗口的高与宽。
3. **填充大小（$P_h, P_w$）**：在输入特征图的上下各填充 $P_h$ 行零（Zero-padding），左右各填充 $P_w$ 列零。
4. **步长（$S_h, S_w$）**：卷积核每次滑动时，在垂直与水平方向跳过的像素格数。

### 尺寸计算精确公式
根据滑动窗口在带有边界的网格上总共能放置的位置总数，输出特征图的尺寸由下式给出（$\lfloor \cdot \rfloor$ 表示向下取整）：

$$H_{out} = \left\lfloor \frac{H_{in} - K_h + 2P_h}{S_h} \right\rfloor + 1$$

$$W_{out} = \left\lfloor \frac{W_{in} - K_w + 2P_w}{S_w} \right\rfloor + 1$$

### 两种最常用的配置
* **Valid 卷积（不填充）**：$P = 0$。滑动窗口只能落在原始图像内部，每经过一层尺寸就会缩水 $K - 1$。深层网络如果层数很深，特征图会过快缩小甚至消失。
* **Same 卷积（等尺寸填充）**：当步长 $S = 1$ 时，若卷积核边长 $K$ 为奇数，设置填充量为：
  $$P = \frac{K - 1}{2}$$
  代入公式可以发现 $H_{out} = H_{in}$，输出特征图的大小与输入完全一致。这种配置广泛用于构建需要深层堆叠的现代卷积网络。

### 实例计算验证
* **题目**：输入特征图尺寸为 $64 \times 64$，使用 $5 \times 5$ 的卷积核，设置 $P = 2$（四周各补 2 圈零），步长 $S = 2$。
* **代入计算**：
  $$H_{out} = \left\lfloor \frac{64 - 5 + 2 \times 2}{2} \right\rfloor + 1 = \left\lfloor \frac{64 - 5 + 4}{2} \right\rfloor + 1 = \left\lfloor \frac{63}{2} \right\rfloor + 1 = 31 + 1 = 32$$
  因为宽与高对称，$W_{out} = 32$。最终输出特征图的尺寸为 $32 \times 32$。

## 5. 多通道卷积与特征融合机制

在真实任务中，输入数据往往不是单通道的灰度图。例如 RGB 彩色图像包含红、绿、蓝 3 个通道；网络中间层的特征图通常包含几十甚至几百个通道。多通道卷积通过跨通道相加，实现了空间特征与通道特征的综合提取。

### 每一个卷积核都是一个三维张量
如果输入特征图包含 $C_{in}$ 个通道，其尺寸为 $(C_{in}, H_{in}, W_{in})$。那么**每一个单独的卷积核也必须具备相同的通道深度 $C_{in}$**，其尺寸为 $(C_{in}, K_h, K_w)$。

### 计算过程：通道分别点积再相加
当一个尺寸为 $(C_{in}, K_h, K_w)$ 的三维卷积核作用于多通道输入时：
1. 卷积核的第 $c$ 个二维切片，与输入的第 $c$ 个二维通道做普通的互相关点积运算；
2. 将所有 $C_{in}$ 个通道在同一个空间位置得到的点积结果**对应逐项累加**；
3. 加上该卷积核对应的常数偏置项 $b$；
4. 累加后输出一个**单通道**的二维特征矩阵：
   $$Y(i, j) = \sum_{c=0}^{C_{in}-1} (X_c \star K_c)(i, j) + b$$

### 配置多个卷积核生成多通道输出
一个三维卷积核只能融合成一个单通道特征图。若网络需要提取 16 种不同模式的特征（如不同角度的线条、边缘、纹理），就需要准备 $C_{out} = 16$ 个独立的三维卷积核。整层的权重张量形状为：
$$\text{权重张量形状} = (C_{out}, C_{in}, K_h, K_w)$$

可学习参数总量的计算公式为：
$$\text{总参数量} = C_{out} \times (C_{in} \times K_h \times K_w) + C_{out} \quad (\text{后项为各通道偏置})$$

### PyTorch 代码验证与自动求导验证
以下代码片段使用 PyTorch 验证上述尺寸推导、参数量统计以及基于 autograd 的反向传播梯度生成过程：

```python
import torch
import torch.nn as nn

# 固定随机种子确保数值一致
torch.manual_seed(42)

# 模拟批量数据: Batch=1, 输入通道 Cin=3, 高度 H=64, 宽度 W=64
x = torch.randn(1, 3, 64, 64, requires_grad=True)

# 定义卷积层: Cin=3, Cout=16, Kernel=5x5, Stride=2, Padding=2
conv = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=5, stride=2, padding=2)

# 执行前向传播
out = conv(x)

# 验证输出尺寸: (64 - 5 + 2*2)//2 + 1 = 32
print(f"输出特征图形状: {out.shape}")  # 输出: torch.Size([1, 16, 32, 32])

# 验证参数量: 16 * (3 * 5 * 5) + 16 (偏置) = 1200 + 16 = 1216
total_params = sum(p.numel() for p in conv.parameters())
print(f"卷积层可学习参数总量: {total_params}")  # 输出: 1216

# 执行反向传播，测试计算图与梯度生成
loss = out.sum()
loss.backward()

# 检查输入与权重的梯度形状
print(f"输入 x 的梯度形状: {x.grad.shape}")        # 输出: torch.Size([1, 3, 64, 64])
print(f"卷积核权重梯度形状: {conv.weight.grad.shape}") # 输出: torch.Size([16, 3, 5, 5])
```

## 6. 池化层（Pooling）的作用与代价：空间下采样与精度损失

在经典卷积网络中，卷积层后面常会周期性地搭配一个池化层（Pooling Layer）。池化层本身**没有任何需要训练的可学习权重**，它使用固定的数学统计规则对特征图做空间降采样。

### 常见的两类池化
1. **最大池化（Max Pooling）**：取滑动窗口内的最大值输出。它能保留窗口内响应最强烈、最具辨识度的显著特征（如边缘最亮处）。
2. **平均池化（Average Pooling）**：计算滑动窗口内所有数值的算术平均值。它的效果偏向平滑局部信息，网络最后常使用全局平均池化（Global Average Pooling）把每个通道压缩成一个单一数值。

### 池化层带来的收益
1. **降低计算量与显存占用**：使用常见的 $2 \times 2$ 窗口、步长为 2 的池化，高和宽各缩小一半，后续网络层的计算量和中间激活显存直接缩减为原先的约四分之一。
2. **扩大后续卷积核的实际覆盖范围**：下采样之后，后续层同一个 $3 \times 3$ 的卷积核，在原始图像上对应覆盖的实际区域扩大了一倍，使深层神经元能够感知更大尺度的整体轮廓。
3. **提供微小位移的平移不变性（Translation Invariance）**：当输入目标轻微移动 1 个像素时，局部最大值往往依然落在同一个 $2 \times 2$ 窗口内，池化输出的值不发生改变。这对于图像分类这种只需要判断“图里有没有目标”的任务非常有用。

### 池化层的代价与现代演进
池化层带来计算精简的同时，也付出了直接的代价：**它永久性地丢弃了精细的空间几何坐标**。
* 在图像分类中，知道“有一只眼睛”就足够了，眼睛在第 32 行还是第 33 行并不敏感；
* 但在目标检测（需要框出物体坐标）和语义分割（需要精确区分每个像素属于什么物体）等**密集像素级预测**任务中，粗暴丢弃精细坐标会导致边缘定位模糊。模型不得不通过空洞卷积、反卷积或跳跃连接（Skip Connection）来找回丢失的高频细节；
* 因此，现代很多主流视觉网络（如 ConvNeXt，或采用步长大于 1 的跨距卷积 Strided Convolution）开始取消显式的池化层，直接用带步长的可学习卷积核进行下采样，让网络自主学习如何提取压缩信息。

## 知识体系接力

卷积神经网络依靠局部连接与权重共享，充分利用了图像二维网格的静态几何空间先验。然而，当输入数据从静态的二维图片变成文本、语音等具备严格时间先后顺序、长度不定的一维序列时，固定的网格滑动就难以有效捕获任意长距离的历史信息。下一篇我们将进入序列模型的世界，探讨[循环神经网络 RNN、LSTM 与 GRU 是如何处理不定长序列并维护隐藏状态的](/fundamentals/dl-basics/rnn-lstm-gru.md)。
