在图像分类或表格数据预测中，常规多层感知机（MLP）通常假设各个样本相互独立，输入特征的维度也是固定的。但在文本、语音、传感器时序等数据中，前后元素之间存在时间或位置上的先后依赖，序列长度也常常不同。

例如，“小明 借给 小刚 十元钱”与“小刚 借给 小明 十元钱”，两个句子包含完全相同的词，但词序颠倒导致含义截然相反。在阅读后半句时，我们必须记住前半句出现的主语和动作。

本篇将通过一个贯穿的文本判别任务，说明标准循环神经网络（RNN）如何通过**隐藏状态**传递时序信息，为什么随时间反向传播（BPTT）会引发**梯度消失**，以及 LSTM 与 GRU 如何通过**门控机制**保护历史梯度的流动。

## 1. 序列建模的特点与隐藏状态的概念

处理序列数据时，模型通常需要面对三个基本特点：
1. **顺序决定语义**：元素的相对次序包含关键逻辑。如果在前馈网络中直接把词按固定位置输入，交换位置就会引起特征错位。
2. **输入长度不固定**：一句话可以由 3 个词组成，也可以由 50 个词组成。传统前馈网络若强行补零（Padding）或截断，不仅可能浪费算力，还会限制模型能处理的上下文跨度。
3. **跨步依赖**：在第 $t$ 步做出的判断，往往依赖前面多个时间步积累的信息。

![序列建模核心挑战示意图](/images/content-rebuild/53b24eeca547bb5a/fig-1.png)

为了处理这类数据，循环神经网络引入了**隐藏状态（Hidden State，记作 $h$）**。

隐藏状态是一个固定维度的向量。在序列步进的过程中，它像一个持续更新的内存缓冲区：每读入一个新元素，网络就结合当前输入与上一时刻的隐藏状态，计算出新的隐藏状态，并继续向后传递。

## 2. 标准 RNN 的计算步骤与参数共享

设输入序列为 $x_1, x_2, \dots, x_T$，其中每个时间步的输入向量为 $x_t \in \mathbb{R}^m$。隐藏状态向量为 $h_t \in \mathbb{R}^d$，初始状态通常设为全零向量 $h_0 = \mathbf{0}$。

在每一个时间步 $t$，标准 RNN 执行两步计算：

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$$

$$y_t = \text{softmax}(W_{hy} h_t + b_y)$$

涉及的参数包括：
- $W_{xh} \in \mathbb{R}^{d \times m}$：将当前输入映射到隐藏状态的权重矩阵。
- $W_{hh} \in \mathbb{R}^{d \times d}$：状态转移矩阵，决定上一时刻的隐藏状态保留并传递多少信息。
- $W_{hy} \in \mathbb{R}^{k \times d}$：将当前隐藏状态映射到输出分类空间的权重矩阵。
- $b_h \in \mathbb{R}^d, b_y \in \mathbb{R}^k$：偏置向量。

![标准 RNN 单元与隐藏状态时序传递示意图](/images/content-rebuild/53b24eeca547bb5a/fig-2.png)

### 参数共享机制

无论序列展开到 5 步还是 100 步，在每个时间步中使用的矩阵 $W_{hh}$、$W_{xh}$ 和 $W_{hy}$ **始终是同一组权重**。

这一设计带来了两个特点：
1. 模型的参数量由特征维度 $m$ 和隐藏维度 $d$ 决定，与输入序列的实际长度无关；
2. 具备平移不变性：同样的词汇组合无论出现在句子开头还是末尾，网络都使用同一套转移规则来提取特征。

### 单步标量算例

为了看清状态数值的演进，我们假设输入维度 $m=1$，隐藏维度 $d=1$，所有参数退化为标量：
$W_{hh} = 0.5$，$W_{xh} = 1.0$，$b_h = 0$。激活函数为 $\tanh$。

给定长度为 2 的输入序列 $x_1 = 1.0, x_2 = -0.5$：
- **初始状态**：$h_0 = 0$
- **时间步 $t=1$**：
  $$z_1 = W_{hh} h_0 + W_{xh} x_1 + b_h = 0.5 \times 0 + 1.0 \times 1.0 + 0 = 1.0$$
  $$h_1 = \tanh(1.0) \approx 0.7616$$
- **时间步 $t=2$**：
  $$z_2 = W_{hh} h_1 + W_{xh} x_2 + b_h = 0.5 \times 0.7616 + 1.0 \times (-0.5) + 0 = 0.3808 - 0.5 = -0.1192$$
  $$h_2 = \tanh(-0.1192) \approx -0.1186$$

在计算 $h_2$ 时，$h_1$ 的信息乘上了权重 $0.5$ 参与求和，使得第 2 步的状态包含了第 1 步的信息。

## 3. 随时间反向传播（BPTT）：链式法则与雅可比矩阵连乘

在训练阶段，模型需要依据预测损失来更新权重。RNN 将网络沿时间轴展开，利用链式法则进行求导，这一过程称为**随时间反向传播（Backpropagation Through Time, BPTT）**。

假设序列总长度为 $T$，每个时间步的损失为 $L_t$，总损失为标量 $L = \sum_{t=1}^T L_t$。

以更新状态转移矩阵 $W_{hh}$ 为例，时刻 $t$ 的损失 $L_t$ 对 $W_{hh}$ 的梯度由所有历史时间步的贡献累加而成：

$$\frac{\partial L_t}{\partial W_{hh}} = \sum_{k=1}^t \frac{\partial L_t}{\partial h_t} \frac{\partial h_t}{\partial h_k} \frac{\partial h_k}{\partial W_{hh}}$$

![BPTT 展开与雅可比矩阵连乘链条示意图](/images/content-rebuild/53b24eeca547bb5a/fig-3.png)

这里最关键的项是隐状态之间的偏导数 $\frac{\partial h_t}{\partial h_k}$。因为 $h_t$ 是从 $h_{t-1}, h_{t-2}, \dots, h_k$ 逐层迭代计算出来的，展开后得到相邻步雅可比矩阵的连续乘积：

$$\frac{\partial h_t}{\partial h_k} = \prod_{j=k+1}^t \frac{\partial h_j}{\partial h_{j-1}}$$

根据隐状态定义 $h_j = \tanh(z_j)$（其中 $z_j = W_{hh} h_{j-1} + W_{xh} x_j + b_h$），令 $h_j$ 为列向量，单步转移的雅可比矩阵为：

$$\frac{\partial h_j}{\partial h_{j-1}} = \text{diag}\big(1 - h_j^2\big) W_{hh}$$

其中 $\text{diag}(1 - h_j^2)$ 是由双曲正切导数构成的对角矩阵，其对角线上的取值落在区间 $(0, 1]$ 内。

## 4. 为什么标准 RNN 会产生梯度消失与梯度爆炸？

把单步导数代入连乘式中，时刻 $t$ 回传到时刻 $k$ 的梯度传递因子为：

$$\frac{\partial h_t}{\partial h_k} = \prod_{j=k+1}^t \Big[ \text{diag}\big(1 - h_j^2\big) W_{hh} \Big]$$

当时间跨度 $t - k$ 增大（例如跨越数十个或上百个词）时，这个连乘项会引发严重的数值不稳定。

深层前馈网络（如多层 MLP）也有许多层，为什么标准 RNN 对时间步长度格外敏感？

关键差异在于**权重共享**：
1. **前馈网络**：各层拥有独立的矩阵 $W_l$。在初始化和更新过程中，不同层的矩阵奇异值各异，可以相互平衡。
2. **标准循环网络**：时间展开后的每一个虚拟“层”，乘以的都是同一个状态转移矩阵 $W_{hh}$。梯度反向传递相当于反复乘上包含 $W_{hh}$ 的结构。

![RNN 长期依赖梯度消失机理示意图](/images/content-rebuild/53b24eeca547bb5a/fig-4.png)

### 消失与爆炸的具体机制

- **梯度消失（Gradient Vanishing）**：
  双曲正切函数 $\tanh$ 的导数最大值为 1（当输入为 0 时）。只要隐状态进入轻微饱和区，导数就会迅速跌落到 0.5 以下。即使 $W_{hh}$ 的较大奇异值接近 1，在 $\text{diag}(1 - h_j^2)$ 的反复收缩下，连乘项通常也会随时间步差 $t - k$ 的增加而呈指数级衰减。随着序列步长增加，早期输入对当前损失的有效梯度往往衰减至接近于 0，使模型难以捕捉远距离的历史依赖。
- **梯度爆炸（Gradient Exploding）**：
  若 $W_{hh}$ 的较大奇异值大于 1，且激活值没有进入饱和区，连乘项可能随步数呈指数级放大，导致数值溢出（NaN）或模型更新震荡。

在工程实践中，梯度爆炸可以通过**梯度截断（Gradient Clipping）**缓解（当梯度模长超过阈值时按比例缩放）；但梯度截断无法挽救指数衰减引起的**梯度消失**。这导致标准 RNN 难以学习长距离的上下文依赖。

## 5. 长短期记忆网络（LSTM）：细胞状态与三门机制

为了缓解时间轴连乘带来的梯度指数衰减，长短期记忆网络（LSTM）改变了状态更新的代数形式。

LSTM 的核心思路是：**在对外输出的隐藏状态 $h_t$ 之外，增设一条主要由加法更新构成的通路——细胞状态（Cell State，记作 $C_t$）**。

![LSTM 核心通道与三门协同机制示意图](/images/content-rebuild/53b24eeca547bb5a/fig-5.png)

在每个时间步，LSTM 维护两个向量：
- **细胞状态 $C_t$**：内部保存的长期记忆；
- **隐藏状态 $h_t$**：当前时刻对外输出并参与下一步门控计算的短期特征。

LSTM 借助三个采用 Sigmoid 激活函数（输出值域在 $[0, 1]$）的门控结构来控制信息的增减：

### LSTM 的完整状态更新方程

1. **遗忘门（Forget Gate, $f_t$）**：决定清除历史记忆中的哪些维度。
   $$f_t = \sigma\big(W_f [h_{t-1}, x_t] + b_f\big)$$

2. **输入门（Input Gate, $i_t$）与候选新状态（$\tilde{C}_t$）**：决定将当前输入中的哪些新特征写入记忆。
   $$i_t = \sigma\big(W_i [h_{t-1}, x_t] + b_i\big)$$
   $$\tilde{C}_t = \tanh\big(W_c [h_{t-1}, x_t] + b_c\big)$$

3. **细胞状态更新（加法主路）**：旧状态经遗忘门筛选后，加上经输入门筛选的新特征。
   $$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$
   （$\odot$ 表示逐元素相乘 Hadamard 积）

4. **输出门（Output Gate, $o_t$）与隐藏状态生成**：决定细胞状态中的哪些信息输出到 $h_t$。
   $$o_t = \sigma\big(W_o [h_{t-1}, x_t] + b_o\big)$$
   $$h_t = o_t \odot \tanh(C_t)$$

### 加法通路为什么能缓解梯度消失？

观察损失沿细胞状态向前传递的单步导数：

$$\frac{\partial C_t}{\partial C_{t-1}} = \text{diag}(f_t) + \dots$$

与标准 RNN 必须经过矩阵相乘 $W_{hh}$ 和 $\tanh'$ 的导数不同，在细胞状态的主通路上，直接导数项是对角矩阵 $\text{diag}(f_t)$：
- 梯度反传不需要跨越连续的矩阵乘法，而是逐时间步乘以遗忘门向量 $f_t$；
- 如果模型学习到某些维度的遗忘门接近 $1.0$（即 $f_t \approx 1$），该维度的梯度在跨时间步传递时就不会经历指数级剧烈衰减；
- 这种**加法直通设计**，允许网络根据任务需要自主决定历史信息的保留时间。

## 6. 门控循环单元（GRU）：结构精简与对比

LSTM 虽然缓解了梯度消失，但每个时间步包含 4 个线性映射层（3 个门加 1 个候选状态），参数量和计算量约为同维度标准 RNN 的 4 倍。

门控循环单元（GRU）在保留门控梯度的同时简化了结构：

![GRU 与 LSTM 结构及计算通路对比示意图](/images/content-rebuild/53b24eeca547bb5a/fig-6.png)

### GRU 的精简设计

1. **状态合一**：取消独立的细胞状态 $C_t$，只保留单一隐藏状态 $h_t$。
2. **门控合并**：将遗忘门与输入门融合成一个**更新门（Update Gate, $z_t$）**，通过互补权重 $(1 - z_t)$ 和 $z_t$ 进行凸组合线性插值，表示“遗忘多少旧信息就填补多少新信息”。

### GRU 的数学方程

1. **重置门（Reset Gate, $r_t$）**：控制计算候选状态时上一时刻状态的参与程度。
   $$r_t = \sigma\big(W_r [h_{t-1}, x_t] + b_r\big)$$

2. **更新门（Update Gate, $z_t$）**：控制旧状态保留与新状态写入的比例。
   $$z_t = \sigma\big(W_z [h_{t-1}, x_t] + b_z\big)$$

3. **候选隐藏状态（$\tilde{h}_t$）**：
   $$\tilde{h}_t = \tanh\big(W [r_t \odot h_{t-1}, x_t] + b\big)$$

4. **隐藏状态更新**：
   $$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

### 复杂度与参数量对比

设输入特征维度为 $m$，隐藏状态维度为 $d$，各模型的参数量与计算规模对比如下（不计偏置项）：

| 模型类型 | 内部状态流 | 分支数量 | 核心权重参数量 | 相对 RNN 复杂度 | 长期依赖表现 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **标准 RNN** | 单一 $h_t$ | 1 个变换 | $d \times (d + m)$ | $1\times$ 基准 | 弱（容易出现梯度消失/爆炸） |
| **LSTM** | 双通道 $C_t, h_t$ | 3 门 + 1 候选状态（4 个变换） | $4 \times d \times (d + m)$ | 约 $4\times$ | 较强（加法主路缓解梯度衰减） |
| **GRU** | 单一 $h_t$ | 2 门 + 1 候选状态（3 个变换） | $3 \times d \times (d + m)$ | 约 $3\times$（比 LSTM 少 25%） | 较强（凸组合加法直通） |

在中短长度的序列建模任务中，GRU 通常以更少的参数量取得与 LSTM 接近的效果；若任务需要对长期记忆进行精细的独立隔离控制，LSTM 的独立输入输出门仍具备结构上的调节空间。

## 7. 循环架构的局限：时序串行依赖与信息瓶颈

尽管 LSTM 和 GRU 缓解了长距离梯度消失问题，但它们仍然遵循时间轴逐时间步循环递推的范式。这一机制存在两个难以克服的瓶颈：

### 1. 无法沿时间轴并行计算

由于递推关系 $h_t = \mathcal{F}(h_{t-1}, x_t)$ 的存在，计算时刻 $t$ 的状态前，**必须等待时刻 $t-1$ 计算完毕**。

这意味着在训练展开深度为 $T$ 的序列时，时间维度的计算依赖链条深度必须为 $O(T)$。现代 GPU 拥有成千上万个计算核心，却无法把同一个序列的不同时间步拆分给不同核心同时运算，导致显卡算力利用率受到限制。

### 2. 固定维度的信息压缩瓶颈

无论序列展开多少步，网络在 $t$ 时刻对历史的全部理解都必须压缩进一个固定维度 $d$ 的向量中。当序列长度扩展到数千步时，早期细节仍容易被后续信息稀释。

为了摆脱时间步串行依赖和固定向量压缩瓶颈，模型结构开始转向允许任意两个位置直接建立连接的计算范式——这正是后续 **[Attention 机制](/fundamentals/dl-basics/attention-mechanism.md)** 所要解决的问题。
