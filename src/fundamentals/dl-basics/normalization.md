在训练深层神经网络时，一个常见的问题是：随着网络层数加深，前层权重的微小调整经过多层矩阵乘法和非线性激活的累积放大，后层接收到的特征尺度和分布会发生剧烈波动。我们在[梯度消失和梯度爆炸是什么？为什么深层网络不好训练？](/fundamentals/dl-basics/gradient-vanishing-exploding.md)中讨论过权重初始化对初始梯度的保护，但随着训练持续迭代，各层权重的持续更新依然会让激活值的均值和方差不受控地漂移。

激活值过大容易让 Sigmoid、Tanh 等非线性函数进入饱和区，导致梯度消失；即使使用 ReLU，特征尺度的层层膨胀也会让损失曲面变得极其陡峭，迫使训练必须使用极小的学习率以防发散。

**特征归一化（Feature Normalization）**就是给每一层的激活值加一把动态标尺，将其约束在稳定的数值范围内。本文重点拆解深度学习中最常见的两种归一化方法：**Batch Normalization（批归一化，BN）**与**Layer Normalization（层归一化，LN）**，对比它们的统计切片维度、训练与推理生命周期，以及为什么 Transformer 最终选择了 LN。

## 激活值分布漂移与损失曲面

考虑一个简单的全连接网络，第 $l$ 层的输出为：

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \quad a^{(l)} = \sigma(z^{(l)})$$

在反向传播更新参数时，所有层的参数 $W$ 和 $b$ 同时改变。对于深层的第 $l$ 层，其输入 $a^{(l-1)}$ 的统计特性由前面所有层的权重共同决定。底层微小的步长更新，在传递到深层时往往会引起输入特征分布的明显偏移。

![深层网络输入特征分布随层数加深产生均值漂移与方差扩散示意图](/images/content-rebuild/0e5dad8d34d18c91/fig-1.png)

阅读提示：图 1 展示了未经归一化的特征流向。左侧平稳的标准分布随着层数加深，方差不断扩散，部分激活值偏移到饱和区域，破坏了反向传播的梯度连续性。

早期研究将这种现象描述为“内部协变量偏移（Internal Covariate Shift）”，认为归一化的主要作用是消除这种偏移。后来的理论与实验分析表明，归一化更本质的贡献在于**平滑了损失函数的几何曲面**，使得梯度的 Lipschitz 连续性更好，优化器可以使用更大的学习率快速稳定地收敛。

## 归一化的两步通用计算流程

BN 和 LN 虽然统计的张量轴不同，但都采用相同的两步处理：**标准化（Standardization）**与**可学习仿射变换（Affine Transformation）**。

给定一组包含 $m$ 个标量数值的特征集合 $\mathcal{X} = \{x_1, x_2, \dots, x_m\}$：

### 步骤一：零均值单位方差标准化

先计算当前特征集合的均值 $\mu$ 和方差 $\sigma^2$：

$$\mu = \frac{1}{m} \sum_{i=1}^m x_i$$

$$\sigma^2 = \frac{1}{m} \sum_{i=1}^m (x_i - \mu)^2$$

然后将每个数值缩放为零均值、单位方差的标准形式：

$$\hat{x}_i = \frac{x_i - \mu}{\sqrt{\sigma^2 + \epsilon}}$$

其中 $\epsilon$ 是一个极小的常数（例如 $1\times 10^{-5}$），主要用于防止分母除以零。

### 步骤二：可学习仿射变换

如果仅仅将激活值硬性限制在均值为 0、方差为 1 的分布中，会削弱网络对特征的表达能力。例如，Sigmoid 函数在 0 附近近乎线性，强行将输入约束在这一区间会导致非线性单元退化。

为了保留网络自主表达的能力，归一化引入了两个可学习参数：缩放因子 $\gamma$（Scale）和平移因子 $\beta$（Shift）：

$$y_i = \gamma \hat{x}_i + \beta$$

在初始化时，通常设置 $\gamma = 1, \beta = 0$。如果在反向传播过程中，模型发现未归一化的原始尺度更利于降低损失，优化器可以将参数训练为 $\gamma = \sqrt{\sigma^2 + \epsilon}$ 和 $\beta = \mu$，从而等价于恒等映射。归一化操作把“是否改变分布尺度”的选择权交给了优化算法。

![通用归一化计算流程与可学习仿射变换参数流向图](/images/content-rebuild/0e5dad8d34d18c91/fig-2.png)

阅读提示：图 2 展示了输入数值经过均值中心化、方差缩放再到仿射参数调谐的完整过程。反向传播时，梯度不仅传给输入 $x$，还会更新 $\gamma$ 和 $\beta$。

## Batch Normalization：沿 Batch 维度跨样本统计

Batch Normalization（由 Ioffe 和 Szegedy 于 2015 年提出）的核心原则是：**针对同一个特征通道，跨越批次（Batch）内的所有样本计算统计量**。

### 1. 计算切片维度

* **全连接层（输入形状为 $(B, D)$）**：$B$ 为批大小，$D$ 为特征维度。BN 沿着第 0 维（批次轴）进行统计。对于第 $j$ 个特征维度，它抽取当前批次全部 $B$ 个样本在该维度上的数值，计算出该维度的标量均值 $\mu_j$ 和方差 $\sigma^2_j$。每个特征通道拥有独立的 $\gamma_j$ 和 $\beta_j$。
* **卷积层（输入形状为 $(B, C, H, W)$）**：由于卷积核在图像的空间各处共享权重，BN 在统计通道 $c$ 时，不仅跨越 $B$ 个样本，还跨越了高度 $H$ 和宽度 $W$ 两个空间维度。也就是说，统计集合的大小为 $m = B \times H \times W$，整个通道共用一组标量均值、方差以及参数 $\gamma_c, \beta_c$。

![Batch Normalization 张量统计切片与小批量抖动分析图](/images/content-rebuild/0e5dad8d34d18c91/fig-3.png)

阅读提示：图 3 中左侧展示了沿批次轴纵向聚合通道特征的过程。右侧展示了批大小（Batch Size）对统计量稳定性的影响，Batch 较小时估计误差显著放大。

### 2. 数值算例：BN 全连接层计算过程

假设全连接层输出张量形状为 $(B=4, D=2)$，数值如下：

$$X = \begin{bmatrix} 1.0 & 10.0 \\ 3.0 & 20.0 \\ 5.0 & 10.0 \\ 7.0 & 20.0 \end{bmatrix}$$

针对第 0 个特征列 $x_{:, 0} = [1.0, 3.0, 5.0, 7.0]^T$：

1. 计算均值：$$\mu_0 = \frac{1.0 + 3.0 + 5.0 + 7.0}{4} = 4.0$$
2. 计算方差：$$\sigma^2_0 = \frac{(1-4)^2 + (3-4)^2 + (5-4)^2 + (7-4)^2}{4} = \frac{9 + 1 + 1 + 9}{4} = 5.0$$
3. 设 $\epsilon = 0, \gamma = 1, \beta = 0$，标准化值：
   $$\hat{x}_{:, 0} = \left[ \frac{1-4}{\sqrt{5}}, \frac{3-4}{\sqrt{5}}, \frac{5-4}{\sqrt{5}}, \frac{7-4}{\sqrt{5}} \right]^T \approx \left[ -1.3416, -0.4472, 0.4472, 1.3416 \right]^T$$

针对第 1 个特征列 $x_{:, 1} = [10.0, 20.0, 10.0, 20.0]^T$，均值为 15.0，方差为 25.0，标准化后结果为 $[-1.0, 1.0, -1.0, 1.0]^T$。两个特征维度独立统计，互不干扰。

### 3. 小 Batch 瓶颈

BN 的统计基础建立在“当前批次的均值与方差能够代表全量数据分布”这一假设上：
* 当 Batch Size 足够大（如 64、128）时，批次统计量比较稳定。
* 当 Batch Size 很小时（如目标检测或分割任务受限于显存，通常只能取 $B=2$ 或 $B=4$），抽样噪声会导致均值和方差剧烈震荡，带来优化方向的不稳定。
* 在全连接层（或特征空间尺寸为 $1 \times 1$）的极端情况 $B=1$ 时，单个样本在每个通道只有一个数值，方差恒为 0，分子也恒为 0，标准化输出恒为 0，BN 完全失效；即使在普通卷积层中 $B=1$ 时空间各像素能计算方差，BN 也退化为了单样本内的局部统计，失去了跨样本批统计的代表性。

## BN 的训练与推理行为差异

BN 在工程实现中最容易踩坑的地方在于：**训练和推理阶段所采用的均值和方差来源不同**。

### 1. 训练阶段

在训练阶段，BN 使用当前小批次的即时均值 $\mu_{\mathcal{B}}$ 和方差 $\sigma^2_{\mathcal{B}}$ 对特征进行归一化。同时，为了给脱离批次的单样本推理做准备，BN 在后台通过指数移动平均（EMA）维护全局均值与方差的估计值：

$$\mu_{\text{run}} \leftarrow (1 - \alpha) \cdot \mu_{\text{run}} + \alpha \cdot \mu_{\mathcal{B}}$$

$$\sigma^2_{\text{run}} \leftarrow (1 - \alpha) \cdot \sigma^2_{\text{run}} + \alpha \cdot \sigma^2_{\mathcal{B}}$$

其中 $\alpha$ 为动量系数（PyTorch 中默认为 0.1）。`running_mean` 和 `running_var` 属于模型的持久状态（Buffers），**不参与反向传播的梯度计算**。

### 2. 推理阶段

在实际部署推理时，系统通常需要处理单个输入请求（$B=1$），此时无法计算样本间方差。因此，推理阶段直接使用训练期间累积下来的固定统计量 $\mu_{\text{run}}$ 和 $\sigma^2_{\text{run}}$：

$$y = \gamma \left( \frac{x - \mu_{\text{run}}}{\sqrt{\sigma^2_{\text{run}} + \epsilon}} \right) + \beta$$

此时 BN 变成了一个固定的线性变换。在模型导出或部署时，该线性变换可以直接合并进上一层卷积或线性层的权重中（算子融合），完全消除推理时的额外计算开销。

![BN 训练与推理阶段计算图差异与模型状态切换流程图](/images/content-rebuild/0e5dad8d34d18c91/fig-4.png)

阅读提示：图 4 对比了训练与评估模式下的数据通路。训练模式动态计算即时批统计量并更新缓存；评估模式直接使用冻结的缓存数据。

### 3. 常见工程故障

如果在推理前遗漏调用 `model.eval()`，模型在测试时会继续使用测试批次的即时统计量：
* 当测试集以小批次或单个样本输入时，统计量失真会导致输出结果完全错误。
* 同一个测试样本在与不同样本一起打包推理时，会因为同批次其他样本数值的变动而得到不同的输出结果。
关于这一机制在排查模型精度异常时的具体场景，可以进一步参考[Transformer 为什么采用 Layer Normalization 而不是 Batch Normalization](/interview/llm-interview/layer-normalization.md)。

## Layer Normalization：单样本内部特征跨度统计

为了摆脱对批大小的强依赖，Jimmy Ba、Jamie Ryan Kiros 和 Geoffrey Hinton 于 2016 年提出了 Layer Normalization。

LN 的核心设计思路是：**完全解耦样本之间的联系，在单个样本内部跨越特征维度计算统计量**。

### 1. 计算切片维度

* **全连接层（输入形状为 $(B, D)$）**：对于第 $i$ 个样本，LN 沿着第 1 维（特征轴 $D$）计算该样本自身包含的所有特征值的均值 $\mu_i$ 和方差 $\sigma^2_i$。每个样本的归一化过程完全独立，互不影响。
* **Transformer / 序列张量（输入形状为 $(B, T, C)$）**：$T$ 为序列长度（Token 数），$C$ 为隐藏特征维度。在标准的 Transformer 实现中，LN 作用于**最后一个维度（通道轴 $C$）**。对于第 $b$ 个序列在第 $t$ 个位置的 Token 向量 $x_{b, t} \in \mathbb{R}^C$，LN 计算该向量内部 $C$ 个特征分量的均值和方差：

$$\mu_{b, t} = \frac{1}{C} \sum_{k=1}^C x_{b, t, k}$$

$$\sigma^2_{b, t} = \frac{1}{C} \sum_{k=1}^C (x_{b, t, k} - \mu_{b, t})^2$$

![Layer Normalization 沿特征维度切片与单样本独立计算机制图](/images/content-rebuild/0e5dad8d34d18c91/fig-5.png)

阅读提示：图 5 高亮展示了单个 Token 向量在自身特征维度上的统计闭环，计算过程不涉及批次内其他任何样本的数据。

### 2. 数值算例：LN 计算过程

设一个单独的 Token 向量为 $x = [2.0, 4.0, 6.0, 8.0]$（特征维度 $C=4$）：

1. 计算均值：$$\mu = \frac{2.0 + 4.0 + 6.0 + 8.0}{4} = 5.0$$
2. 计算方差：$$\sigma^2 = \frac{(2-5)^2 + (4-5)^2 + (6-5)^2 + (8-5)^2}{4} = \frac{9 + 1 + 1 + 9}{4} = 5.0$$
3. 设 $\gamma = 1, \beta = 0, \epsilon = 0$，标准化值：
   $$\hat{x} = \left[ \frac{2-5}{\sqrt{5}}, \frac{4-5}{\sqrt{5}}, \frac{6-5}{\sqrt{5}}, \frac{8-5}{\sqrt{5}} \right] \approx [-1.3416, -0.4472, 0.4472, 1.3416]$$

无论当前批次中包含 1 个样本还是 10,000 个样本，只要该 Token 向量自身的数值不变，归一化结果就完全一致。

### 3. LN 的一致性优势

由于 LN 仅使用当前输入向量自身的数值计算统计量：
* **训练与推理逻辑完全一致**：推理阶段不需要切换分支，无需依赖外部维护的滑动平均值。
* **不受批大小约束**：支持任意 Batch Size，哪怕在 $B=1$ 的流式在线生成场景下，依然能正常且确定地完成归一化。

## 为什么 Transformer 和 NLP 任务选择 LN 而非 BN

在经典卷积网络（参见[卷积神经网络 CNN 是什么？为什么适合处理图像？](/fundamentals/dl-basics/cnn.md)）中，BN 是标准配置；但进入以[Transformer 是什么？为什么它成为大模型的基础架构？](/fundamentals/dl-basics/transformer.md)为代表的自然语言处理领域后，LN 成为了主导选择。这一选型分化是由序列建模的内在属性决定的。

| 维度 | Batch Normalization (BN) | Layer Normalization (LN) |
| :--- | :--- | :--- |
| **统计聚合方向** | 跨样本聚合同通道（沿 Batch 轴） | 单样本内部聚合所有特征（沿 Feature 轴） |
| **批次依赖性** | 强依赖 Batch Size，小批次性能明显下降 | 完全独立于 Batch Size，支持 $B=1$ |
| **训练/推理一致性** | 逻辑不同（训练用批统计，推理用 EMA 累积值） | 逻辑完全一致（均用当前向量即时统计量） |
| **变长序列支持** | 较差（Padding 符号会污染统计量） | 天然适配（每个 Token 独立在特征维度归一化） |
| **主流应用** | 传统计算机视觉（ResNet 等大 Batch 任务） | Transformer、自然语言处理、大语言模型 |

### 原因一：变长序列与填充（Padding）污染

自然语言句子长度通常不一致。为了将多条文本组成一个二维或三维张量，需要用填充符号（如 `<pad>`，对应数值通常为 0）将较短的句子补齐到统一长度。

如果采用 BN，系统会在特定时间步 $t$ 跨样本计算均值和方差：
* 在句子靠后的位置，短文本全是无效的 Padding 零向量，真实样本只有少数几条。
* 跨样本聚合会把大量的补零数据算入统计量，严重扭曲均值和方差，导致真实的语义特征被污染。
* 即使借助 Mask 掩码剔除 Padding 位置，由于长句尾部的有效样本数量极其稀疏，有效批大小 $B_{\text{eff}}$ 会骤降到 1 或 2，再次触发小批次统计量抖动。

而 LN 是在每个 Token 内部沿特征维度进行计算。无论句子有多长、批次中有多少 Padding，有效 Token 内部的均值和方差计算完全不受其他句子的影响。

![变长序列 Padding 导致 BN 跨样本统计污染与 LN 独立计算对比图](/images/content-rebuild/0e5dad8d34d18c91/fig-6.png)

阅读提示：图 6 展示了变长序列对归一化的影响。上方 BN 跨样本统计时，短句末尾的 Padding 块扭曲了真实均值；下方 LN 对每个有效 Token 向量独立计算，避开了 Padding 干扰。

### 原因二：自回归流式解码的单步特性

大语言模型在生成文本时采用自回归解码，每次仅输出一个新 Token。在在线服务场景中，用户的并发请求往往以单流的形式到达，系统需要实时响应单样本输入（$B=1$）。

在这种场景下，BN 根本无法在推理时获取当前时间步的真实批次统计量，只能依赖离线训练记录的全局滑动平均值；而语言生成具有高度动态的上下文特征，固化的滑动统计量难以适配生成过程中独特的语义分布。LN 每次只在当前 Token 自身的向量维度上归一化，与批次完全解耦，天然契合自回归推理。

### 原因三：特征维度的整体表征

在词嵌入和深层表征中，词向量内部各维度之间的相对大小和激活模式编码了具体的语义特征。LN 在向量维度做中心化和尺度缩放，保留了该向量内部不同分量之间的相对强弱关系；而 BN 会跨样本调整某一个维度的数值，改变了单个词向量内部各特征维度的相对比值。

## 代码验证：张量切片与单样本独立性

以下代码通过 PyTorch 验证了 `nn.LayerNorm` 在三维序列张量 $(B, T, C)$ 上的计算行为，并验证了修改批次中的其他样本不会影响目标样本的归一化结果：

```python
import torch
import torch.nn as nn

torch.manual_seed(42)

# 构造序列张量: Batch=2, 序列长度 T=3, 特征维度 C=4
B, T, C = 2, 3, 4
x = torch.randn(B, T, C)

# 初始化 LayerNorm，指定对最后一个维度 (C=4) 归一化
ln = nn.LayerNorm(normalized_shape=C, eps=1e-5)

# 模型前向传播
y = ln(x)

# 手动计算 Batch 0, Token 0 的归一化结果
x_sample = x[0, 0, :]  # 形状为 (4,)
mean_manual = x_sample.mean()
# 注意：LayerNorm 内部使用总体方差（除以 m），因此需设置 unbiased=False
var_manual = x_sample.var(unbiased=False)
y_manual = (x_sample - mean_manual) / torch.sqrt(var_manual + 1e-5)

print("原始向量:", x_sample)
print("PyTorch LN 输出:", y[0, 0, :])
print("手动归一化输出:", y_manual)

# 验证单样本独立性：大幅修改第二个样本的数值
x_modified = x.clone()
x_modified[1, :, :] = x_modified[1, :, :] * 100.0
y_modified = ln(x_modified)

# 检查第一个样本的输出是否有任何变化
diff = (y[0] - y_modified[0]).abs().max().item()
print("样本 1 被大幅修改后，样本 0 的输出最大差异:", diff)
# 输出结果严格为 0.0，证明 LN 对批次内的其他样本完全解耦
```

运行上述代码可以验证：
1. Layer Normalization 输出的每个 Token 向量，其自身特征在仿射参数生效前严格保持均值为 0、方差为 1；
2. 批次中其他样本无论如何变动，目标样本的输出差异严格为 0，两者在计算图上完全独立。

## 总结与延伸

* **Batch Normalization**：沿批次维度统计通道均值和方差。适合输入尺寸对齐、批大小充裕的计算机视觉模型；但在小 Batch、变长序列和单样本自回归推理中表现受限。
* **Layer Normalization**：在单个样本内部跨越特征维度统计。计算逻辑完全独立于批次，训练与推理行为一致，天然适配变长序列和自回归生成，是 Transformer 和大语言模型的标准基础组件。

在大语言模型的最新架构演化中，LN 还衍生出了 Pre-LN 结构以及去除减均值操作、只保留均方根缩放的 **RMSNorm**（如 LLaMA 系列所采用，目的是减少显存读写带宽，提升计算吞吐）。但它们的核心逻辑始终一致：在单个 Token 的特征向量内部完成尺度控制。

理解了特征尺度的控制机制后，当模型参数进一步扩大到数十亿级别时，另一个核心问题是防止模型记住训练集细节而丧失对新数据的泛化能力。相关机制请参考[Dropout 和正则化：深度学习如何缓解过拟合？](/fundamentals/dl-basics/dropout-regularization.md)。
