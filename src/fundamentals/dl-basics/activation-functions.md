在上一讲[神经网络是怎么工作的？从神经元到多层感知机](/fundamentals/dl-basics/neural-network-basics.md)中，我们了解了多层感知机的计算过程：输入特征经过矩阵相乘加上偏置，再经过激活函数输出。这里有一个很自然的问题：矩阵乘法本身就能组合输入特征，为什么不能直接把多层线性变换堆叠起来，而必须在中间插入非线性激活函数？

结论很简单：**如果不加非线性激活函数，无论堆叠多少层网络，其整体数学形式依然只是一个单层线性变换**。它连最基础的异或（XOR）分类任务都无法解决。

本讲通过异或分类这个贯穿小例子，推导多层网络退化为线性变换的数学过程，再对比 Sigmoid、Tanh、ReLU、LeakyReLU 与 GELU 的导数特性、计算开销与失效边界，最后给出隐藏层与输出层的选型方法。

## 贯穿例子：为什么纯线性网络连异或（XOR）都解不开？

我们来看一个简单的二分类任务。平面上有四个样本点：
- 标签为 0 的样本：$(0, 0)$ 和 $(1, 1)$
- 标签为 1 的样本：$(0, 1)$ 和 $(1, 0)$

这是一个经典的异或逻辑分布。如果你在草稿纸上画出这四个点，就会发现：**在二维平面上，没有任何一条单一直线能够把标签 0 的点和标签 1 的点完全分开**。传统机器学习可以用非线性核函数（如支持向量机 SVM 的 RBF 核）或树模型的正交切分来处理，而神经网络要想解决这个问题，靠的就是多层结构配合非线性激活函数。

假设我们构建一个两层全连接网络，但不加任何激活函数（或者激活函数为恒等映射 $f(z) = z$）。对于输入向量 $x$，各层计算如下：

$$z^{[1]} = W^{[1]} x + b^{[1]}$$

$$z^{[2]} = W^{[2]} z^{[1]} + b^{[2]}$$

把第一层的表达式代入第二层：

$$z^{[2]} = W^{[2]} (W^{[1]} x + b^{[1]}) + b^{[2]} = (W^{[2]} W^{[1]}) x + (W^{[2]} b^{[1]} + b^{[2]})$$

令组合矩阵 $W' = W^{[2]} W^{[1]}$，组合偏置 $b' = W^{[2]} b^{[1]} + b^{[2]}$，式子就变成了：

$$z^{[2]} = W' x + b'$$

无论第一层有 100 个神经元还是 1000 个神经元，经过两层纯线性计算后，最终输出与输入之间依然是一个严格的线性变换。多个线性变换的复合，数学上等价于单次线性变换。此时网络在几何空间里划出的决策边界仍然是一条平直的超平面，无论训练多少轮，都无法切分异或分布。

![两层线性变换退化为单层仿射变换与加入非线性激活函数划分异或边界的对比](/images/content-rebuild/d8fce5a11bb50d1f/fig-1.png)

只有在每层之后加入非线性激活函数 $\sigma(\cdot)$：

$$a^{[1]} = \sigma(W^{[1]} x + b^{[1]})$$

$$z^{[2]} = W^{[2]} a^{[1]} + b^{[2]}$$

网络才能把原始平直的特征空间进行弯曲、折叠，使得在隐层表示空间中，原本不可分的数据点变得线性可分。

## Sigmoid 函数：值域压缩与两端梯度饱和

Sigmoid（又称 Logistic 函数）是最早被广泛应用的激活函数之一，定义与一阶导数如下：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

$$\sigma'(z) = \sigma(z)(1 - \sigma(z))$$

Sigmoid 把任意实数输入压缩到 $(0, 1)$ 区间。在二分类任务的输出层中，这个数值可以直接解释为样本属于正类的后验概率 $P(y=1|x)$。

![Sigmoid 函数曲线与其导数分布，标出饱和区与最大导数值 0.25](/images/content-rebuild/d8fce5a11bb50d1f/fig-2.png)

然而，如果把 Sigmoid 放在深层网络的隐藏层，会遇到两个明显的优化阻碍：

### 1. 两端饱和导致梯度消失
当输入绝对值较大（例如 $|z| > 4$）时，$e^{-z}$ 会使输出极度接近 1 或 0。观察导数公式 $\sigma'(z) = \sigma(z)(1 - \sigma(z))$：
- 当 $\sigma(z) \approx 1$ 时，$\sigma'(z) \approx 0$
- 当 $\sigma(z) \approx 0$ 时，$\sigma'(z) \approx 0$

只有在输入接近 0 时，导数才取得最大值 $\sigma'(0) = 0.5 \times 0.5 = 0.25$。在反向传播中，浅层参数的梯度是由后续各层导数连乘得到的。由于每个 Sigmoid 导数最大只有 0.25，多层相乘后梯度会迅速趋向于 0，浅层参数几乎无法得到有效更新。这就是隐藏层使用 Sigmoid 极易出现梯度消失的原因（关于梯度问题的系统定量推导可参考[梯度消失和梯度爆炸是什么？为什么深层网络不好训练？](/fundamentals/dl-basics/gradient-vanishing-exploding.md)）。

### 2. 输出非零均值引发更新震荡
Sigmoid 输出恒为正数（$a^{[l-1]} > 0$）。根据梯度计算公式：

$$\frac{\partial L}{\partial W_{ij}^{[l]}} = \frac{\partial L}{\partial z_i^{[l]}} a_j^{[l-1]}$$

对于同一个神经元 $i$ 的所有输入权重 $W_{i, :}$，其更新梯度的正负号完全由标量项 $\frac{\partial L}{\partial z_i^{[l]}}$ 决定。这意味着与该神经元相连的所有权重，在单次更新中要么全部增大，要么全部减小。当参数的理想更新方向需要“部分增大、部分减小”时，优化过程就只能沿着锯齿状（Zig-Zag）路径迂回前进，降低收敛效率。

## Tanh 函数：零均值改进与饱和区局限

为了解决 Sigmoid 输出恒为正的问题，双曲正切函数（Tanh）被引入：

$$\tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1$$

$$\tanh'(z) = 1 - \tanh^2(z)$$

Tanh 将输入映射到 $(-1, 1)$ 区间，函数图像关于原点对称，输出的期望接近 0（Zero-centered）。

![Tanh 与 Sigmoid 的函数与导数对比，突出零均值与最大导数 1.0 的优势](/images/content-rebuild/d8fce5a11bb50d1f/fig-3.png)

相比 Sigmoid，Tanh 有两个直接改进：
1. **均值归零**：隐层输出有正有负，输入权重梯度的正负号不再被完全同向绑定，缓解了更新过程中的锯齿震荡。
2. **原点导数更大**：当 $z = 0$ 时，$\tanh'(0) = 1.0$，是 Sigmoid 峰值 0.25 的 4 倍。在接近 0 的线性区内，梯度传导不会被人为缩减。

**局限**：Tanh 依然属于双侧饱和函数。当 $|z| > 2.5$ 时，导数会迅速衰减至 0.05 以下。在网络层数较深且缺乏合适归一化时，加权和一旦偏离原点，反向传播依然会遇到梯度消失问题；同时指数运算仍占用一定计算资源。

## ReLU 函数：分段线性与计算效率优势

整流线性单元（Rectified Linear Unit, ReLU）的表达式非常直接：

$$\text{ReLU}(z) = \max(0, z)$$

其导数形式（在 $z=0$ 处数学上不可导，框架中通常采用次梯度定义，工程约定 $z=0$ 时导数为 0 或 1）：

$$\text{ReLU}'(z) = \begin{cases} 1 & \text{if } z > 0 \\ 0 & \text{if } z < 0 \end{cases}$$

![ReLU 的单侧抑制结构与梯度在正半轴无损传导机制](/images/content-rebuild/d8fce5a11bb50d1f/fig-4.png)

ReLU 在深度网络中得到广泛应用，主要有三个原因：
1. **正半轴无饱和**：当 $z > 0$ 时，局部导数恒为 1。反向传播时，梯度经过该神经元不会被激活函数连乘削弱，大幅缓解了深层网络的梯度消失问题。
2. **计算开销极低**：Sigmoid 和 Tanh 都需要计算昂贵的浮点指数运算（$e^z$），而 ReLU 只需要一次硬件级的阈值比较（`cmp` 或条件赋值），前向计算与反向求导都更加高效。
3. **单侧抑制带来稀疏激活**：当输入小于等于 0 时输出为 0。在一个批次的数据前向计算中，通常只有一部分神经元处于激活状态，使得网络在面对特定样本时表现出更稀疏的特征表达。

## ReLU 的失效边界与改进：Dying ReLU、LeakyReLU 与 GELU

ReLU 虽然解决了正半轴的梯度衰减，但其负半轴硬截断的特性带来了一种特定的失效现象：**Dying ReLU（神经元坏死）**。

### 1. Dying ReLU 是怎么发生的？
如果某个神经元的权重因为过大的学习率发生剧烈偏移，或者偏置被调整为一个很大的负数，导致对于训练集中的**所有样本**，该神经元的输入都满足 $z = w^T x + b < 0$。

此时：
- 该神经元对所有样本的前向输出恒为 0；
- 其局部导数恒为 0。

在反向传播中：

$$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} x^T = 0 \times x^T = 0$$

传入该神经元的梯度始终为 0，该神经元的参数将永远停留在原地，无法通过后续训练纠正，相当于永久失活。

![Dying ReLU 的单向死锁机制与 LeakyReLU、GELU 的平滑修正机制](/images/content-rebuild/d8fce5a11bb50d1f/fig-5.png)

### 2. LeakyReLU：保留微弱负斜率通道
为了避免神经元在负半轴完全失去梯度，LeakyReLU 在负半轴保留了一个固定的小斜率 $\alpha$（通常取 $\alpha = 0.01$）：

$$\text{LeakyReLU}(z) = \max(\alpha z, z)$$

$$\text{LeakyReLU}'(z) = \begin{cases} 1 & \text{if } z > 0 \\ \alpha & \text{if } z \le 0 \end{cases}$$

即使输入为负，反向传播时依然有 $\alpha$ 比例的梯度回传，为失活神经元保留了参数更新和纠正的可能性。

### 3. 高斯误差线性单元（GELU）
在以 [Transformer 是什么？为什么它成为大模型的基础架构？](/fundamentals/dl-basics/transformer.md) 为代表的现代预训练模型中，GELU 成为主流选择。

GELU 的基本思路是根据输入数值自身的大小来决定其通过比例：输入越小，被置零的概率越大；输入越大，越倾向于原样保留。

$$\text{GELU}(z) = z \cdot \Phi(z)$$

其中 $\Phi(z)$ 是标准正态分布 $\mathcal{N}(0, 1)$ 的累积分布函数（CDF）。工程上通常使用近似公式计算：

$$\text{GELU}(z) \approx 0.5z \left( 1 + \tanh\left( \sqrt{\frac{2}{\pi}} \left( z + 0.044715 z^3 \right) \right) \right)$$

GELU 是一条全局光滑的非单调曲线，在 $z \approx -0.75$ 处取得极小值（约为 $-0.17$）。相比 ReLU 在原点处的生硬折角，GELU 在全域平滑可导，既保留了负轴小范围信息的平滑渗透，又保持了正轴近乎线性的传导能力。

## 验证实验：用 PyTorch 观察极端输入下的梯度

以下是一段最小可运行的 PyTorch 代码，直接观察各激活函数在负向饱和点（$z = -5.0$）和正向激活点（$z = 5.0$）下的导数计算结果：

```python
import torch
import torch.nn.functional as F

def test_activation_gradients():
    activations = {
        "Sigmoid": torch.sigmoid,
        "Tanh": torch.tanh,
        "ReLU": torch.relu,
        "LeakyReLU": lambda x: F.leaky_relu(x, negative_slope=0.01),
        "GELU": F.gelu
    }
    
    print(f"{'激活函数':<12} | {'z=-5.0 梯度':<12} | {'z=5.0 梯度':<12}")
    print("-" * 42)
    
    for name, fn in activations.items():
        # 分别对两点计算导数
        z = torch.tensor([-5.0, 5.0], requires_grad=True)
        out = fn(z)
        out.sum().backward()
        grad = z.grad
        print(f"{name:<12} | {grad[0].item():<12.6f} | {grad[1].item():<12.6f}")

if __name__ == "__main__":
    test_activation_gradients()
```

运行上述代码输出数值如下：
- **Sigmoid**：负向梯度 $0.006648$，正向梯度 $0.006648$。两端均陷入饱和区，导数非常微弱。
- **Tanh**：负向梯度 $0.000182$，正向梯度 $0.000182$。远离原点后梯度几乎归零。
- **ReLU**：负向梯度 $0.000000$（完全截断），正向梯度 $1.000000$（无损传递）。
- **LeakyReLU**：负向梯度维持预设的 $0.010000$，正向梯度为 $1.000000$。
- **GELU**：负向梯度平滑趋近于 0（约 $-0.000007$），正向梯度约为 $1.000007$。

## 激活函数选型指南：隐藏层与输出层

在构建网络时，隐藏层与输出层面临的目标不同，选型逻辑必须分开考虑。

![激活函数在隐藏层特征提取与输出层任务匹配上的系统选型决策树](/images/content-rebuild/d8fce5a11bb50d1f/fig-6.png)

### 1. 隐藏层选型：关注梯度健康与计算开销

- **通用多层感知机（MLP）与卷积网络（CNN）**：首选 **ReLU**。计算代价小，配合标准化方法（如 [Batch Normalization 和 Layer Normalization 有什么用？](/fundamentals/dl-basics/normalization.md)）时训练稳定高效。
- **深层 Transformer 与大语言模型**：主流选用 **GELU**（或其门控变体 SwiGLU）。全局光滑的导数有助于深层架构在大量参数下的平稳优化。
- **浅层网络或观察到较多神经元失活时**：可以尝试 **LeakyReLU**（负斜率设为 0.01），给负输入保留微弱梯度通路。
- **隐藏层通常避免使用 Sigmoid**：在层数较多的前馈网络中，Sigmoid 容易导致浅层梯度消失，极难收敛。

### 2. 输出层选型：根据任务目标与损失函数严格匹配

输出层的激活函数不是为了“引入非线性”，而是为了把模型的实数得分映射到目标任务所要求的数值空间：

| 任务类型 | 期望输出格式 | 推荐输出层激活函数 | 匹配的损失函数 |
| :--- | :--- | :--- | :--- |
| **二分类任务** | 单个正类概率值 $\in (0, 1)$ | **Sigmoid** | 二元交叉熵（Binary Cross-Entropy） |
| **单标签多分类** | 各类别概率和为 1 的概率向量 | **Softmax** | 类别交叉熵（Categorical Cross-Entropy） |
| **多标签多分类** | 每个类别独立的概率值 $\in (0, 1)$ | **Sigmoid**（各通道独立计算） | 逐类别二元交叉熵 |
| **无界连续值回归** | 任意实数值 $\in (-\infty, +\infty)$ | **无激活函数（线性输出 Linear）** | 均方误差（MSE）或 L1 损失 |
| **非负连续值预测** | 范围在 $[0, +\infty)$ 的实数 | **ReLU 或 Softplus** | 均方误差或泊松损失 |
