在前两篇中，我们推导了[反向传播算法的链式法则计算流](/fundamentals/dl-basics/forward-backward-propagation.md)，并探讨了[各类优化器如何加速参数更新](/fundamentals/dl-basics/optimizers.md)。但在机器学习任务中，让训练损失尽可能接近零并不等于模型真正学会了规律。

以预测二手房价格的神经网络为例：输入特征包括建筑面积、房龄、朝向，同时可能夹杂着样本特有的随机噪声，比如房东的幸运数字、签约当天的室外气温。如果网络参数量很大、拟合能力过剩，优化算法完全有能力把“幸运数字是 7 时房价偏高 3 万”这种偶发巧合当作规则强行背下来。最终的结果是：模型在训练集上误差极小，但拿去预测新房源时却频频出错。

这种模型在训练集上表现优异、在未知测试集上性能显著恶化的现象就是**过拟合（Overfitting）**。为了让模型学到真正的普适规律，我们需要引入约束手段。本篇将通过这个房价例子，推导**L1/L2 正则化（权重衰减）**与 **Dropout** 的具体工作原理和工程实现细节。

## 经验风险与期望风险：训练损失与验证误差的差距从何而来

在机器学习中，我们最希望降低的是**期望风险（Expected Risk）** $R(f)$，即模型在真实世界所有可能数据分布 $P(X, Y)$ 上的整体平均损失：

$$R(f) = \mathbb{E}_{(x, y) \sim P(X, Y)} [\mathcal{L}(f(x), y)] = \int \mathcal{L}(f(x), y) \, dP(x, y)$$

然而，真实世界的数据分布是无法直接穷尽的。我们在实际工程中拿到的，只有从该分布中采样出的有限训练集 $\mathcal{D}_{\text{train}} = \{(x_i, y_i)\}_{i=1}^N$。因此，程序实际优化的是**经验风险（Empirical Risk）** $R_{\text{emp}}(f)$：

$$R_{\text{emp}}(f) = \frac{1}{N} \sum_{i=1}^N \mathcal{L}(f(x_i), y_i)$$

依据大数定律，当独立同分布采样的样本量 $N$ 足够大时，经验风险会逼近期望风险。但在有限样本条件下，直接追求经验风险最小化（Empirical Risk Minimization, ERM）往往会遇到问题。

![模型训练损失与验证误差随训练轮次演化的泛化差距曲线图](/images/content-rebuild/beed96d22d9af0e0/fig-1.png)

*上图展示了训练损失与验证误差随训练轮次演变的关系。请注意两条曲线在拐点右侧张开的剪刀差，这是由于模型过度优化训练样本特有的噪声，导致经验风险继续下降而真实期望风险恶化，泛化差距持续拉大。*

在统计学习理论中，模型在真实分布上的期望风险与训练集经验风险之间的差值被称为**泛化差距（Generalization Gap）**：

$$\text{Gap}_{\text{gen}} = R(f) - R_{\text{emp}}(f)$$

在工程实践中，由于真实数据分布穷尽不可得，我们通常在独立划分的验证集或测试集上计算经验误差 $\hat{R}_{\text{val}}(f)$，用它作为期望风险 $R(f)$ 的经验估计，从而通过观察验证误差与训练损失的剪刀差来监控泛化差距。

随着训练轮次推进，模型通常经历三个阶段：

1. **欠拟合阶段**：训练损失与验证损失同步下降，模型正在学习面积、房龄等关键通用规律。
2. **最佳泛化点**：验证损失达到全局最低点。此时模型学到了通用的统计特征，尚未过度迎合训练集独有的噪声。
3. **过拟合阶段**：训练损失继续逼近 0，但验证损失掉头向上恶化。模型开始消耗多余参数去“记忆”房东幸运数字等个别样本的噪声，泛化差距迅速扩大，形成典型的剪刀差。

为了限制模型过度自由地记忆噪声，我们必须在优化过程中引入**归纳偏置（Inductive Bias）**——即人为对参数或网络结构施加先验约束。最经典的两类约束是**参数惩罚（L1/L2 正则化）**与**计算图随机扰动（Dropout）**。

## L2 正则化与权重衰减：通过平滑权重抑制噪声敏感度

### 数学目标与求导

L2 正则化的基本直觉是：**较小的权重参数对应更平滑的预测函数**。在线性层 $y = w x + b$ 中，如果权重 $w$ 很大，输入特征 $x$ 只要有微小扰动，输出 $y$ 就会剧烈跳变；反之，若 $w$ 处于较小区间，输出对无关特征的波动就不会过度敏感。

我们在经验损失函数后加上权重向量的 L2 范数平方惩罚：

$$\mathcal{L}_{\text{reg}}(w) = \mathcal{L}_0(w) + \frac{\lambda}{2} \|w\|_2^2 = \mathcal{L}_0(w) + \frac{\lambda}{2} \sum_{j} w_j^2$$

其中 $\lambda > 0$ 为正则化超参数，控制惩罚力度。对任意权重分量 $w_j$ 求梯度：

$$\nabla_{w_j} \mathcal{L}_{\text{reg}}(w) = \nabla_{w_j} \mathcal{L}_0(w) + \lambda w_j$$

在标准随机梯度下降（SGD）中，学习率为 $\eta$，参数更新规则为：

$$w_{t+1} = w_t - \eta \nabla_w \mathcal{L}_{\text{reg}}(w_t) = w_t - \eta (\nabla_w \mathcal{L}_0(w_t) + \lambda w_t)$$

合并同类项后可以写成：

$$w_{t+1} = (1 - \eta \lambda) w_t - \eta \nabla_w \mathcal{L}_0(w_t)$$

![L2 正则化在 SGD 更新步中对权重矢量的收缩机制示意图](/images/content-rebuild/beed96d22d9af0e0/fig-2.png)

*上图展示了 L2 正则化的更新动力学分解：在每一步执行经验损失梯度的位移前，权重必须先乘以小于 1 的收缩因子 $(1 - \eta \lambda)$，从而被持续拉向原点。*

### 单步数值算例

从公式可以看出，只要 $\eta \lambda < 1$，收缩因子 $(1 - \eta \lambda)$ 必定是一个小于 1 的正数。也就是说，**在沿着当前批次负梯度方向移动之前，权重本身先按固定比例无条件收缩一次**。这就是 L2 正则化在 SGD 中被称为“权重衰减（Weight Decay）”的原因。

我们通过具体的数值算例来看：

* 假设某个特征连接权重当前为 $w_t = 2.0$；
* 学习率 $\eta = 0.1$，正则化系数 $\lambda = 0.05$；
* 当前批次经验损失的反向传播梯度为 $\nabla \mathcal{L}_0(w_t) = 0.4$。

若**未启用 L2 正则化**（$\lambda = 0$）：
$$w_{t+1} = 2.0 - 0.1 \times 0.4 = 1.96$$

若**启用 L2 正则化**（$\lambda = 0.05$）：
$$w_{t+1} = (1 - 0.1 \times 0.05) \times 2.0 - 0.1 \times 0.4 = 0.995 \times 2.0 - 0.04 = 1.99 - 0.04 = 1.95$$

单步相比未正则化多衰减了 $0.01$。在成千上万个批次的训练循环中，如果某个特征（如幸运数字）对降低经验损失没有持续而确切的贡献，它的梯度项就无法抵消每一步的 $(1 - \eta \lambda)$ 缩放，该权重就会被持续压制在接近 0 的微小区间。

### SGD 与自适应优化器（AdamW）的差异

在标准 SGD 中，向损失函数添加 $\frac{\lambda}{2}\|w\|_2^2$ 与在参数更新步直接乘以衰减系数 $(1 - \eta \lambda)$ 在数学上完全等价。

但在 Adam 等自适应学习率优化器中，两者会产生分歧。正如我们在[优化器原理详解](/fundamentals/dl-basics/optimizers.md)中所述，Adam 会根据历史平方梯度的移动平均开方 $\sqrt{v_t} + \epsilon$ 来缩放每一步更新量。若把 $\lambda w$ 直接放进损失函数求导：

$$g_t = \nabla \mathcal{L}_0(w_t) + \lambda w_t$$
$$w_{t+1} = w_t - \frac{\eta}{\sqrt{v_t} + \epsilon} g_t$$

这会导致梯度绝对值较大的权重分量，其衰减量反而被分母中更大的 $\sqrt{v_t}$ 缩小；更新不频繁的参数受到的相对衰减反而过大。因此，在 Adam 中通常采用 **AdamW**，把权重衰减直接剥离出来作用于参数更新步，维持比例收缩的初衷。

## L1 正则化：绝对值惩罚与特征稀疏性机理

### 绝对值惩罚与次梯度

L1 正则化对权重的绝对值和进行惩罚：

$$\mathcal{L}_{\text{reg}}(w) = \mathcal{L}_0(w) + \lambda \|w\|_1 = \mathcal{L}_0(w) + \lambda \sum_{j} |w_j|$$

绝对值函数在 $w_j = 0$ 处不可微，因此需要使用**次梯度（Subgradient）**。对于一维绝对值函数 $f(w) = |w|$，其次微分定义为：

$$\partial |w| = \begin{cases} \{1\}, & w > 0 \\ [-1, 1], & w = 0 \\ \{-1\}, & w < 0 \end{cases}$$

当 $w_j \neq 0$ 时，参数更新公式为：

$$w_{t+1} = w_t - \eta \nabla_w \mathcal{L}_0(w_t) - \eta \lambda \cdot \text{sign}(w_t)$$

其中 $\text{sign}(w_t)$ 是符号函数。

![L1 菱形次梯度约束与 L2 圆形平滑约束在参数平面的几何对比图](/images/content-rebuild/beed96d22d9af0e0/fig-3.png)

*上图展示了二维参数空间中损失等高线与正则化约束边界的几何关系。请注意左侧 L1 的菱形尖点如何迫使最优点直接落在坐标轴上产生稀疏解。*

### 为什么 L1 能彻底将权重压为 0？

对比 L1 与 L2 的更新步，可以看到收缩规律的本质差异：

1. **L2 的衰减力与参数大小成正比**：L2 带来的衰减量是 $\eta \lambda w_t$。当权重逐渐缩小时（例如 $w_t = 0.001$），衰减量也按比例缩减为极小的数值，拉力越来越弱。因此 L2 倾向于让权重无限逼近 0，但极难在有限步内精确停留在 0。
2. **L1 的衰减力大小恒定**：L1 带来的次梯度衰减量大小恒为 $\eta \lambda \cdot \text{sign}(w_t)$。无论权重本身多小，只要未达到 0，每一步都受到固定大小的向心拉力。但在有限离散步长下，单纯依靠次梯度步会在 0 附近震荡跨越；实际优化（如近端梯度法 Proximal Gradient）通常借助软阈值算子（Soft-Thresholding），当参数更新进入 $[-\eta \lambda, \eta \lambda]$ 区间时直接截断为 0，从而高效产出精确的稀疏解。

从几何约束视角看（将正则化等价视为约束条件下的最优化）：
* **L2 约束域**是一个超球面（二维下为圆形），损失等高线与圆周相切的位置通常落在光滑的圆弧上，各维度坐标一般都不为 0。
* **L1 约束域**是一个超多面体（二维下为旋转 45 度的菱形），拥有尖锐的顶点。这些尖点恰好落在坐标轴上（此时其余维度的参数为 0）。向外扩张的损失等高线极大概率首先接触到菱形的尖点，使得次要维度的权重被精确截断为 0。

在房价预测的例子中，如果使用 L1 正则化，“房东幸运数字”和“室外气温”这两个无用特征的权重会被直接压缩为 0，模型相当于自动完成了**特征选择（Feature Selection）**。

## Dropout：破坏神经元共适应性与隐式模型集成

与改变损失函数形式的 L1/L2 正则化不同，Dropout 是一种在训练阶段直接**修改网络拓扑**的方法。

### 阻断神经元共适应（Co-adaptation）

在标准多层感知机中，隐藏层激活值计算公式为：

$$z = W x + b, \quad h = \sigma(z)$$

在密集训练中，相邻神经元很容易产生**共适应（Co-adaptation）**现象：神经元 A 误记了一个伪特征，而相邻的神经元 B 学到了一个相反的偏移来抵消 A 的偏差。从最终损失来看输出依然正确，但这种网络结构非常脆弱——一旦测试集样本稍微变化导致 A 的输出失真，B 的补偿机制就会失效，预测误差便会放大。

![全连接层神经元在 Dropout 掩码作用下阻断共适应性与子网络采样机制](/images/content-rebuild/beed96d22d9af0e0/fig-4.png)

*上图展示了 Dropout 如何通过伯努利随机掩码瓦解神经元之间的依赖网络。左侧的密集关联在右侧被随机离散化，迫使存活神经元独立提取有效表征。*

Dropout（Srivastava et al., 2014）通过在训练的每次前向传播中，以保留概率 $1 - p$ 随机保留神经元，以丢弃概率 $p$ 强行将其激活值置为 0：

$$m_j \sim \text{Bernoulli}(1 - p)$$
$$\tilde{h}_j = m_j \cdot h_j$$

由于任何一个同伴神经元在当前批次都有可能被随机清零，单个神经元无法再依赖特定同伴的掩护，必须学会提取更加鲁棒的独立特征。

### 隐式模型集成（Implicit Ensemble）

若某一层拥有 $D$ 个隐藏单元，理论上每个单元有“保留”与“丢弃”两种状态，组合起来共有 $2^D$ 种可能的子网络结构。每次 mini-batch 迭代，模型都在随机采样这 $2^D$ 个子网络中的一个进行单步更新。所有子网络共享同一套权重矩阵，这相当于以极小的计算开销实现了一种大规模参数共享的集成学习。

## Inverted Dropout 标准实现：期望对齐与推理免缩放

### 原始 Dropout 与 Inverted Dropout 的演进

在原始 Dropout 实现中，训练阶段直接执行伯努利置零：

$$\tilde{h} = m \odot h, \quad m_j \sim \text{Bernoulli}(1 - p)$$

由于 $\mathbb{E}[m_j] = 1 - p$，下一层接收到的激活值在训练阶段的数学期望为：

$$\mathbb{E}[\tilde{h}_j] = (1 - p) h_j$$

到了推理（Inference）阶段，所有神经元都要参与计算以得到确定性的稳定输出，因此所有掩码均保持为 1。此时下一层接收到的输入期望恢复为 $h_j$。

这就产生了训练与推理阶段**数值能量分布不一致**的问题。早期做法是在**推理阶段**把所有权重乘以 $(1 - p)$，即 $W_{\text{test}} = (1 - p) W$。但在工程部署时，推理引擎（如 TensorRT、ONNX Runtime）加载模型时必须额外维护一套权重缩放转换，一旦漏掉就会导致输出数值失真。

![Inverted Dropout 训练阶段除以保留概率与推理阶段免缩放直通对比图](/images/content-rebuild/beed96d22d9af0e0/fig-5.png)

*上图对比了训练与推理两个阶段的数据流。Inverted Dropout 将缩放算子前置到了训练图内部，使得测试图保持绝对透明直通。*

### 前置缩放的数学证明

现代深度学习框架（包括 PyTorch 的 `nn.Dropout`）统一采用 **Inverted Dropout（反向 Dropout）**。其方案是在**训练阶段**生成掩码后，直接将输出除以保留概率 $(1 - p)$：

$$\tilde{h} = \frac{m \odot h}{1 - p}, \quad m_j \sim \text{Bernoulli}(1 - p)$$

此时计算训练阶段激活值的数学期望：

$$\mathbb{E}[\tilde{h}_j] = \mathbb{E}\left[ \frac{m_j h_j}{1 - p} \right] = \frac{\mathbb{E}[m_j] \cdot h_j}{1 - p} = \frac{(1 - p) h_j}{1 - p} = h_j$$

推导表明：**在训练阶段预先除以 $(1 - p)$，就让激活值的期望直接与完整无丢弃状态对齐**。

带来的工程收益非常直接：在评估与推理阶段（调用 `model.eval()` 时），Dropout 层直接退化为恒等映射（Identity），无需进行任何缩放与权重修改，输入数据直接原样透传。

### PyTorch 代码验证

以下代码验证 Inverted Dropout 在训练与评估模式下的输出与梯度行为：

```python
import torch
import torch.nn as nn

# 设置随机种子保证可复现
torch.manual_seed(42)

p = 0.4  # 丢弃概率，保留概率为 1 - p = 0.6
x = torch.ones(1, 10, requires_grad=True)  # 基础输入激活值全为 1.0

dropout = nn.Dropout(p=p)

# 1. 模拟训练模式
dropout.train()
y_train = dropout(x)

print("--- 训练阶段 (train mode) ---")
print("掩码与缩放后的输出值:\n", y_train)
# 存活单元的数值应当放大为: 1.0 / (1 - 0.4) = 1.6667
survived = y_train[y_train > 0]
scale = 1.0 / (1.0 - p)
print(f"存活单元数值是否为 1/(1-p) ({scale:.4f}):", 
      torch.isclose(survived, torch.tensor(scale)).all().item())

# 验证大数定律下的期望守恒
large_x = torch.ones(100000)
large_y = dropout(large_x)
print("10万维全1向量经过 Dropout 后的均值:", round(large_y.mean().item(), 4))

# 验证反向传播梯度
loss = y_train.sum()
loss.backward()
print("反向传播梯度 x.grad:\n", x.grad)
# 存活单元的梯度同样被放大 1/(1-p) 倍，被丢弃单元梯度为 0
print("存活单元的梯度是否等于 1/(1-p):", 
      torch.isclose(x.grad[y_train > 0], torch.tensor(scale)).all().item())

# 2. 模拟推理阶段
dropout.eval()
with torch.no_grad():
    y_eval = dropout(x)

print("\n--- 评估阶段 (eval mode) ---")
print("推理输出值（直接透传）:\n", y_eval)
print("推理输出是否严格等于原始输入:", torch.equal(y_eval, x))
```

在底层反向传播时，根据 PyTorch 的 autograd 链式法则，被屏蔽的神经元局部导数为 0，梯度不会反向传导；而存活神经元的反向梯度同样会乘以 $\frac{1}{1-p}$，确保了梯度的无偏估计。

## 超参数选择与训练监控曲线判读

### 超参数经验区间与模型差异

不同网络架构对正则化的敏感度存在明显差异：

1. **Dropout 丢弃概率 $p$**：
   * **全连接层（MLP）**：由于参数密度高且缺少局部拓扑先验，过拟合风险高，通常在隐藏层设置 $p \in [0.2, 0.5]$。
   * **输入层**：若要对原始输入添加掩码噪声，通常设置较小的丢弃率，如 $p \in [0.05, 0.1]$，防止有用输入信号被过度破坏。
   * **卷积层（CNN）**：标准 Dropout 在卷积特征图上的效果往往不如全连接层。因为卷积特征具有极强的局部相关性，单独随机屏蔽一个像素，相邻像素依然能还原出相似特征。CNN 中更常优先使用**数据增强**与[批量归一化（Batch Normalization）](/fundamentals/dl-basics/normalization.md)，或采用按通道置零的 **SpatialDropout**。
   * **Transformer 架构**：现代注意力模型（如后续讨论的 [Transformer 模型](/fundamentals/dl-basics/transformer.md)）通常在自注意力输出及前馈层后施加 $p = 0.1$ 的轻量 Dropout。

2. **权重衰减参数 $\lambda$（`weight_decay`）**：
   * 在配合 SGD 或 AdamW 时，搜索区间通常位于 $[10^{-5}, 10^{-2}]$ 之间。设置过大（如 $\lambda > 0.1$）会导致欠拟合，所有参数被过早压制在 0 附近；设置过小（如 $\lambda < 10^{-6}$）则起不到约束作用。

### 曲线判读与调参决策表

在训练过程中，根据训练集和验证集的损失变化轨迹可按如下策略调整：

| 验证损失曲线表现 | 背后原因 | 调参动作建议 |
| :--- | :--- | :--- |
| **反弹发散（剪刀差巨大）** | 正则化约束不足，模型容量过度拟合了训练噪声 | 适度增大 Dropout 概率 $p$；提高优化器的 `weight_decay`；启用 Early Stopping 提前终止训练 |
| **高位停滞（欠拟合）** | 正则化约束过强，压制了模型提取真实有用特征的能力 | 调小或临时关闭 Dropout；减小 `weight_decay`；增加网络隐藏层宽度或深度 |
| **阶跃剧烈震荡** | 丢弃概率 $p$ 过大导致相邻步次间有效网络拓扑变化过激 | 适当降低 $p$；调小学习率 $\eta$ |
| **平稳收敛（理想状态）** | 泛化差距保持在合理低位，验证集指标收敛稳定 | 保持当前超参数配置，保存模型权重 |

## 总结与延伸

回顾本篇的核心机制：

1. **L2 正则化（权重衰减）**：对权重平方求导引入 $(1 - \eta \lambda)$ 衰减因子，促使权重保持平滑的小振幅分布；在自适应学习率优化器中推荐使用 AdamW 进行解耦更新。
2. **L1 正则化**：通过恒定大小的收缩拉力和多面体几何尖点约束，将冗余特征参数精确截断为 0，具备特征稀疏化能力。
3. **Dropout**：通过伯努利随机掩码瓦解神经元共适应性，并以极低开销实现子网络集成；Inverted Dropout 在训练期按 $1/(1-p)$ 放大激活，使推理阶段可以免除额外缩放、保持透明直通。

正则化方法是在模型结构与损失函数层面施加通用的平滑先验。但如果输入数据本身具备二维空间结构（例如图像中物体的平移、旋转与尺度变化），仅靠全连接层配合正则化依然不够高效。如何把空间局部相关性与平移不变性直接编码进网络架构？下一讲我们将深入探讨图像特征提取的经典范式——[卷积神经网络（CNN）的工作机制](/fundamentals/dl-basics/cnn.md)。
